1. 研究目标与本次路线调整

机器人在暗处观察杯口时，单帧可能看不清边缘。杯子静止，可以积累过去的弱线索；杯子移动但对应准确，旧测量仍有用；杯子被挪到新位置后，旧位置不应继续拖着抓取动作；只有当前一帧突然变坏时，也不应清空此前可靠历史。N01 研究这些情况怎样由同一套计算规则处理，并在机器人需要行动时输出可用表征。

核心问题：在弱观测下积累有用历史，同时识别已经失效的历史支持，并消除它对当前表征和动作的持续误导。 研究对象是完整 RAW 编码器及其行动后果。局部统计量用于解释成败，不能代替完整模型表现。

v1.1 做出以下调整：

  1. P3 一次建成完整 N01。 时空支持、实际内容融合、撤回重算、有界记忆、期限读出和 π0.5 训练同时纳入 P3；不再把每个局部组件作为独立的长期研究阶段。
  2. 真实 RawVLA-Bench 从 P3 起承担主体训练和开发验证。 程序生成信号只承担数值检查与有边界的辅助诊断；局部改进也必须返回真实任务链验证。
  3. 每次研究交付包含可理解的真实案例。 同步展示输入、历史利用、支持变化、来源干预和动作后果，配套整体统计。
  4. 成熟能力直接复用。 使用作者完整模块及正式规模；新增设计集中在证据组织规则，避免自造小网络充当强基线。
  5. 理论对应主链，训练对应完整任务。 每项保证列出对象、假设、推导和实际执行路径；充分训练由数据覆盖、优化和动作/开发闭环证据共同支持。

P3 的内部调试、warm-up、恢复检查和诊断可以顺序执行，但交付对象始终是同一个完整模型。实现出一个零件、局部误差下降、测试通过或服务能运行，都不足以宣布 P3 完成。

3. 文献依据、成熟模块与创新位置

3.1 检索范围与研究判断

本次扩展检索覆盖 RAW burst/video、对应与遮挡、状态空间与机器人记忆、变化检测与顺序统计、可撤回推断、RAW 表征适配和可视化解释。重点核对论文的方法/训练设定及部分作者源码；来源与代码核对层级见 来源记录。新增候选未完成安装、训练或 GPU 兼容验收，不以检索数量宣称穷尽或首创。

已有工作 应复用或认真比较的能力 对 N01 的限制与启发
DBSR、BSRT [R01–R02] 完整 RAW 特征、对齐和融合；Swin/流引导可变形对齐 图像恢复效果不能直接转移为非图像表征或动作能力
BIPNet、Burstormer [R03–R04] 跨帧通信、隐式/多尺度对齐与渐进融合 光流并非唯一入口；成熟融合本身就能抑制部分坏历史
KPN、Handheld MFSR [R05–R06] 逐位置来源利用、真实噪声和错配鲁棒融合 不把“有选择地多帧积分”当作新增贡献
SEA-RAFT、WAFT [R07–R08] 成熟对应模块、迭代/直接运动估计与训练方法 RGB 权重、数值单位与预测风险不自动适配目标 RAW
RViDeformer、AIM 2025 RAW 视频挑战 [R09–R10] 真实噪声与多传感器数据 只支持相应传感器/恢复诊断，不是动作数据

Switchable Constraints、iSAM2 [R20–R21] 错误约束退出、依赖更新和重求解 来源删除已有基础；不能只给神经缓存加一个 mask 就宣称新框架

Noise2Noise/Noise2Self [R27–R28]、attention 解释性研究 [R29–R30]分别约束辅助监督和可视化结论。Perceiver IO、Mamba 和 REN [R31–R33]是按需使用的读出、状态与稳定性参考，不是 P3 必装清单。

默认内容骨干：现有作者规模 DBSR。 固定上游 16f158e0553b6702cc1693c43f733c2830973278；保留 64 通道、9 个残差块、512 维特征及成熟融合器。继续使用已接入的三通道 RAW stem，不通过复制通道伪造第四个测量。DBSR 派生源码遵循现有 CC-BY-NC-SA-4.0 与学术用途声明。模型初始化、已有 RAW 任务权重是否采用及其训练来源，在 P3 核心比较前锁定；各臂共享同样初始化条件。

默认运动模块：现有完整 SEA-RAFT。 固定上游 9137517ba24e628442aec097d3afe71d03503b75；保留核心编码、对应和更新模块。P2 模型可作候选初始化，必须与目标场景中的实际表现对照；不直接继承原风险表。主因果通路仅使用当前与过去观测。新对应训练、校准属于 P3 完整任务的一部分，不再单设一轮脱离真实场景的局部性能关卡。

记忆和读出：先复用现有有界 RAW 回放及 VisualTokenPostprocessor。 学习投影属于可训练容量。首版不要求新造 query 网络；确需可变读出时参考 Perceiver IO 完整结构。Mamba/TS-Mamba 仅在实际瓶颈支持其必要性时进入替换分支，不能以“完整 N01”为由强行加入未经验证的递归模块。

作者完整模型参数较少不构成否定理由；为 smoke 砍掉主要层、通道或运动更新，再把它当强模型，不符合本方案。新的网络/权重在正式运行前保存仓库提交、配置、许可、数据与损失来源、文件 hash 和必要适配，不使用浮动 HEAD 冒充执行版本。

3.3 拟验证的新增设计

N01 的新增位置是：共同组织结构的空间成员、时间有效期、来源角色与撤回依赖，使支持选择实际控制特征和状态，并改善行动中的积累—修订取舍。 不是发明一种平均、注意力或 Mamba 层。

最近邻差异必须能被实验否证：相同成熟骨干、历史信息和训练条件下，完整 N01 是否比成熟融合和“标准检测＋reset”减少错误历史拖尾，同时保留静态弱信号收益与单帧异常鲁棒性。若全部收益由成熟模块、增加历史/容量或普通 reset 解释，按已有方法组合报告，不能宣称新增机制成立。

4. 完整模型及首版功能规格

4.1 主数据流

RawVLA-Bench 当前及历史 RAW，多视角分别登记
  → 唯一来源记忆 + 校准、有效性和真实单位
  → 完整逐帧特征 + 当前到历史的运动对应候选
  → 空间结构相容性与时间有效期共同选择支持
  → 被接纳来源的成熟融合 + 可撤回状态重建
  → 同一版本的非图像视觉 token
  → π0.5 语言/动作后端 → 动作与闭环反馈

支持改变 → 使全部受影响依赖失效 → 从保留 RAW 重算 → 提交新版本

主链不生成 RGB/sRGB/XYZ 中间图像，不使用 RGB 教师蒸馏或 RGB 重建目标。RGB 镜像或固定预览渲染仅用于独立系统基线与人工理解。多相机各有来源/时间身份；没有经验证几何时，不跨相机直接混合 RAW 测量。后端沿用固定的相机/token 约定。

4.2 来源、结构与状态

唯一来源沿用 (dataset, episode, camera, frame, channel_or_phase, sensor_y, sensor_x) 语义，但允许张量、掩码与紧凑索引实现，不要求每个像素创建 Python 对象。重复传输、窗口重叠和 flow-matching 多次去噪均不增加新观测。数值相同的两次真实到达帧仍保持不同身份；去重不等于噪声独立。

一个局部结构的支持域至少包含：当前参考位置/坐标版本、来源成员、空间范围、时间分段、来源角色、噪声/对应风险类型及支持版本。空间组织不以亮度相近或连通性替代结构一致性；使用 P1 局部常数/仿射结构参考，在实际映射坐标上评估残差、秩和有效性。CFA 分支保持相位；三通道分支按实际共址测量建模。

必须区分：持续相容、对应不确定、短时测量异常、持续结构改变、缺失/坏点/饱和。速度不是撤回阈值：快而能准确对齐应继续利用，慢而结构已变应修订。不可观测时允许保留不确定性，不强制解释成变化。

4.3 实际执行的支持规则

空间候选由明确的局部邻接/多尺度区域产生，按同一结构参数和共同查询位置检验域级相容；只因 A-B 与 B-C 分别相似，不能沿链合并 A-C。时间候选采用 BOCPD 与鲁棒 BOCPD 的成熟规则/作者实现作参考，沿对应轨迹判断持续性；阈值、hazard、空间尺度和结构容差在真实开发/校准数据上确定。

同一个完整前向中，登记新观测、估计对应、更新持续/异常/变化假设、提出合并/分裂、确定来源集合、重建受影响结果并提交。接纳、暂缓、拒绝三态应有实际作用；一次大残差不无差别清空历史。不存在成熟收益依据时，不额外训练一个小型支持预测网络。

默认先采用来源特征通路：每个来源独立编码，再按支持和映射进入成熟融合。支持掩码必须在实际内容、权重预测、归一化及后续依赖中落实。仅把最终 softmax 某项置零，不能证明卷积感受野、基准特征或缓存中已无该来源。必要时对受影响来源/区域连同感受野重编码；第一版允许整窗重算，不要求局部优化。原先额外“积分内容节点”保留为历史候选，不作为首版默认必需分支。

支持判断的 GLS/结构残差应实际参与主链选择；解析参考仍用于独立核对，不以只在参考程序成立的性质代替神经主链证据。学习融合权重不解释成测量精度，特征方差代理不解释成物理后验。

4.4 两种撤回与记忆角色

结构支持撤回是来源不再支持当前结构。例如杯子旧位置退出当前几何估计，但“曾看见杯子”或“已完成一步任务”的上下文事件可以保留，须明确角色。保留这类依赖时，不能宣称整个输出完全不依赖该来源。

完整来源删除用于更强反事实：该来源内容及全部派生依赖从输入移除，重新计算运动、支持决策、特征、状态和读出。上下文分支也必须包含在删除闭包中；不能通过任何旁路读回旧内容。

对应两种评测：固定已选规则的内容干预，与删除后全部决策重放。前者允许“曾发生撤回”的事件留下，后者与指定的删除后序列参考比较。不能把二者混成一个撤回成功字段。

4.5 有界状态、期限与流式服务

首版完整规格为每 episode/camera 最多 32 个唯一到达帧的精确 RAW 回放记忆，以实际到达观测为单位。自适应支持在该范围内选择；明确报告保留帧数、实际使用历史、状态时间和计算成本。更旧内容不作为可精确撤回的隐含数值摘要。精确范围以外的历史丢失单独声明，32 帧不等于无限长记忆。

默认从保留 RAW 完整重建，时间分段/BOCPD 的数值状态也从同一窗口的固定初始化重放，不在旁路保留更旧的数值后验；特征缓存不跨优化参数版本复用。以后引入 Mamba/压缩状态，需同时处理卷积与 SSM 等全部状态，并从不含被删来源的起点回放；继承污染状态只重放最近 32 帧不构成精确删除。

完整模型训练和服务均支持 episode reset、相机缺失、重复请求与同帧多次策略读出。窗口内批量参考与流式执行具有同一到达历史和参数版本。先保证一致，再基于实测采用缓存或局部执行。

读出只访问同一版本的已提交快照。期限到达时返回已完成且标明测量时刻的合法状态，或按预定义规则使用当前有效测量通路；全无效状态交给显式失效处理。过时状态和回退比例进入行为评估，不能用“合法快照”掩盖响应滞后。p95/p99 是经验 SLO，不是硬实时保证。重规划频率、动作块中断和额外曝光若改变，应另建所有方法共享的控制协议。

6. 理论：主链命题、适用条件与创新证据

6.1 三项主要理论任务

理论与完整实现共同推进，不单设一系列脱离任务的数值阶段。每个命题交付定义、假设、推导/证明、直接反例及主链算子映射；“待证明”与“证明成立”分列。已有 T1—T6 文件保留为 P0/P1 历史参考，后续编号按下表迁移，不抹去其适用边界。

v1.1 理论任务 实际要求 对应旧义务
G1 来源删除与重建一致性 对明确的两种撤回语义，覆盖实际运动、卷积、融合权重、归一化、状态和读出依赖；给出与批量参考一致的条件 T1、T5
G2 积累收益、陈旧偏差与响应代价 从可解释测量模型出发分析取舍，明确新增支持规则控制哪项误差，分析自适应选择后的适用条件 T2；需要递归时补 T4
G3 顺序支持判断的错误控制 若声称统计保证，实际构造合法检验/置信序列，处理区域/候选选择和重启预算，并对应主链分支 T3；停止规则涉及 T6

原子提交、因果性、来源幂等及有界状态是实现必须维持的性质；它们单独不构成新的理论贡献。新增设计的理论价值还需要 G2/G3 对真实支持规则的分析及与最近邻的差异，不以经典公式换名交付。

6.2 G1：实际神经链路中的删除一致性

把完整有限窗口计算表示为确定算子图。参数、模式、随机输入与数值约定固定时，若来源及受影响版本的全部后继依赖被重建，则其结果应等于从相应保留输入重算的参考。证明按完整依赖图归纳，重点在于本实现是否满足前提。

固定决策模式保持映射/支持决策不变，清除内容依赖；完整反事实模式还要重算选择、对应和初始化。一个支持边退出与整个来源消失是不同输入问题。对齐网络、跨域感受野、reference/consensus、权重归一化、神经缓存和上下文均在审计范围内。

浮点实现按事先测定的精度容差比较；允许数值容差不允许遗漏依赖。逐来源内容置换、全源删除、跨边界传播及故意漏删依赖都要能揭示错误。策略干预固定 flow-matching/采样随机性；“动作变化小”不自动证明删除成功，也可能是后端根本没利用视觉。

6.3 G2：积累与滞后的可解释分析

对已固定对应、支持和权重的标量结构方向，设 y_i=z_i+ε_i、噪声零均值、联合 covariance 为 Σ，且 Σ_i w_i=1。可引用/推导：

ẑ_t = Σ_i w_i y_i
Bias_t = Σ_i w_i (z_i − z_t)
E[(ẑ_t − z_t)²] = Bias_t² + wᵀΣw

前项表示错配或陈旧结构引入的偏差，后项表示融合噪声。若固定映射后的结构漂移满足 |z_i−z_t|≤v·age_i、w_i≥0，则 |Bias_t|≤v·Σ_i w_i age_i。这里的 v 是对齐后仍存在的结构漂移界，不是像素速度；快且对齐准确的运动可以有很小偏差，慢速结构改变也可能有大偏差。

这只是条件明确的分析起点，不是对自适应网络的已完成保证。主模型用同一带噪观测选择支持/flow/权重时，不能忽略选择偏差与额外交叉项，detach 不解决统计依赖。P3 需要对所用规则给出联合/同时有效的界、可预测选择构造或明确限制；对未知关联、插值、共享噪声和饱和不能沿用独立噪声的 1/n 方差下降。

向非线性特征或动作推广时，说明所需的有界性/Lipschitz 等条件以及常数是否可用；不得从上述标量公式直接推出动作误差界或任务成功保证。不能得到主链定量界的部分如实保留为经验机制，不能用解析支路的正确掩盖理论缺口。

6.4 G3：连续选择的保证不能由校准字段代替

对每个有效支持零假设，如果实际统计过程 E_(d,t) 是合法 e-process，则以 1/α_d 为阈值可控制该检验全程越界概率。多区域/多次新建与重启的预算须在测试前或以合法可预测方式分配，满足 Σ_d α_d≤α_total，才可给出对应整体界。[R18]

候选、运动、下注参数和待检验残差复用同一测量时，需要合法的条件构造或重新推导。独立校准集可以估计经验风险，但不自动验证在线条件假设。BOCPD 后验、鲁棒性证明、e-process 的越界概率界与 e-detector 的平均误报间隔不是同一个保证；必须按各自定理写明。[R16–R19]

默认鲁棒变化模型可承担经验支持判断，但主链尚未满足统计条件时，不标为 G3 已证明。若严格支路与主链算子不同，其保证只属于该支路。无法提供条件内保证时，应交付失败条件和经验覆盖，而不是另设永远停留在夹具上的“有保证示例”。

6.5 与完整任务的共同判断

G1 对应“删掉之后是否真消失”，G2/G3 对应“何时该保留或撤回”，闭环回答“这样做是否帮助行动”。三者分别形成证据；有限观测下无法区分的世界，不承诺有限帧内必然检测。理论任务未完成可以形成有边界的工程/经验结论，不能宣布理论研究目标完成或默认机制已优于近邻。

7.2 热图与误差图的语义

现有 DBSR MaskedDbsrFusion 输出 [B,T,C,H,W] 的真实融合权重，可以按预先固定的通道聚合方式绘制逐来源空间图；这表示平均融合权重，不是后验概率或严格因果贡献。通道 attention、空间 attention、支持概率、风险分数和扰动影响分别标注；Burstormer 等模块中的通道 attention 不直接伪装成像素重要性图。[R04、R29–R30]

预览使用配对 RGB 镜像或相同固定 tone mapping，仅供人看；不同方法不各自调亮、独立归一化色标或挑不同帧。warp 残差不冒充有真值 flow error；没有深度/几何标注时不画所谓真值几何。动作仅在坐标/单位和运动学已验证时转换成可投影轨迹，否则按原动作维度展示。

冻结模型来源干预与匹配重训消融分开。固定随机性后报告逐来源影响的分布，包含低权重但高影响、以及删源后无变化的情况。注意力图与干预一致才支持相应解释，不把热图好看当作性能好。

7.3 报告顺序

主要报告先展示同步案例，再给整体/分条件成功率、事件恢复和总时延，随后解释支持与来源干预；代码/配置/数据 hash、检查命令和原始日志放附录。每张图可追溯到方法、checkpoint、episode/camera/frame 与生成配置。大视频、数组和权重留 ignored 输出或服务器，小型索引、选例规则、图表摘要和结论进入版本管理。

8. 完整训练与“充分”的操作定义

8.1 训练对象与初始化

训练完整的 RAW encoder → bridge → π0.5 通路，以真实动作监督为主。先检验模型能利用视觉和历史、真实小训练集可拟合、各参数组确有梯度/更新，再进入正式矩阵。这些是短开发诊断，不形成独立架构阶段。

RawVLA 的共同 2,000-step 配方保留预训练视觉和动作骨干，主要训练 ISP；N01 替换视觉塔后需要学习后端可用表征，不能把这个步数继承为充分训练证明。[R25] 同样，原合成定位/运动任务的平台不等于动作训练平台。

完整模型从第一轮正式主体训练即存在。内部先冻结后端训练桥/编码器，再按预定方案开放相同后端范围；各匹配方法有相同初始化、解冻机会和超参搜索预算。是否采用已验证 RAW 权重、从头学习或合法 RAW 预训练，在核心矩阵前锁定并计入成本。无合规表征初始化时，应正面增加 RAW/任务训练，不能隐含依赖 RGB 恢复或教师补回视觉能力。

8.2 配方、数据覆盖与预算

采用所选作者模块的完整训练结构和可追溯优化经验，针对真实多视角、分辨率与序列进行 profiling。默认完整回放范围为 32 帧；允许梯度累计、checkpointing、分相机/帧分块计算来适应显存，但不能只实际消费 8 帧却宣称验证了 32 帧模型。历史长度、RAW 到达节奏与动作 endpoint 节奏分别记录，验证训练与服务一致。

资源估算可沿用 v1.0 的每平台/种子 30k—100k 动作 updates 作为待 profiling 的初始容量规划，它不是硬停止点、作者默认配方或充分性保证。运动适配的预算由真实分布覆盖和完整任务表现决定，不再默认消费原 100k—300k 合成预算。P3 核心矩阵前固定有效 batch、样本采样/平衡、最大预算、作者式 LR schedule、评估频率、实用差异与追加预算规则。

训练记录独立来源轨迹和窗口覆盖、各照明/运动/遮挡条件、优化步骤、真实 GPU 小时和数据吞吐。相同轨迹的多噪声样本、同帧多次 flow-matching 随机采样和梯度累计不混作独立观测。可用充分训练所需的不同步数，但要同时交付同更新/样本/计算预算比较及各自充分优化后的能力比较。

8.3 充分训练的共同证据

  1. 优化和利用证据。 没有已知输入/归一化错误；真实训练集可拟合；编码器/桥/开放后端实际更新；遮住视觉或打乱历史能揭示模型是否利用它们。平台但欠拟合、只靠语言/状态完成任务不算视觉机制有效。
  2. 覆盖与验证证据。 使用独立验证轨迹，固定无增强的诊断样本、flow-matching 噪声/时刻及采样随机性，并跟踪动作误差与开发闭环。同时保留随机采样估计，不能以固定小样本代替全体验证。
  3. 延长训练证据。 完成选定成熟配方和有效降 LR 后，对核心方法按相同规则追加一个预定训练段，检查动作与开发闭环是否仍有实用改善；记录该段长度、斜率/区间、分条件变化和成本。仍在改善则续训或报告预算受限；不能因验证次数达到固定数字宣布充分。
  4. 种子与公平性证据。 按用户2026-10-15执行补充，项目初期每平台的N、B0、B1各训练1个种子，默认101，保留配对结果和失败；相同数据与训练机会，不只让候选获得更多后端容量。当前不要求211/307或三种子验收，后续多种子验证由用户另行安排。单种子不足以判断训练随机性稳定；按任务/episode得到的区间只描述该固定训练seed下的评测变化。

原 P2 的“最终低 LR 连续 8 次”等条款只作为原运行的历史验收标准，不回写旧结论；v1.1 充分性按上述完整任务证据及运行前固定的具体配方判断。达到平台不等于科学上证明最优，所有预算耗尽与仍改善的情况如实报告。

8.4 序列、辅助损失与恢复

动作 flow-matching 使用固定后端约定；语言、本体/动作维度与统计沿用各平台审计。RoboTwin 缓存的 joint target 不能不加说明地称为实测本体状态。辅助 RAW/几何目标须与可观测关系、实际数据字段和主链边界一致。不得以时间一致性损失强迫变化后的正确动作保持不变。

有状态训练记录 burn-in、完整 BPTT 或 TBPTT、状态 detach 边界和窗口采样；每次参数变化后从合法 RAW 重建相应状态。checkpoint 保存模型、优化器、scheduler、scaler、RNG、sampler 和实际源码/数据/校准版本。相同版本精确续训与更改配方的新运行分开，后者登记 parent，不覆盖旧收据。

9. 对照、整体指标与反证

9.1 聚焦的核心矩阵

方法 作用 主要比较
B0 成熟多帧融合 同一完整 DBSR、对应、历史、读出和后端训练机会，不含 N01 支持修订 N01 是否超出成熟融合已有的自适应能力
B1 成熟融合＋标准变化检测/reset 采用同来源检测信息和公平调参，明确局部/整窗 reset 粒度 新规则是否只是普通 reset 的复杂写法

核心确认性比较是 N 对 B0、B1。三者当前各完成1个训练种子的匹配训练与 P3 开发闭环（默认101）；N-minus 的冻结干预与匹配重训分别报告，预先固定主要消融，避免扩成大量零散矩阵。当前帧/固定平均只作解释性辅助，不能充当唯一强基线。

固定 Default/RawVLA 等保留原视觉塔的系统作为实用性能参照，分开解释架构、预训练和后端适配差异。N 对匹配 RAW 基线回答机制增量，N 对强系统回答实际竞争力；不能用其中一个替代另一个。

9.2 条件和主报告指标

必须覆盖静态弱信号、快而可对齐、运动/遮挡确实困难、慢但持续结构变化、当前单帧异常、缺失/饱和和重复观测；这些是要在真实基准中检验的条件，不保证每个自然轨迹已经有标签。自然案例、人工标注、可控干预与仿真真值分列。

主要结果为两平台任务成功率、照明/任务分层、动作变化后恢复、正常条件退化及端到端成本。动作误差、事件后前 1/2/4/8/16 个实际到达帧的响应、错误历史残留/来源干预、静态误撤回和支持年龄用于解释。没有相应真值时不报告伪造“正确支持率”。

恢复包括未恢复和删失，报告固定期限内恢复比例及受限恢复时间/误差面积；不只平均成功恢复者。时间同时标到达帧与实际墙钟。队列、传输、运动、支持、重算、读出、策略推理与动作提交全部纳入 p50/p95/p99、超期率、回退率和显存/状态成本，不能用单对 flow estimate 时延代替系统时延。

9.3 判断方式

在未消费正式测试前，以开发方差和应用精度固定最小实用差异、正常条件退化容限、事件定义与样本量/检验力。v1.0 的 5% 局部误差改善或 3 个百分点闭环目标保留为历史规划，不机械升级为新模型的通用 PASS 线。关键比较须有实用量级的配对效应，同时披露静态、异常和真实变化之间的代价，不能以一个加权总分盖过退化。

按完整 episode/任务/初态结构统计，纳入训练种子；不把高度相关帧当独立实验，多主比较按预定顺序或 Holm 等方法处理。若未形成实用增量，就报告完整负结果并区分规则、对应、优化/数据覆盖、后端表征和实现成本，不能把训练 loss 下降或热图合理写成机制有效。

10.2 v1.1 P4：冻结后的全量验证

P3 独立审查后固定代码、checkpoint 选择规则、每个种子的权重、输入/历史/状态协议、训练/校准数据、后端参数范围、控制节奏和完整清单，之后执行原 RawVLA-Bench 的 LIBERO 10,000＋RoboTwin 3,250 身份。附加 632 条原条件核查单列，不能加入 13,250 主分母。

核心 N 与 B0/B1 均按同一正式清单执行，每个训练种子独立完整覆盖。当前按1个训练种子执行：N与B0为 2×1×13,250=26,500 rollouts；含B1的三臂是 3×1×13,250=39,750，另计预注册的消融/强系统比较。按真实资源排期，不能把种子数混加成一个模型的分母。既有冻结系统结果只在协议/源码/输入身份一致时复用。

正常失败/超时计原分母；基础设施缺口按冻结规则恢复，不换种子或挑最好重跑。开发闭环与正式测试身份和输出分开，不用正式测试选择 checkpoint/阈值。测试后改变模型视为新研究迭代，披露已经消费的测试；不能继续称新版本的独立确认。

10.3 v1.1 P5：原生 RAW、跨域与扩展

根据 P3/P4 的已知限制选择扩展：真实传感器 CFA/跨会话、第二成熟骨干、两个下游读出、长记忆或局部计算优化。P5 不再用于补交 P3 缺失的主体网络、训练或行动接口；不把所有扩展强制串行塞进完成基准验证的前置。

真实 RAW 可参考 RViDeformer/CRVD 和多传感器挑战数据；保留显示屏重拍、静态/动态、噪声与许可边界。报告零样本与适配、冻结 probe 与公平 fine-tuning。32 帧之外的压缩/递归状态须重新证明删除范围与完整成本；第二骨干保持成熟规模。未完成 P5 时，结论限定于已测基准，不能宣称广泛原生 RAW 泛化。
