# 给DeepSeek：P5，集成机制与独有收益审计

读[共同契约](00_SHARED_CONTRACT.md)、P3/P4实际报告、原方案T3–T7及P5。你负责实现和产生可审计比较，不自行决定创新成立。主要扩展model/solver/provenance，新增`evaluation/n02_full/p5.py`与基线适配`baselines/n02_full/`。

## 1. 先固定N02相对标准算法的实际差异

同一Base/对象/生成模型、可用观测、提议集合与求解预算下，N02首版的被检验规则是：干扰解释后的局部预测不足触发结构提议；同一目标账本接受结构修订；支持失效引起来源一致的神经状态重建。B3采用标准SMC或开发集选定的成熟结构推断+精确来源缓存。两者都能结构搜索和重放，不能故意给B3只改权重的弱实现。

把差异写成实际函数/config差异表。触发机制若只相当于标准残差驱动proposal或Gen已有trace update，如实标注；不能通过更换模块名称制造创新。开始P5正式训练前，复查Gen、结构SMC、神经状态重算与真值维护的近期原始来源，保存相关工作差异表，交本聊天判断定位。

## 2. 按顺序建立六类强对照

1. 同一机制的全局重算参考，所有有效因子和历史均执行。
2. 标准SMC+精确J缓存，复用相同学得表示/提议，概率/近似模式匹配。
3. Gen结构搜索及trace update，枚举小系统先与P3对齐；复杂神经组件可采用固定预测结果输入做算法对照，披露这种边界。
4. iSAM2对可表达的连续因子子问题，用相同测量/噪声/初值/因子；它不负责实体发现，不能用其缺失离散功能作为失败分数。
5. 标准循环对象模型/SCALOR式发现；共享数据、监督与足够训练。
6. 固定候选已知依赖的普通事件缓存，继续保留旧负结果条件。

官方入口见[R11 GTSAM](02_REFERENCES.md#r11)、[R13 Gen](02_REFERENCES.md#r13)、[R28 particles](02_REFERENCES.md#r28)。每个外部运行时保存真实版本与命令。Julia/CPU与PyTorch/GPU时延不能直接归因于算法；分别报告原生实现时延、因子/网络调用工作量，以及尽量同硬件/同内核的比较。

## 3. 集成全局闭环后，再实现可选区域选择

先运行：predict/check→nuisance解释→结构proposal→完整目标接受→支持失效→重放→再求解→整世界读出。每个事件保存输入版本、触发原因、候选与拒绝代价。发生反复编辑时按同一目标δ下降和预算停止，保留best_seen及未解决歧义。

可选`RegionSelector`以局部残差、G关系分布和J影响摘要给出实体/因子子集。选择器只提议求解区域；实际J失效集合是正确性下限，不能少算已知失效节点。局部问题加入所有跨边界因子及固定外部变量的版本。逐轮计算边界残差，需要时扩张一跳；最多3轮后全局回退为起点，具体次数在开发集冻结。

ConvNeXt GRN和全局slot attention的依赖计全局；首版每个新帧完整编码，比较节约点限定在结构/因子求解及合法缓存。必须真的少调用网络/因子或减少solver变量；先全场算完再mask写回仅是状态策略，不记为局部计算提速。

T7只在已知强凸二次小问题上验证完整梯度范数与误差界；实际非凸模型报告完整目标差、残差和全局参考误差。没有m强凸证据就不输出ε/m证书。T4可选known-noise合成e-process，真实learned模型保持P1固定窗口经验误报；这些数值保证不越过其假设。

## 4. 训练与配对设计

P1–P4各seed自己的checkpoint续训，P5新增50k；共5个完全独立训练seed，其中新增2seed补齐上游。有效16×32序列，各组件lr起点1e-5，新RegionSelector1e-4；测量/对象/关系/提议损失沿冻结配置。selector目标可用全局解产生的有效影响区域，额外标签计算计入训练成本。

同输入/旧状态/RNG分叉比较，记录训练共享哪些模型；机制同表示比较优先冻结共同模型，只变推断规则。充分能力比较则各自同训练/调参预算。至少做：固定候选/随机/SCALOR/Gen/N02 proposal；只降权/全reset/精确重放/N02；oracle/学习/随机/全连G；局部有无边界校验；全局/精确缓存/区域学习。

开发集冻结强基线选择、行为阈值、延迟和内存预算；正式测试再运行。每序列统计恢复、漂移、发现、误撤回、漏检及端到端p50/p95。计时包含输入搬运/编码/提议/拒绝步/因子/求解/回滚/重放/缓存维护/读出，CUDA同步边界明确；单列墙钟与GPU事件测量。冷启动/稳态和总state bytes单列。

## 5. 两项准入，分别报告

机制准入：5seed至少4seed无关键行为退化，对同表示/训练预算最强成熟基线满足其一：恢复提升≥5个百分点且未受影响状态漂移不恶化；或恢复相差≤1个百分点且全链路p95下降≥20%。配对簇级95%区间支持方向，其他发现/误撤回指标同时报告，且不超P0系统预算。

局部执行准入：相对同机制全局/精确缓存，恢复不劣于1个百分点、漂移不恶化、p95下降≥20%，至少4/5seed一致并有区间支持。未过局部门槛时保留最好的全局/精确缓存版本；它是否值得继续看独立机制行为收益。

强基线更好或同等且更便宜时保留结果。充分训练后机制准入仍失败，交付“机制组合未成立”的证据；表示若有效可单列。不要自行删除基线或无限追加模块。

交付逐场景/seed配对记录、全部成本、强基线来源/runtime、全局与局部状态一致性、T3/T5及条件性T4/T6/T7实现表、模型和配置。P5结果是P6选择正式机制版本的依据。
