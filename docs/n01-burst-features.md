# N01：先复用成熟特征，再检验支持关系

本分支将 Deep Burst Super-Resolution（DBSR）的逐帧编码器和融合器作为独立强对照。N01 原有积分、唯一测量、支持图、合并/分裂及分裂后重算源码保持不变。当前新基线没有应用支持图，也没有宣称建立了 N01 的机制收益。

## 复用范围

上游为 [goutamgmb/deep-burst-sr](https://github.com/goutamgmb/deep-burst-sr/tree/16f158e0553b6702cc1693c43f733c2830973278)，固定提交 `16f158e0553b6702cc1693c43f733c2830973278`。保留作者配置规模：64 通道、9 个残差块、512 维逐位置特征，融合器投影 32 维、偏移分支 64 维。复用实际源码及其可训练层，不用小网络近似替代。文件与原始哈希见 [provenance.json](../src/owac/baselines/_vendor/dbsr/provenance.json)。

数据流为四平面 packed CFA RAW → 作者逐帧特征层 → 显式提供的对应关系 → 作者特征融合层 → 非图像特征。没有 RGB 恢复、RGB 教师或 RGB 超分辨率损失。仅调用 `ResEncoderWarpAlignnet` 的特征层，不调用其包含 RGB/PWC 对齐的整体 `forward`；未引入上游预训练权重。因此这是原模块的 RAW 任务适配与从头训练，并非复现整篇 DBSR 的图像结果。

`MaskedDbsrFusion` 保留上游全部权重预测层，只增加掩码计算：无效来源不参与平均或 softmax；全部缺失时输出零；当前参考缺失时使用有效来源的均值。全有效情况下，两种模式的输出、输入梯度和参数梯度均与原融合器一致。有效性是四 CFA 相位均有效的中心掩码；它不是覆盖整个卷积感受野的置信度。噪声方差没有作为融合权重，注意力权重也不具备测量精度或校准后验的含义。

上游许可为 **CC-BY-NC-SA-4.0**，另有仅限学术研究的使用声明；vendored 源码及其派生掩码融合实现保留这组限制。完整归属及变更说明见 [第三方声明](../THIRD_PARTY_NOTICES.md)。

## 接口和因果边界

实现见 [burst_features.py](../src/owac/baselines/burst_features.py)。

- `forward(values, valid, offsets_xy=None)`：`[B,T,4,H,W]`，最新帧在第 0 槽；调用方只能提供已经到达的帧。固定最多 8 个唯一来源。
- `offsets_xy`：`[B,T,2,H,W]`，以 packed 格点为单位，按照 `(column+dx,row+dy)` 拉取历史特征。当前帧偏移必须为零。正权重插值点全部有效且坐标未越界才可用。未提供对应关系即原坐标融合，不隐含估计运动。
- `step`：复用原 N01 测量缓冲的身份去重和时间边界，每次由 RAW 缓冲重算特征。要求显式 canonical RGGB `sample_xy`；不接收 `episode_ids`，调用方须在 episode 边界 `reset_state`，不同相机各自维护状态。
- 训练中的逐帧特征只在同一 optimizer step 内共享。编码器没有跨时间归一化，当前输出只取当前及过去特征；优化器更新后不保留旧权重生成的特征缓存。

目前仅验收四平面合成 CFA 与 CPU。三通道 RawVLA 接口、真实传感器、GPU、自动对齐与 VLA 闭环未验收。默认流式重算用于可追溯的对照，尚未做线上缓存优化或部署延迟测量。

## 五组配对对照

| 方法 | 特征融合 | 编码残差块 | 总参数，包含同一个定位头 |
| --- | --- | ---: | ---: |
| current | 只读当前帧 | 9 | 1,119,393 |
| mean | 有效历史固定平均 | 9 | 1,119,393 |
| mean_capacity | 有效历史固定平均 | 16 | 1,636,385 |
| dbsr_reference | 相对当前帧预测融合权重 | 9 | 1,653,953 |
| dbsr_consensus | 相对多帧均值预测融合权重 | 9 | 1,653,953 |

固定平均容量控制增加的是实际参与计算和训练的上游残差块，与融合模型参数量相差约 1.06%；它不是计算量完全相同的对照。所有组共用原定位头、数据流及可对应参数的初始化。这样可以区分历史特征、多帧学习融合和单纯增加容量的效果。

实验入口为 [n01_burst.py](../src/owac/evaluation/n01_burst.py)。沿用静态弱信号、准确对齐运动、遮挡解除和局部错误历史四个序列条件；逐帧记录误差、变化后前六帧误差、恢复延迟及未恢复数。准确对齐仅是显式标注的 oracle 正例，训练中按相同安排出现，选型与主均值排除该条件。合成数据不能替代真实 RAW 表征实验。

```bash
uv run --locked python -m owac.evaluation.n01_burst \
  --config configs/encoders/n01/burst_features_pilot.json \
  --output outputs/n01-dbsr-pilot-rerun
uv run --locked pytest -q tests/baselines
```

输出目录须为空；保存 best/last 模型、优化器、配置、逐步训练曲线和数据/源码哈希。检查点可恢复模型与优化器，CLI 暂不提供中断续跑命令。开发配置只评验证集，不消费正式测试集。[三种子 768 步配置](../configs/encoders/n01/burst_features.json)是后续受控预算方案，当前没有执行；它本身也不是充分收敛的保证。

下一阶段应先确认共享骨干的学习、训练预算和适当数据，再在同一融合器上比较关闭支持约束、静态支持约束、动态撤回并重算。当前图作用于原始测量，卷积特征含邻域内容；不能简单把图掩码乘在最终特征上就声称跨边缘的测量影响已消失。图约束进入特征形成或重算的位置，需要单独设计和来源隔离测试。新增收益须相对于成熟融合器和容量控制成立。
