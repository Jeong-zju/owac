# N04 全量开发方案：自运动预测与外部变化分离

**版本：v1.0 · 日期：2026-10-14 · 状态：开发方案，尚未实施。**

本方案以当前 N04 与作者 RKN 实验为起点，规定从数据协议、成熟网络、可分析的状态更新，到 π0.5 / RawVLA-Bench 全量训练和闭环验证的开发顺序。文中的训练预算、验收门槛与新增机制均为计划；已有数字单独标明。Markdown 是源文档，[HTML 阅读版](N04_full_development_v1.0.html)由同一正文生成。

## 1. 要解决的实际问题

机器人抬起手臂，腕部相机里的杯子向下移动。这不一定是杯子动了，可能只是相机动了。随后杯子被推动，即使画面也在整体移动，机器人仍应发现杯子相对桌面的位置发生了变化。若杯子被手臂遮住几帧，机器人需要依据最近确认的运动继续估计；再次看见杯子已经停下时，又必须迅速放弃旧速度。

N04 要建立的计算过程是：**先用实际发生的动作、本体状态和标定预测观测应该怎样变化，再用新测量修正没有被充分解释的部分，并让这次修正影响下一次预测和最终动作。**

这里有三个不同的问题：

1. **自运动解释**：哪些视觉变化可以由相机、机器人本体与已知成像条件解释？
2. **外部状态估计**：物体在哪里、怎样运动，有哪些量仍不确定？物体运动可以是可预测的，也可以由机器人接触引起。
3. **意外变化修订**：哪些新测量反驳了原有预测，需要修改位置、速度、接触模式或可见性？

“物体正在运动”不等于“当前预测出错”。一个持续匀速运动、已经被准确预测的杯子，运动分数应高，但创新残差可以很小。曝光变化也能产生大残差，却不一定需要改变物体速度。方案必须同时保留这两层语义，不能再次把运动存在、残差幅值和原因占比当成同一种分数。

预测不要求生成完整图像。首选输出是带坐标的局部几何、空间关系和连续潜在状态；RAW 域重投影只承担观测解释与诊断。最终成功标准是：**在同等视觉测量、可用信息及合理训练预算下，状态更可靠、错误先验修订更快，并在机器人任务中产生可重复的收益。**

## 4. 拟研究的新机制与可证伪主张

N04 的候选增量应集中在：**将测量支持、时空标定误差和外部动态修订放到同一个因果更新过程里，使系统既不会轻易把自运动误差认成物体事件，也不会因为残差大就把真实变化全部降权。**

三个研究假设分别验收，不以一个总分相互抵消：

| 假设 | 预期行为 | 最近对照与反证 |
| --- | --- | --- |
| H1：误差解释提高外部变化判断的特异性 | 时间 / 标定 / 增益扰动下少误报，在同等误报预算下保留真实外部变化 | Ac-RKN + 几何补偿 + 校准测量噪声；若新增规则仅把所有更新变小，H1 不成立 |
| H2：被确认的外部变化修订动态状态 | 停止、反向、接触切换后更快改变后续预测，同时保留遮挡收益 | Ac-RKN、自适应过程噪声 / 鲁棒更新；切断“事件 → 转移状态”路径应损害事件后的预测，否则新分支没有机制作用 |
| H3：这种修订改善物理决策 | 再次观测后更少追逐旧位置、更少误抓，在连续任务中提高成功率 | 同骨干、同动作输入、同后端训练预算的 Ac-RKN 与无记忆模型；只改善 RAW 重投影不算 H3 成立 |

动作条件网络、RAW 接入、几何 warp、协方差传播、nullspace 消元和变化检测各自都有前人。MCDS-VSS 也已组合了 ego / 外部运动补偿与特征更新。候选创新是针对**可辨识的外部变化如何修订因果运动记忆**形成的新更新规则及其证据，而不是模块拼装的名称。S0 和投稿前均需重新做最近文献检索；本方案不作“首次提出”承诺。若最近基线已经获得同样收益，应保留有效工程方案，撤回新增机制主张。

## 5. 目标计算架构

### 5.1 输入、状态与因果顺序

每次新观测到达时，执行以下流程：

```text
上次后验状态 + 上次曝光之后实际执行的动作序列
             + 已到达的本体测量 + 标定 / 时间模型
                       ↓
              predict_before_observe
                       ↓
几何位置 / 局部结构的当前先验 + 动态潜在状态 + 不确定性
                       ↓
当前 RAW → 独立当前帧测量 → 关联与有效支持 → 观测创新
                       ↓
         成像 / 运动误差解释 + 外部状态修订
                       ↓
当前后验状态 → π0.5 视觉前缀 → 动作块 → 实际执行日志
       └──────────────────→ 下一次预测
```

建议接口 `predict_before_observe(state, executed_interval, proprio_history, calibration, target_time)` 不接受当前图像或由它计算的光流。它可以使用预测时确已到达的本体信息。`measure(raw, sensor_metadata)` 只读取当前 RAW 和当帧传感器元数据，输出测量、噪声估计、有效性与坐标；不读取上一帧滤波状态。状态关联、投影、更新放在下一层，避免把已融合历史的特征再次当成独立新证据。

状态分为四部分：

- **几何与动力学状态**：局部三维点 / 表面锚点、位置与速度、机器人可见结构及其不确定性；物理量有明确坐标系和单位。
- **RKN 潜在状态**：每个局部支持的测量相关部分与记忆部分，初始采用 128 个锚点、256 维观测 / 512 维状态，参数共享。潜在变量不自动解释成物理量。
- **标定与成像量**：相机位姿 / 内外参、时间偏移、曝光 / 增益及其不确定性；固定标定和在线估计分别标记。
- **证据元数据**：最后真实观测时间、连续缺失时长、可见支持、关联置信度、measurement ID、reset / 失效原因。

锚点数是首版预算，不是理论常数。先比较单相机，再加入多相机；共享物体状态与相机特征间的相关性不能当成独立测量相乘。固定网格需进行几何运输；跟踪锚点需记录出生、遮挡、重新关联和消失，不能随帧换序后仍复用旧协方差。完整 RKN 的逐样本有效性需要显式扩展为逐锚点有效性，并单独检验；初版可把独立锚点展平为批次，但需披露空间相关性近似。

### 5.2 动作、本体与相机运动不能互相替代

动作告诉系统“控制器实际向机器人发了什么”，本体状态告诉系统“机器人实际上到了哪里”。受延迟、碰撞、柔顺和控制饱和影响，两者可能不同。相机运动优先由可用的本体状态、正运动学和外参计算；动作条件转移补充尚未观测到的控制区间和接触动力学，不能把同一次运动从动作与位姿重复叠加。

手臂在固定相机画面内运动属于机器人自身可见结构变化，不是相机 ego flow。它由运动学和机器人几何支持单独解释；机器人推动杯子产生的杯子运动仍是外部对象状态，可以被动作预测。无法判断接触关系时保留不确定性，不把“外部”强行定义成“与动作无因果关系”。

### 5.3 不让新增分支再次失去作用

外部修订量必须修改下一次传播所使用的位置 / 速度 / 接触模式或潜在转移状态。只把 change 附加到输出 token，或只训练事件分类但不进入状态转移，不满足本方案。

同时保留两个接口：`motion_presence` 表示外部对象是否运动；`prediction_mismatch` 表示新测量是否反驳预测。二者具有独立标签、分数校准与报告。不能在新数据集里静默更改旧版 event 的含义；旧权重显式标记 schema 版本。

### 5.4 首版修订规则：比较解释，再修改对应状态

首版不再用一个自由学习的 change gate 决定所有事情。对同一当前测量，先用共享的 Ac-RKN 预测构造三种解释：正常延续、外部动力学改变、时空 / 成像误差；无效或严重异常测量另外标记。正常延续允许物体按既有速度运动，不等同于静态背景。

三种解释共享当前视觉测量，区别限定在有物理含义的误差方向：

```text
延续解释：Q0，沿用已确认的动态状态
动态改变：Qdyn = Q0 + Bdyn Λdyn Bdynᵀ
误差解释：Ση,error = Ση,base + Δη

每种解释 j：rj, Sj → 观测似然 ℓj → 后验 (μj, Pj)
wj ∝ prior_mode_probability_j × ℓj
μ = Σj wj μj
P = Σj wj [Pj + (μj-μ)(μj-μ)ᵀ]
```

`Bdyn` 只作用于物理速度 / 接触动态和与其明确耦合的潜在方向；`Δη` 受可观测标定误差和时间先验约束，不允许把任意局部物体位移装进增益或相机误差。尚不能确定的解释保留混合或 unknown；初版不将混合均值当成唯一确定的动作目标。先做有单位的几何状态版本，再单独评估几何—潜在状态桥接；桥接参数同样记录来源、梯度与总预算。

这使用了多模型估计的成熟思路 [R29]，必须以标准模式切换 / 自适应 Q 为近邻对照。候选新增部分是：用 RAW 测量支持及标定 / 时间 Jacobian 限定各解释的可用方向，并让被支持的动态解释改变下一次 Ac-RKN 的状态。若只输出一个原因标签而不影响后续传播，该规则没有完成。

在各分量 Pj 半正定、wj 非负且和为 1 时，上式混合协方差仍半正定；额外项保留解释之间的分歧。它只是矩匹配，不能保证多峰分布被单 Gaussian 准确表示。S5 必须对混合被压成均值后出现错误中间位置的反例做验收；必要时保留有限模式分量，并计入计算成本。

### 5.5 训练目标与防止退化解

S1 使用当前帧几何 / 对应监督；S2–S3 使用多步状态与测量预测；S4 使用校准似然；S5 加入事件和修订后的预测；S7 才加入正式动作目标。统一损失表如下，权重在开发集固定，消融中共享选择预算：

| 项 | 计算对象 | 主要约束 |
| --- | --- | --- |
| `L_geometry` | 有效支持上的位置 / 深度 / 相对位姿 | 米、像素和旋转单独归一化；尺度监督只来自训练可用标签 |
| `L_predict` | 当前校正前 prior 与未来多步预测 | 缺失阶段不输入未来测量；只用目标计算损失 |
| `L_measurement_nll` | 同单位残差与协方差 | 包含 log determinant，不能只用残差除以方差；方差膨胀另用覆盖率与宽度检验 |
| `L_revision` | 首次新证据之后的动态状态和多步误差 | 不只优化事件分类；后续预测必须对动态修订可导且有干预响应 |
| `L_event` | 运动存在与预测失配两个独立标签 | 标签版本、可见支持、模糊区固定；不得用预测自身生成全部“真值” |
| `L_raw`，可选 | 合法支持上的 RAW 预测参考 | 噪声、曝光、遮挡、裁剪及插值正确；不做 RGB 重建 |
| `L_action` | 冻结协议的 π0.5 flow-matching 动作目标 | 动作规范化、padding、horizon 与作者一致；未来专家动作仅作监督 |

不以“特征间距离越小越好”单独训练所有模块，否则常数特征可能得到好损失。需要几何 / 动作监督、方差与支持审计，并报告 prior、posterior 和读出三层误差。由当前图像估计的方差可能与残差相关，拟合后的 NLL 仅是模型目标，仍需独立校准。

## 6. 坐标、时间与真实测量合同

### 6.1 坐标及几何传播

统一用 `T_A←B` 表示把 B 系坐标变到 A 系，W 是世界 / 局部参考系，C 是相机系。对上一帧的静态点：

```text
p_C(t-1) = depth × K(t-1)^(-1) × homogeneous(pixel)
p_C(t)   = T_C(t)←W × T_W←C(t-1) × p_C(t-1)
pixel_t  = project(K(t) × p_C(t))
```

独立物体运动在世界系或明确的物体局部系额外传播，再变到当前相机系。相机的前向点投影不是 `grid_sample` 的反向采样网格；遮挡、多对一、越界和负深度必须产生支持掩码。统一仓库 `align_corners=False` / zeros 约定，并将外部代码的 border / True 约定转换后验收，不能直接拼接。

记录原传感器、裁剪、缩放、CFA 平面、特征网格的每一层坐标变换。对于四平面 Bayer，平面像素 `(i,j)` 对应原始格点 `(2i+δy,2j+δx)`；R/G1/G2/B 不能共享一个忽略相位的坐标。裁剪缩放后用对应仿射变换更新 K，特征 stride 的中心偏移也要校验。保持单位明确：米、秒、弧度、原图像素、特征像素不能混用。

当前 `proprio.py` 使用 wxyz 四元数，并存在需要复核的“相对旋转表达式与 body-frame 注释”问题：在常用 world-from-body 约定下，`R_t R_prev^T` 与 `R_prev^T R_t` 表达的参考系不同。S0 通过已知旋转、复合和逆变换测试确定语义，不靠变量名猜测，不全局替换为另一种四元数顺序。

### 6.2 时间与动作合同

必须同时保存曝光开始 / 中点 / 结束、帧到达时间、本体采样时间、控制命令时间及实际执行区间。缺失字段用 availability 标识；帧号不是秒数，缺失动作不是零动作。滚动快门若存在，应记录行读出时间；首版不能准确建模时先限定全局快门实验，再单因素加入滚动快门。

当前 RawVLA 适配器的关键事实是：

| 数据路径 | 已有内容 | 不能直接假定的内容 |
| --- | --- | --- |
| LIBERO | agentview / wrist 三通道 uint8 pseudo-RAW，8 维机器人状态，7 维动作目标 | 未来动作标签不是当前已执行动作；末端位姿不等于完整关节状态 |
| RoboTwin | head / left / right 三通道 float32 HDR-derived RAW；当前代码把 `actions[t]` 当 14 维关节状态，后续序列作为目标 | 16 维 `robot_states` 是末端状态表示，不能替代关节角；采样对齐需逐字段核对 |
| 当前统一接口 | `executed_action=None`，多项物理时间 / 标定 / 曝光元数据尚不可用 | 不能仅把 target_actions 改名就声称动作条件化已经实现 |

S0 应核查作者原始缓存、仿真记录与控制器日志能否补齐。可通过**完全一致的仿真版本和轨迹重放**生成标定 / 时间 sidecar，但要验证观测、机器人轨迹和动作执行一一对应。重放漂移时不得强行挂接；生成新的扩展训练数据并单独命名。新闭环运行从执行器侧记录经过裁剪 / 限幅后真正下发的控制序列，未执行的动作块不进入预测历史。

迟到观测按曝光时刻更新历史缓存，再用已发生的控制重新传播到当前；报告真实输出时刻和可用信息。若使用固定延迟平滑，必须另报等待时延，不能把事后修正轨迹当作在线遮挡预测。在线和训练都以同一时间合同运行。

### 6.3 RAW 边界与测量独立性

RawVLA-Bench 的现成输入是三通道 pseudo-RAW / HDR-derived RAW，不等同于原生 Bayer CFA。[官方数据卡][R25]说明训练数据包含 1,771 条 LIBERO 和 632 条 RoboTwin 轨迹的 RAW / RGB 配对；测试通过另行仿真清单生成。实际文件与分母仍以本项目冻结清单核对。

项目保持两条明确的输入标签：`rawvla_rgb3` 服务官方 benchmark 可比性，`bayer_cfa` 服务原生采样机制实验。二者可以共享主干后的状态模块，但输入 stem、坐标和噪声模型分别实现、分别计分。原生 CFA 的合成实验不能宣称真实传感器验证；官方三通道闭环成绩不能宣称已经完成原生 Bayer 闭环验证。

主链不产生 RGB / sRGB / XYZ 中间图像，不使用 RGB 教师或 RGB 重建。只允许明确披露的黑电平、响应、曝光 / 增益、坏点、CFA 重排与 RAW 方差处理。每个新 measurement ID 只融合一次；π0.5 内部重复去噪不是获得新观测。

## 7. 可证明的性质、假设与不可保证的部分

本方案的“理论保证”分为可证明的局部性质和必须实验验证的系统主张。以下证明针对明确的模型假设；它们不能推出任意场景的分离正确、任意神经网络稳定或策略成功率必然提高。

### 7.1 带误差的观测模型

记 x 为希望估计的场景状态，η 为相机位姿、时间、内外参和增益等干扰量，y 为当前独立测量。在线性化点附近：

```text
r = y - h(μ⁻, η_hat) ≈ H e + Jη δη + ε
e = x - μ⁻,  Cov(e)=P⁻,  Cov(δη)=Ση,  Cov(ε)=R
C = Cov(e, δη)
S = H P⁻ Hᵀ + Jη Ση Jηᵀ + H C Jηᵀ + Jη Cᵀ Hᵀ + R
K = (P⁻ Hᵀ + C Jηᵀ) S^(-1)
```

相机姿态不准、曝光时刻偏差越大，相应预测残差的合理范围就应变宽。若状态与标定独立，可令 C=0；若它们由相同历史估计，必须使用联合状态 / 交叉协方差，或明确验证保守近似，不能默默假设独立。一个误差来源不能既进入 P 又重复加入 R。

这套模型用于有单位的几何 / 测量分支。神经潜在特征的 R 必须在自身单位下学习和校准；RAW 像素方差不能直接塞进任意非线性特征的协方差。

### 7.2 性质 A：协方差的半正定性

在线性预测 `P⁻ = A P Aᵀ + Q` 中，若 P、Q 半正定，则 P⁻ 半正定。联合状态的观测更新使用 Joseph 形式：

```text
P⁺ = (I - K H) P⁻ (I - K H)ᵀ + K R Kᵀ
```

在正确维度及半正定 R 下，任意给定 K 都保持代数上的半正定性。采用 Cholesky / 正值参数化、方差下界和 FP32 更新，辅以小维度 dense 参照，避免仅靠损失去“学会正定”。作者 RKN 的结构化协方差也需满足其交叉块约束；不能只对对角线做 softplus。

这保证的是数值结构，不保证估计方差等于真实误差。当增益依赖当前残差、采用关联筛选或非高斯门控时，不能把 Joseph 输出直接解释成精确 Bayesian 后验协方差。S4 必须另做经验覆盖率检查。

### 7.3 性质 B：对局部干扰的一阶不敏感性

对严格正定的基础残差噪声 R 做 `R = L Lᵀ`，令 `Jw = L⁻¹ Jη`。取 U 为 Jw 列空间的正交补基：

```text
Uᵀ Jw = 0
e_perp = Uᵀ L⁻¹ r
∂e_perp / ∂δη = 0        （当前线性化点的一阶项）
```

因此，该分量不会把可由局部标定 / 时间 / 增益扰动解释的一阶残差直接当成外部事件。这沿用估计中的 nuisance 消元原理 [R15]，并不是首次发明 nullspace 投影。

代价同样明确：若真实物体运动的观测方向也落在 Jw 的列空间，它也会被消去。设外部运动的测量 Jacobian 为 Jd，只有 `rank(Uᵀ L⁻¹ Jd)` 保留的方向能够由该分量检出。全画面只有一个平面、相机和物体以相同方式运动、深度不可确定等情形，可能根本不可辨识。系统应输出“解释不唯一”，借助其他视角或后续测量，而不是强行输出高置信原因。

主实现先采用有先验不确定性的**边缘化更新**，保留全部测量方向；硬投影作为后续独立对照，用于高不确定干扰下的事件证据。两者不能无审计叠加，也不能将同一残差先拟合校准再按未拟合的自由度计算显著性。大时间偏差、强旋转与滚动快门的高阶项不在该一阶保证内。

### 7.4 性质 C：缺失阶段能给出有限时域误差界

若传播 f 在考察区域有 Lipschitz 常数 L，模型和扰动误差每步上界为 b，则缺失 k 步后：

```text
||e_k|| ≤ L^k ||e_0|| + b Σ(i=0…k-1) L^i
```

这是有限时域的误差积累界，需要验证适用区域和噪声假设；不能假定所有物理系统 L<1。匀速位置积分本来就会积累速度误差，强制所有状态收缩可能破坏正确动力学。线性状态还需报告 A 的 k 次乘积与过程噪声累积。RKN 只在局部近似条件下使用这些诊断，不直接继承 IEKF 的特定稳定性定理 [R12]。

看不见期间、没有任何额外线索的随机停止 / 反向不可被保证提前预测。合理目标是扩大不确定性、保留多种可能，并在恢复测量后迅速修订。

### 7.5 性质 D：成像尺度与统计阈值必须一致

独立 Poisson–Gaussian 近似下，黑电平校正后的 RAW 方差可写为 `α × signal + β` [R17]。乘性增益 g 使方差乘以 g²；线性重采样 W 的完整协方差为 `W Σ Wᵀ`。只取独立输入的单点方差时才可写成权重平方求和，插值后的相邻像素一般相关。

若参考帧也有噪声，差分残差应同时计入当前与参考的不确定性，以及重复使用历史导致的相关性。饱和与裁剪破坏零均值 Gaussian 假设，应屏蔽或用截断似然，不能把饱和像素的低残差当高置信。

只有在模型正确、线性 Gaussian、自由度和选择过程明确时，标准化创新平方才能按 χ² 解释。实际特征采用独立开发集校准，在轨迹层面报告覆盖率、分组误报和可靠性；默认不承诺任意分布漂移下的统计覆盖。

### 7.6 理论交付要求

S0 写出坐标和生成模型，S4 交付每项性质的假设、推导、数值对照和反例。必须覆盖：关联错误、共享历史相关性、秩不足、物体运动与 nuisance 重合、强非线性和迟到测量。若这些条件不满足，报告适用范围缩小；不能用训练曲线补充缺失的证明，也不能用局部证明替代 H1–H3 的实验。

## 8. 分阶段实施：每次只改变一个因素

主顺序为 **S0 数据与理论合同 → S1 正式视觉测量 → S2 动态记忆 → S3 动作与自运动 → S4 测量误差与更新 → S5 外部运动修订 → S6 组合与迁移 → S7 π0.5 全量闭环**。阶段可以复用数据与训练设施，但验收时不同时更换观测、状态、损失和后端。

### S0：冻结可信数据、因果合同与诊断标准

**输入**：当前 checkout、既有合成器、RawVLA 原始缓存 / manifest / 部署记录。

**工作**：

1. 建立 episode / source-trajectory 分组，所有照明、噪声、裁剪变体归属于同一个拆分；固定训练、开发、最终留出清单。
2. 审计实际执行动作、时间戳、关节 / 末端状态、相机标定的可获得性，生成带 provenance 的 sidecar 或独立扩展数据集。
3. 写明第 6–7 节的单位、坐标、误差模型和可辨识反例；修正经测试确认的接口 / 注释不一致。
4. 以逐样本图像—标签对应、静态零残差、已知旋转、曝光缩放、控制延迟、隐藏测量 NaN 毒化、未来动作置乱检验数据与因果性。
5. 核对已有远端 supervisor、冻结权重及评测清单；本机历史记录不代表服务器当前进度，不能启动重复评测。

**训练**：无网络训练，仅标定与小规模数值诊断。

**出口**：数据字段覆盖表、不可用条件清单、split hashes、理论假设表及逐样本审计通过。若动作或标定无法可靠补齐，先建立新数据；此时不把普通视频 RKN 验收为动作条件 N04。

### S1：建立正式规模、独立当前帧的 RAW 测量

**唯一新增因素**：把诊断 tiny stem 替换为正式 ConvNeXt-B，输出多尺度特征、局部几何测量、方差和支持。状态模块暂不训练。

**训练**：使用 RAW-only 几何 / 对应监督和传感器域自监督；标签可来自训练仿真真值，输入不能包含真值。先训练单帧测量，固定后导出相同测量缓存。深度存在尺度歧义时使用可信多视角 / 运动尺度约束，不能在测试时借助真值尺度。随机初始化与任何公开预训练初始化分别建账。

**诊断**：真实测量误差对比“真值位置 / 深度测量”的诊断替换。若真值测量也不能改善任务，优先修正任务和读出；若差距主要来自测量，继续训练观测网络，不急于堆记忆。

**出口**：训练与开发学习曲线趋稳；测量缓存、权重、误差单位、方差可靠性可复现。建立同骨干无记忆基线，不要求大模型一定胜过易任务的小模型。

### S2：把 RKN 从二维探针扩展为实际空间状态

**唯一新增因素**：固定 S1 测量，接作者 RKN，不加动作新项、曝光修正或事件分支。先在相同已知坐标中验证状态，随后单独扩展局部缺失和多目标关联。

**训练 / 对照**：完整 RKN、同信息 GRU 和保持测量基线共享缓存；低维子任务沿用已有 KF 结果，并可在隔离环境复现强数值对照，不自动恢复 FilterPy stash。必要时采用合法可复用的鲁棒 / 多模式滤波作为诊断比较。

**真值诊断**：分别替换当前测量、最后可见速度和关联，不在隐藏阶段输入真值运动。通过状态重置、后半潜在状态清零、跨场景置换证明动态路径影响预测。

**出口**：既改善连续运动中的缺失误差，又量化停止 / 反向修订代价；若平滑收益伴随不可接受的修订退化，进入 S4 / S5 的问题清单，不能把 S2 写成完整机制通过。

### S3：依次接入实际动作、本体传播与标定几何

分成三个可独立回滚和评价的子阶段：

- **S3a**：普通 RKN → Ac-RKN。只增加过去已执行控制，保持相同视觉测量和状态规模；测试动作置乱、时间偏移、实际限幅与未执行计划替换。
- **S3b**：只增加本体 / 正运动学给出的相机位姿传播，保持 S3a 训练协议；固定相机与腕部相机分报。动作控制项只解释剩余未知动力学。
- **S3c**：加入深度或局部三维结构，使 ego 预测从二维补偿升级为三维投影；先用真值深度诊断，再训练正式深度模块。

**训练**：未来测量 / 几何状态预测损失、可见区似然及多步预测；未来数据只作为训练目标，不能作为在线输入。训练时随机丢帧与时间间隔变化使用物理时间。

**诊断阶梯**：估计 ego → 真值 ego → 真值 ego + 深度；每次只换一项，保持掩码、更新和读出一致。真实位姿改进很小则不训练大型 ego 网络；位姿来源足够好时优先保留解析几何。

**出口**：预测误差随可用运动信息改善；正确时间比错位动作更有用；纯相机运动不会凭空产生外部对象速度。若动作无增量，如实采用本体 / 几何有效部分，不能把 action token 存在当收益。

### S4：逐项建立可信残差和误差感知更新

固定 S3 的测量与转移，按以下顺序分别验收：

1. **S4a 成像解释**：可靠曝光 / 增益元数据 → 受约束的残余低频增益；先真值增益后估计增益。未知阴影和物体材质变化保留为未解释量，不让任意局部 gain 抹掉它们。
2. **S4b 传感器噪声**：只引入 α、β 与正确插值方差；先真值参数再训练 / 标定参数，分噪声组报告。
3. **S4c 几何与时间误差**：只加入位姿 / 时间 / 标定协方差传播；比较固定 R、仅学 R、显式传播、联合校准，避免只与劣质固定阈值比较。
4. **S4d 外部事件证据**：比较边缘化残差与一阶 nuisance 正交分量；增加不可辨识 / unknown 输出，并验收第 7 节理论性质及反例。

**训练**：先冻结测量与传播，仅标定噪声、必要的误差头和更新参数；每项通过后才做匹配重训。事件阈值固定在独立开发集的相同误报预算，不能按最终数据重新选。

**出口**：纯 ego / 光照 / 时间偏差误报降低，同时外部运动召回、位置更新和停止修订没有被一起压低。必须用“最强误差建模基线”证明新增事件判断的剩余增量。

### S5：让外部变化真正修改动态记忆

此阶段解决目前最明确的短板：持续运动先验会在停止和反向后拖住系统。

**S5a 诊断事件**：在当前可见时，分别使用真值事件标签、真值当前位置、真值当前速度，保持同一更新公式和协方差配置，测量每一项的空间。真值事件只告知“模型失配”，不能同时偷偷提供新速度。

**S5b 学习修订**：在 S4 可靠证据上修改动态状态 / 转移模式；优先使用 Ac-RKN 状态校正与成熟的模式切换 / 自适应过程噪声对照。新增头可读取局部残差、支持和协方差，但不能以无限增大 R 为唯一解法。外部变化可能需要增加 Q、修改速度均值或切换接触模式，单纯降低测量权重常常适得其反。

**S5c 条件运动网络**：只有当真值外部运动在困难三维 / 操作任务上带来实际状态或动作收益，才接入完整 Dynamo-Depth / RAFT 类模块。先在其原任务或可重建的作者条件下做最小忠实复现，再逐项适配 RAW、几何与因果时间。深度、ego、外部运动分阶段训练，避免不可辨识解相互补偿。

原二维实验的 0.02855 px 增量仍保留为未触发证据。新任务必须在读取最终测试前确定新的工程意义门槛，不能只因想训练大网络而放宽旧门槛。光流网络需要当前观测，所以它只负责当下校正；遮挡期间仍依赖最近确认的动态状态。

**出口**：事件后的预测和动作相关误差下降；切断“修订 → 下次传播”路径会显著损害结果；若只提升事件分类却不改变未来状态，S5 不通过。

### S6：组合训练、跨条件迁移与充分消融

**工作**：将已独立验证的部件组合，再进行端到端训练。按纯因素、两两组合、全组合分层采样；留出未见的因素组合、对象、速度 / 加速度范围、相机位姿和传感器噪声。

同时保留两种评价：

- **冻结权重干预**：同一模型内切断一条路径，检查实际依赖。它能回答机制有没有被使用，不能替代完整消融。
- **匹配重训消融**：无动作、无几何、无不确定性传播、无事件修订分别从同一初始化按同预算训练。它能回答新增机制是否优于充分训练的替代。

必要矩阵包括无记忆、原版 RKN、Ac-RKN、Ac-RKN + 几何 + 校准 R、Ac-RKN + 自适应 Q / 鲁棒更新、完整 N04。模型规模、可用上下文、训练轨迹、后端和调参次数分别列出。

另以 MCDS-VSS 的“ego + 残余流 + 特征融合”作为结构对照，逐项披露 RAW 和骨干适配；未获得作者源码时不冒称官方复现。若正式运动分支被启用，必须比较“残余运动一概用于补偿”与“区分误差来源后修订状态”，才能支持分离规则的增量。

**出口**：至少三个完整训练种子，主要收益的轨迹级配对区间支持预定方向；未出现“相机误报改善但外部事件几乎全被忽略”。各项局部收益与组合收益分报，未通过部件从主配置移除并保留负结果。

### S7：π0.5 / RawVLA-Bench 正式训练与闭环验收

S7a 是数据和动作梯度合同验收，S7b 是充分训练，S7c 才是最终闭环。不得把前者替代后者。

**S7a 接入**：复用 `rawvla_features.py` 的外部视觉前缀入口；保留语言、掩码、位置编码、动作规范化和作者任务配置。每相机 256 × 2048 前缀的容量保持一致，一次新观测只运行一次编码器，后续所有 flow-matching 去噪步复用它。冻结 π0.5 参数时仍保留经过后端回传到编码器的梯度，不套整个后端 `no_grad()`。

**S7b 训练**：分别在 LIBERO 和 RoboTwin 的正式训练轨迹上训练。先以冻结 π0.5 比较视觉和状态机制，再让全部主对照使用相同的后端适配方式和参数预算。若全量微调后端优于冻结 / adapter，再作为第二训练档，对所有主对照统一开放。不能让 N04 更新整个后端、基线只训练线性头后声称机制获胜。

LIBERO 外部动作 7 维 / horizon 10，RoboTwin 14 维 / horizon 50，以冻结配置再次核验；后端内部 32 维 padding 和 10 步去噪迭代不是实际执行 32 维动作或每 10 步才更新视觉。执行动作块长度、重规划间隔、采样频率和观测延迟均按实际值记录，不从 horizon 猜测。

**S7c 闭环**：使用被冻结的 10,000 条 LIBERO + 3,250 条 RoboTwin 主清单，另有 632 条原条件核查独立计分。开始前确认既有基线已补齐并审计；本方案不把历史部分 RoboTwin 结果算成完整成绩。基础设施异常保留身份和原分母，补跑成功前标记 incomplete，不能静默删除；策略达到步数上限记真实失败。

最少三个主要系统：同骨干无记忆、同骨干 Ac-RKN、完整 N04；各三个独立训练种子、每个 checkpoint 完整 13,250 条，合计 **119,250 次主清单 rollout**。若资源不足，先完成开发集预选；最终仍按预注册主对照补全，不把部分测试当全量。原版 RKN 与强误差建模基线至少在机制全量评测中保留；若 N04 的主张依赖其差异，也纳入最终闭环主对照。RawVLA 原系统是额外强系统基线，沿冻结协议复核，不能用未经同等训练的历史 smoke 作对照。

新增遮挡、延迟、错误先验、物体停止 / 反向属于独立的机制闭环套件，不能混入官方分母后继续使用官方成绩名称。可在同一初态做配对评测，但动作改变后的物理轨迹不能强求逐像素一致。

**最终出口**：完整成功 / 失败分母、三个训练种子的统计、全部成本、无未来信息证据和具身机制反证均齐备。π0.5 动作 loss 下降、离线动作误差改善或权重能加载，都不足以单独宣布 N04 完成。

## 9. 数据设计与诊断上限

### 9.1 从可辨识条件到真实难点

| 数据层 | 内容 | 主要用途与限制 |
| --- | --- | --- |
| D0 解析控制 | 静态、单轴平移 / 旋转、已知 K / 深度 / 曝光；无噪声和独立传感器噪声 | 验证坐标、方差和局部理论；不作大模型性能主证据 |
| D1 三维仿真机制 | 多物体、不同深度、相机 / 机械臂运动、遮挡、接触、物体停止和反向、阴影 / 高光 | 标签从生成过程导出，逐样本核对；包含可辨识和不可辨识反例 |
| D2 RAW 域与传感器变化 | 原生 CFA 采样、黑电平 / 噪声 / 曝光 / 裁剪；已测真实 RAW 可用时另建集合 | 标记模拟与真实传感器来源；不把重新马赛克的 RGB 当原始 RAW |
| D3 RawVLA-Bench 训练 | 官方三通道 RAW，补齐可靠 telemetry 的 sidecar 或独立扩展集 | 真值几何可作训练监督，不作普通测试输入；作者轨迹按 source 分组 |
| D4 官方 / 扩展闭环 | 正式测试 manifest；另建动态与延迟挑战 | 官方与新增任务分别计分，正确动作改变时重新示范 / 规划 |

训练至少覆盖：纯 ego、纯外部运动、纯增益、纯传感器噪声、静态、机器人自遮挡、对象出生 / 消失、错误关联、迟到帧、校准偏移，以及它们的组合。稳定的背景标定支持可能不存在，应专门加入整幅画面被移动物体占据的反例。

### 9.2 真值诊断只替换一个环节

| 替换项 | 其余保持不变 | 能定位的瓶颈 |
| --- | --- | --- |
| 当前真值测量 | 转移、Q/R、缺失、读出 | 当前视觉测量是否限制状态和任务 |
| 真值 ego / 时间 / 标定，各自单独替换 | 当前测量、外部动态、更新 | 自运动或同步误差是否值得建模 |
| 真值增益 / 噪声参数，各自替换 | 几何、标签、阈值预算 | 成像解释和噪声尺度的空间 |
| 当前可见时的真值事件 | 不提供新速度，不更换协方差 | 事件检测错误还是状态修订错误 |
| 最近可见时的真值外部速度 | 隐藏期间不读取真值；同一更新 | 动力学估计的额外任务空间 |
| 真值关联 / 可见性 | 不改变测量值或运动 | 数据关联 / 支持掩码是否才是瓶颈 |

这里的“上限”是**诊断参照**，不是自动严格高于所有学习方法的数学最优值。插值、噪声、估计偏差和其他模块失配都可能导致真值替换的指标更差，应保留这种排序并解释。

## 10. 充分训练与资源计划

充分训练由正式容量、数据覆盖、学习曲线和独立复验共同决定，不能再用 200 步 toy 训练承担机制否定或全量完成结论。以下是启动前要转成配置的**初始预算**，不是已经消耗的 GPU 时间，也不是论文保证。

| 阶段 | 初始正式预算 | 首版优化与数据要求 |
| --- | --- | --- |
| S1 当前测量 | 100k–300k 更新 | ConvNeXt-B，RAW 输入，独立帧与多视角监督；有效 batch 128 帧起，经显存测量调整 |
| S2 / S3 动态 | 每个主要对照 100k–300k 更新 | 有效 batch 16 段；先 16 帧 burn-in + 32 帧训练，再独立比较 64 / 128 帧跨度；物理 Δt 输入一致 |
| S4 校准 / 更新 | 每项 30k–100k 更新或估计收敛 | 固定测量和传播，分别训练噪声 / 修订参数；不在一次运行中一起更换四项因素 |
| S5 条件运动网络 | 通过诊断才安排 100k–300k 更新 | 参照作者完整配置并记录迁移差异；新增数据必须足够支持深度 / 动态分解 |
| S6 组合 | 100k–200k 更新 | 已确认部件联合训练，混合因素和独立留出组合；三完整种子 |
| S7 π0.5 | 每系统、每平台、每种子 100k 更新起，必要时延长至 200k+ | 相同动作规范化、数据访问、后端可训练参数和选择次数；完整记录 epoch 等效覆盖 |

采用 AdamW 及 warmup / cosine 等成熟训练配方，首轮开发集学习率网格为 `{1e-4, 3e-4, 1e-3}` 的编码器 / 新模块档；预训练后端采用单独较低学习率网格并对各系统一致开放。不是所有模块都使用同一学习率。梯度裁剪、混合精度、EMA 是否采用均在配置中冻结，协方差和几何校准优先 FP32。

每个正式档至少三完整种子；五种子用于关键差异小或方差较大的主张。开发集每 5k 更新评价，连续五次主要开发指标相对改善小于 1% 才作为趋稳证据，同时查看困难组和过拟合；最终测试不参与早停。若预算上限到达时仍明显改善，按预先规定扩展一档（如 ×2），或明确标为训练未充分，不能改口说机制已失败。避免以反复运行最终集来选择训练时长。

两张表分别报告“相同步数 / 数据 / 调参机会的受控比较”和“各方法充分调优后的能力比较”。视觉骨干相同不代表总计算相同，还要记录训练 FLOPs 或实测 GPU 小时、显存、数据吞吐与总参数。Dynamo 网络引入的额外成本不能隐去。

先进行 500–1,000 步正式形状的资源 profiling，测量单卡和多卡吞吐、序列缓存、通信与检查点大小；据此生成 GPU 小时预算和排期。当前本地 RTX 5090 的诊断速度不能外推成完整 π0.5 训练时长。可从 4–8 张 80GB 级 GPU 的资源档估算多模型训练，但这是待验证配置，不是已可用资源或采购要求；资源有限时用梯度累积 / checkpointing 保留正式容量。

## 11. 指标、统计与阶段门槛

### 11.1 统一指标语义

| 指标 | 必须固定的定义 |
| --- | --- |
| 几何预测误差 | 校正前 prior；米 / 原图 px / 特征 px 分报；静态背景与动态对象分别统计 |
| 当前状态误差 | 校正后 posterior；与 prior 不混用 |
| 外部运动存在 | 由对象相对参考系的运动标签定义，与是否预测准确无关 |
| 创新事件 | 由已有动力学是否被反驳定义；既有匀速运动可不是事件 |
| RAW 可观测变化 | 无噪声成像变化达到固定阈值的采样点，不等于整个运动物体掩码 |
| 修订延迟 | 从首次可用、有效的新证据开始计时，到误差连续回到容忍区间；未恢复记 censored |
| 缺失误差 | 按真实缺失时长分桶，报告误差随时间的曲线和面积，不只平均一个 gap |
| 不确定性 | NLL、分组覆盖率、预测区间宽度；有真值物理状态时另测 NEES，潜在状态不硬套物理 NEES |
| 任务收益 | 官方任务成功率、错误目标 / 误抓、恢复时间及控制代价；动作 loss 作为训练诊断 |

### 11.2 预注册的开发门槛

以下为 v1.0 建议的工程门槛。S0 根据坐标精度和任务容忍度冻结；若修改必须先记理由并重新冻结开发协议，不依据最终测试结果调门槛。

- **动态状态门**：旧二维数据沿用缺失误差至少降低 10% 且 0.05 px；新三维任务采用至少 10% 且超过标定 / 测量分辨率的绝对收益。可见段退化不得超过预设任务容忍度。
- **误差分离门**：相同开发误报预算（首版 1%）下，比较外部变化召回；在标定 / 时间扰动负样本上，新增规则较最强既有对照误报相对降低至少 20%，外部事件召回下降不超过 2 个百分点，并要求配对区间支持方向。每个关键组单列，不允许平均值掩盖失效组。
- **动态修订门**：停止 / 反向后的积分误差较 Ac-RKN 至少降低 15%，缺失期误差退化不超过 5%；修订延迟同时改善或不退化。用误导 / 过期状态验证，不只测试正确历史。
- **运动网络训练触发**：同更新、同掩码条件下的真值运动使主要状态 / 任务指标达到上述工程意义门槛；否则保留诊断，不启动大规模运动训练。
- **最终闭环门**：完整 N04 相对同骨干 Ac-RKN 的主要成功率差异用任务分层、初态配对的 95% 区间报告；目标为总体至少 +3 个百分点且区间下界大于 0，同时关键安全 / 控制组无超过预定容忍度的退化。若仅扩展挑战有收益，应将结论限定到该挑战，不宣称官方基准普遍更好。

所有主张分开判定。具有局部显著性但未达到工程意义阈值，报告“收益小”；区间过宽报告“证据不足”。不得把相邻帧、同一轨迹的照明变体或百万像素作为独立样本增加显著性。训练种子与环境随机性分别建账，bootstrap 以任务 / 源轨迹为分组单位，多个次要指标作探索性报告。

### 11.3 完整系统成本

记录曝光至动作下发的 p50 / p95、编码器 / 传播 / 读出 / π0.5 / 通信分项、状态显存、峰值显存、每个新观测的调用次数、控制频率、动作执行长度、迟到帧数量和恢复缓存开销。CUDA 计时需同步，warmup 单列；batch 吞吐不能冒充在线单帧延迟。若计算延迟改变机器人表现，另做等延迟对照。

## 13. 决策分支与失败后的处理

| 发现 | 下一步 |
| --- | --- |
| 真值测量有效，学习测量差 | 增加 S1 数据、覆盖或训练；不把问题归因于动态状态 |
| 真值运动也不改善任务 | 该任务没有足够机制空间；在新三维 / 遮挡任务上重新诊断，或保留简单状态模型 |
| 误报下降但真实变化也消失 | 检查 nuisance 与外部运动重叠、R 膨胀与门控；输出 unknown，减少无依据解释 |
| 事件识别对，后续预测不变 | 修复事件至转移的路径，做梯度和干预；不先扩事件分类网络 |
| 遮挡更好，重现后更慢 | 优先状态修订 / 模式变化；不要继续增大平滑强度 |
| 潜在 NLL 更好，物理状态不改善 | 检查方差膨胀、读出、关联和尺度；不要只优化 NLL 排名 |
| 几何 / 状态改善，π0.5 不获益 | 检查读出、信息是否被后端使用、动作对齐和动作相关性；以冻结 / 适配双档定位 |
| 仅算力更多时提升 | 报告充分能力与受控预算的差别；补做等成本对照，不归因为新机制 |
| Ac-RKN + 标准误差建模已达到相同表现 | 保留成熟方案，撤回无增量模块；创新主张需要重新定位 |
| 只有三通道 RawVLA 结果 | 可报告该 benchmark 的闭环结论，原生 CFA / 真实传感器结论继续留空 |

## 14. 实施优先级与 v1.0 完成定义

第一批工作集中在 S0–S2：补齐可信控制 / 时间 / 标定合同，建立正式视觉测量，再确认空间 RKN 在复杂连续状态上的收益。第二批 S3–S5 才引入自运动、误差解释和可改变未来预测的外部修订。第三批 S6–S7 完成充分训练、匹配消融和完整机器人闭环。

排期应以 S0 数据可得性和正式模型 profiling 为依据，不用 toy CPU 数字承诺几天完成。每个阶段结束写一页“已验证结果—剩余假设—下一项单因素实验”，进入下一阶段的依据必须是实际证据。

本路线达到“全量 N04 开发完成”需同时具备：

1. 成熟来源、正式规模的 RAW 测量与状态模型，充分训练、可重复加载和继续训练。
2. 实际执行动作、本体状态、标定、坐标和时间进入因果预测的可核查链条。
3. 有假设与反例的理论性质，以及 H1 / H2 的匹配实验和动态路径干预。
4. π0.5 在两个 RawVLA-Bench 平台的正式训练、完整闭环分母、强基线和成本比较。
5. 清楚区分得到收益的条件、未通过的主张及三通道 RAW / 原生 CFA / 真实传感器范围。

如果第 1–2 项完成而第 3–4 项没有收益，可以交付完整系统和负结果，但不能声称新机制成立。当前这份 v1.0 是上述工作的研究和开发合同，不提前写成验收通过。
