## 核心结构与训练依赖

```text
教师：同源因果 RAW burst／历史＋递归状态
              → RawVLA Neural ISP／已验证 RAW 前端 → 原 RGB 预处理
              → 当前策略的 SigLIP＋原投影 → 教师 tokens

学生：同源因果 RAW 观测／历史 → 校准与打包
              → RAW stem＋按效果选择的时序聚合／状态
              → 继承的 SigLIP blocks＋位置编码＋原投影 → 学生 tokens

两者 → 权重相同且冻结的 π0.5 语言／动作后端
部署 → 只保留学生，不加载 ISP、教师或教师缓存
```

从当前实际策略 checkpoint 继承视觉权重，不另外换一个通用 SigLIP。stem 直接产生 patch embeddings；教师和学生逐位置对应同一物理视野、裁剪、时刻和相机。真实 Bayer 打包与 benchmark 三通道 pseudo-RAW 分开，当前 benchmark 结果不能冒充原生 CFA 能力。

主教师对外必须接收 RAW，内部可经 Neural ISP 生成 RGB，再进入 SigLIP／VLA。优先保留有效教师的 burst／递归能力，学生不限定单帧，可选择因果聚合／状态以取得好效果。登记双方历史、stride、burn-in、reset 和成本；不同历史范围的比较披露信息差异，不把额外观测收益单独归因于蒸馏。教师需真实任务验证，RGB 输入策略不能静默替代。
