## 1. 目标、判断与当前起点

N02 要解决的问题是：**一个已经形成的场景解释，怎样在后续测量的约束下被保留、补充、替换或撤回，并改变后续动作。** 例如，系统最初把一段被遮挡的轮廓解释为一个物体；新观测说明那里其实有两个物体，原来的身份关联、接触关系和抓取目标随之失效。系统应能提出两个实体的解释，找出哪些判断使用了原来的错误关联，并重新推断这些判断。

这条路线有足够的学术基础，值得开展完整研究；但**成熟组件的组合本身不构成新机制，网络规模和训练时长也不能代替机制证据**。建议把研究主张集中为：测量支持的结构修订，如何与可追溯的神经状态、可检验的局部求解结合，从而比成熟的多假设推断与增量计算更可靠或更节省代价。最终是否成立，依赖新阶段的证据。

当前已经建立的基础与缺口如下。数字来自本分支的实验记录，不是外部论文性能。

| 现有证据 | 能支持什么 | 还不能支持什么 |
| --- | --- | --- |
| 重训 sbi CNN 加首帧 RAW 差分，三个种子留出配对均13/16、无信息均16/16；95%错先验纠正为10/5、5/5、11/8，各方向分母16 | 测量差异可以学习，原冻结 stem 不是充分入口 | 一般场景下的可靠观测模型、完全纠错 |
| 共用评分器、固定二候选、已知单跳依赖时，N02与事件缓存逐帧状态相同，N02约慢4% | 旧调度没有表现出独有收益 | 未知结构、多跳错误链和新候选发现的最终结论 |
| 新诊断中双亮点未被绝对拟合拒绝；末帧平移2像素，方向正确降至8/11/8（各16） | 当前评分对配准敏感，平均残差会漏掉局部结构不足 | “残差大就是语义反证”或“残差小就解释正确” |
| RAW序列 loader、唯一观测ID、候选读出、π0.5特征桥已有实现和历史连通性证据 | 可以复用工程接口和历史回归 | 新模型已经通过真实数据训练或机器人闭环 |

本地依据：[测量基线](../../research/experiments/2026-10-13_n02_retrained.md)、[调度对照](../../research/experiments/2026-10-13_n02_revision_comparison.md)、[反证边界](../../research/experiments/2026-10-13_n02_refutation_boundary.md)、[旧实现归档](../decisions/0014-n02-scheduler-archive.md)。旧模型与新模型分版本、分结果表，不能把后续新成绩回填为旧模型成功。

### 1.1 以目标为导向的路线决定（v1.1）

用户明确不要求保留某种分块形式或传播算子，以最终效果决定实现。本版选择**多尺度测量表示 + 对象级候选状态 + 显式约束与来源维护**作为首条开发主线。这个选择是工程与研究判断，尚无新实验能证明它优于分块状态；选择原因是当前核心任务包含实体出生、身份重关联、关系改写和替代支持，对这些变量进行显式操作更容易定义与验收。成熟对象模型提供实现起点 [R02](#r02)、[R04](#r04)，其原论文监督与数据条件仍须按正文处理。

不将上一轮讨论中的“先恢复完整分块循环，再叠加对象”作为必经顺序。它会在尚无收益证据时，同时引入网格隐状态和对象隐状态两套持续记忆，增加同步、归因和重建负担。也不将纯对象压缩天然更好作为前提：相同编码器的直接 RAW 特征策略基线从 P1 开始保留，P2/P6检查对象化是否损失动作相关细节。

| 决策 | 本轮确定的做法 | 由什么结果改变决定 |
| --- | --- | --- |
| 测量空间 | 保留带坐标、采样支持和有效性的多尺度特征网格；分块可用于测量定位与数值计算，不默认切成独立世界 | 局部证据遗漏、配准误判或跨块边界失真时调整尺度/支持域 |
| 循环状态 | 首选有来源的 SAVi 式对象状态，完整假设保存对象配置、关联和关系；不强制每个图像块再维护独立 GRU | 充分训练后对象表示仍持续损害细节或行为，暂停结构扩展，做一次有记录的表示重选 |
| 传播 | 区分预测消息传播与推断失效传播；前者服务状态估计，后者由实际输入依赖与版本决定 | 学习图不能覆盖实际依赖时扩大重建范围，不用预测边冒充完整来源 |
| 求解执行 | P2—P4首先全局求解/重建，P5再比较全局、精确缓存和学习区域选择 | 局部版本达到相同质量且真实成本下降才启用；否则使用全局/精确缓存版本 |
| 系统风险 | P1合格后立刻做一次π0.5小规模适配预检，P2末再检查对象读出 | 适配不通或细节损失明显时先定位接口/表示问题，不等到完整机制训练完才发现 |

初版继续贡献唯一测量账本、测量/推断支持分离、循环内不重复计数、绝对拟合检查、依赖方向和局部修订的反例测试，以及 RAW loader/策略桥。旧四邻域共享兼容表、旧小型 cell、全场计算后掩码写回不作为新版本必须保留的模块。此前固定候选、已知单跳条件的缓存等价结果只限定该实现与实验条件，既不证明对象方案更优，也不否定所有局部推断。

开发顺序固定为：**可靠测量 → 早期策略适配预检 → 全局对象推断 → 新结构发现 → 依赖学习与正确撤回 → 局部执行的增益检验 → 正式策略适配与全量闭环**。此顺序只有一条正式主线，不同时全面训练多个互不兼容的架构。定点对照用于回答具体问题。

三个结论分别验收：机器人任务效果、发现/依赖/撤回机制、局部计算效率。局部提速失败时允许保留有独立行为收益的全局机制；完整机制不优于共用表示的成熟强基线时归档机制；仅更强 RAW 表示有效时单独报告表示收益。不会把后两种结果重命名为“完整 N02 成立”。

检索截止于2026-10-13，围绕对象级循环表征、结构学习、粒子推断、能量求解、真值维护、序贯统计和RAW具身控制查阅论文、作者项目和源码入口。关键论文查看正文或方法说明；部分近期工作仅查摘要及作者公开材料，核对层级见参考文献和来源清单。以下是与方案直接相关的比较，完整链接见文末。

| 方法与来源 | 已有能力 | N02可复用的部分 | 不能直接继承的结论 |

| RJMCMC / SMC [R14](#r14)、[R15](#r15) | 变维模型搜索、序贯多假设推断 | 正确的提议概率、权重和接受规则 | 漏掉反向概率/Jacobian后不再继承后验正确性 |

| 序贯e-process / Robust BOCPD [R18](#r18)、[R19](#r19) | 合法条件下的持续检验、鲁棒变化检测 | 反证累积和变化检测基线 | 学习残差/BNRE logit并非天然e-value；场景变化也不等于语义归因 |

| DreamerV3 [R21](#r21) | 强循环随机状态和充分训练配方 | 非对象式RSSM对照、训练稳定性参考 | 本项目不同时叠加完整Dreamer策略与π0.5策略 |
| Invariant Slot Attention，ICML 2023 [R22](#r22) | 对象坐标系中的姿态等变归纳偏置 | 位移/尺度干扰与实体属性分离的对照 | 不能直接解决所有遮挡、噪声或身份错误 |
| Dyn-O 2025 / ObjectZero 2026 [R23](#r23)、[R24](#r24) | 近期对象世界模型与规划路线 | 更新相关工作和对象模型强度的参照 | Dyn-O使用Cosmos/SAM2先验，不能原样成为无RGB教师主方法 |
| RawVLA / π0.5 [R25](#r25)、[R26](#r26) | RAW成像适配、现成策略和操作基准 | 作者环境、数据、动作损失、闭环协议 | 原RawVLA输出RGB，N02替换视觉塔的比较必须另披露适配预算 |

**选型结论。** 主线保留多尺度测量特征，分阶段引入 ConvNeXt V2-Base、SAVi式对象循环、Theseus全局参考求解、多假设结构搜索与dNRI式关系提议。局部执行由P5实测决定，不将这些组件一次性全部叠加后才开始验证。Gen、iSAM2、SCALOR、标准SMC承担不可省略的强对照。DreamerV3、monDEQ和ISA作为定点对照，不在首版一次性堆入主链路。sbi NRE/BNRE保留为观测相对评分对照 [R27](#r27)。

## 3. 下一代N02的统一状态与计算过程

### 3.1 三项核心能力的操作定义

**发现未知解释**：正确结构起初不在活动候选集中，后续证据促使系统生成新实体、拆分/合并实体、改变身份关联或替换关系，而不是只对预置标签重新排序。“未知”限于模型定义的实体与关系组合空间；发现任意新物理定律、新概念不在本阶段的可保证范围。

**学习依赖**：从历史观测、已执行动作及可用训练监督中估计哪些实体状态能够预测另一个实体的变化，保留不确定关系候选。还要记录每条实际推断使用了哪些证据和假设。前者是学到的交互结构，后者是计算来源，两者不可混为一张注意力图。

**撤回错误推理链**：当某假设或测量解释失效，所有仅靠该支持成立的下游判断被标记失效并重新求解；仍有独立有效支持的判断继续保留。受污染的循环隐状态、边际化摘要和π0.5前缀缓存也必须回滚或重建。不能只把某个候选权重调低，仍继续使用由它生成的旧隐状态。

### 3.2 数据结构

| 状态 | 内容 | 生命周期和限制 |
| --- | --- | --- |
| 测量账本 M | episode/camera/frame/burst ID、原始值、时间、标定、噪声、有效性 | 同一ID只能提供一次统计证据；纠正标定产生版本，不复制观测 |
| 测量特征 X | 带相机/时间/空间坐标与采样支持的多尺度网格、有效掩码 | 是观测的派生表示，不额外贡献独立证据；区域可重叠，不能将重叠块似然直接相乘 |
| 实体集合 Z | 对象ID、存在概率、姿态/形状/属性、对象槽隐状态及协方差或分布参数 | 支持出生、暂时遮挡、重现、合并/拆分；ID不按槽下标永久绑定 |
| 世界候选 H | 每个候选的实体集合、关联、关系图、成像干扰参数、来源与权重 | 每个粒子是一套自洽解释；不逐实体独立拼接互相矛盾的MAP |
| 物理/预测图 G | 接触、共同运动、遮挡等关系的分布 | 可有环；主要是预测关系，因果主张另做干预验证 |
| 因子图 F | 测量、时序、约束和先验因子 | 可有环；以因子ID与测量账本关联，显式记录边界因子 |
| 推断来源图 J | 某版本结论使用的父假设、测量、模型版本和计算节点 | 按版本/迭代展开成DAG；记录替代支持集，不用G代替J |
| 缓存 C | 网络特征、局部解、边际化信息、策略前缀和动作chunk版本 | 每项缓存携带依赖版本；来源变化后不能静默复用 |

循环神经状态用于提出候选和预测下一状态，不承担“不可检查的唯一事实库”。事实的当前接受状态由候选、因子和来源记录共同定义。

### 3.3 主计算流

```text
RAW / 标定 / 已执行动作
        ↓
唯一测量账本 → 标准RAW编码器 → 循环实体预测与校正
        ↓                         ↓
RAW条件生成模型              多候选：实体、关联、关系
        ↓                         ↓
先检验曝光/噪声/配准等干扰能否解释残差
        ↓
候选内连续求解 → 独立预测检查 → 保留 / 暂缓 / 结构不足
                                              ↓
                         新实体、拆分/合并、关系改写提议
                                              ↓
                         同一数据上的受约束比较与接受
                                              ↓
                         撤回失效支持 → 重建受影响状态
                                              ↓
                    单个自洽候选的结构化读出 → π0.5
```

一次新观测可以触发多次计算，但这些计算始终针对同一个观测集合和同一版本目标。曝光或配准无法确定时，结果应为“不确定/模型不足”；不能自动宣布某条物体关系错误。

### 3.4 测量模型与目标

主模型直接预测传感器表示中的测量分布。Bayer数据输出四个有真实采样坐标的平面；RawVLA-Bench数据输出其作者定义的三通道伪RAW。两者分别建模、分别标定。网络不生成RGB/sRGB/XYZ中间图像供策略使用，也不通过RGB教师蒸馏 [本地RAW边界](../../AGENTS.md)。

在固定时间窗、模型版本和观测集合下，目标可写为：

```text
E(Z,G,η ; M) = Σ唯一测量因子 ℓraw(y | Z,G,η,c)
              + Σ时序因子 ℓdyn(Zt | Zt−1,at−1,G)
              + Σ有效物理约束 ψ(Z,G)
              − log p_initial(Z,G,η) 。
```

其中先验项只包含尚未计入时序因子的初始状态与结构/干扰先验，避免重复计算动态转移。η包含曝光、响应偏差、噪声尺度和相机运动等可解释干扰；c为已知标定。RAW似然要保留方差归一化项、相关噪声结构、量化/饱和的区间概率，不能任意截断残差后仍称严格似然。无法得到可信RAW生成密度时，相关目标明确称为经验能量，禁用其精确后验与误报保证。

共享首帧差分只是对照表示。它使不同时间的误差共享参考噪声，不能把各差分视为独立观测直接相乘。主线优先对原始帧条件建模；若采用差分，须显式使用联合协方差或条件创新。

绝对拟合与候选相对偏好分开输出：相对偏好回答哪个解释更好；绝对检查回答当前解释族能否说明局部测量。局部标准化残差、空间最大统计量和后验预测检查都要在独立校准集上定阈值，包含多区域和多次查看的误报控制。拟合与检验复用同一像素会产生乐观偏差；采用独立帧预测或有明确条件独立依据的测量划分，相关像素不能简单当独立样本。

### 3.5 结构提议、后验维护与撤回

结构提议采用有来源的SCALOR发现/传播与dNRI关系推断思想，加入残差区域和动作后观测作为输入。至少保留三类竞争解释：原结构加成像干扰、新实体/新关联、旧关系失效。对象增删必须同时付出存在性或复杂度先验代价，避免模型仅靠增加自由度降低训练拟合误差。

多假设参考算法采用标准SMC；变维动作先在可枚举小系统中用Gen或RJMCMC独立验证。任何学习提议都记录正向概率、反向概率和必要的变量变换Jacobian。若确定性拆分、top-k筛选或隐式神经提议无法计算这些量，主算法标为近似搜索，与概率正确的参考分开报告。不能以优化后的softmax能量直接冒充包含连续体积因素的模型后验。

同时维护两个输出：用于点估计的最好已见可行解，以及用于不确定性的样本/候选分布。点估计可执行单调接受；MCMC采样允许上坡以保持目标分布，二者不能混用同一个“只降能量”规则。

撤回依据J中的实际支持。物理图G只提供修订区域的提议，最终区域需要用边界因子残差或完整支持遍历核验。P2—P4允许对当前候选的全部状态重新求解或从检查点重放，以先确保撤回语义正确；只处理局部区域是P5的可选执行优化。模型参数在线更新会影响大量派生状态，首版推理时冻结参数；图/实体结构可以变，网络权重不在线自适应。

## 5. 理论保证：明确对象、假设、证明和失效条件

“有理论保证”应落到可检查的算法性质。本方案要求正式实现至少完成T1、T2、T3、T5的证明与程序对应验证；T4、T6、T7作为有条件的统计或近似性质。现有N02代码尚未满足下列全部要求。引用相关定理只是起点，必须逐条核查新算法是否满足假设。

### T1. 同一测量重复计算不增加证据

目标按唯一测量ID集合定义，而非按solver调用次数定义。对固定模型和静态状态问题，重复插入已有ID不改变目标函数及其定义的后验；在同一组候选状态上，能量与归一化权重也不变。推导只需集合并的幂等性。额外求解可改善近似解，重采样可改变经验粒子集合，这些计算变化不等于新增证据。动态状态可随真实时间预测，但重复帧本身仍不产生新似然因子。时序前缀评分只能整体替换，或采用严格条件增量，不能将重叠前缀似然反复相乘。

验证：重复帧、重试、断点恢复和多次内循环在固定候选上的目标/权重一致，并检查实际求解变化未重复加入因子；不同时间的新独立测量正常累积。该保证不依赖编码器训练是否成功。

### T2. 固定问题的接受步骤保持能量下降

对固定测量集合、固定参数、固定结构以及下界有限的连续目标E，学习网络只提出候选步d。若候选不满足充分下降条件，则回退到带回溯线搜索的梯度/近端步；最终接受必须满足：

```text
E(z_next) ≤ E(z) − c ||z_next − z||²，c > 0。
```

因此接受能量单调且收敛，步长平方和有限。**仅此不保证迭代点收敛或梯度趋零**；若进一步满足相对误差条件、局部Lipschitz、迭代有界和KL性质，可沿PALM类证明得到驻点收敛 [R16](#r16)。这些是新实现待核查的充分条件，不是默认事实。网络权重更新、新测量加入、离散结构改变后，必须重新开始对应的固定问题计数。

有限预算可能在尚未收敛时结束，输出最好已见可行解和剩余残差。每个结构编辑若都使同一复杂度惩罚后的目标下降至少δ>0，则一次固定问题的已接受编辑次数不超过 `(E0−Emin)/δ`；这只保证终止，不保证全局最优。采样模式不套用单调接受。

### T3. 可追溯撤回相当于对受影响计算重新执行

假设J完整记录确定性计算节点的所有输入依赖，节点版本固定，受影响子图按拓扑顺序重算；随机计算须把随机种子或随机选择也记为输入。这里必须区分结论是否仍有支持与缓存数值是否仍然有效：结论只有失去全部有效支持才被撤回，但任何实际输入或支持集合发生变化的数值缓存都须失效并重算。即使另一条证据还能支持同一结论，其置信度、来源集合或神经隐状态也可能变化。对拓扑序归纳，可证明重算结果等于用更新后的叶节点、有效支持、固定程序及相同随机输入从头执行；实际输入均未变的节点可以复用。控制流或结构发生变化时，相应子轨迹必须重新生成并登记，不能沿用旧图假装已经覆盖新路径。

这是**计算一致性**，不是世界事实正确性。如果神经全局注意力已经混合所有对象，实际依赖就可能是全局的；不能为了宣称局部性而漏记边。实体GRU历史、优化边际化因子和策略KV缓存均需纳入J。窗口外历史失效时，使用检查点加测量重放或重建摘要；不能直接从非线性隐状态“减去影响”。相关思想已有ATMS、Gen和增量求解基础 [R11](#r11)、[R12](#r12)、[R13](#r13)。

### T4. 有条件的序贯误撤回概率控制

在零假设H0下，若每一步非负检验因子e_t满足 `E[e_t | 历史] ≤ 1`，则 `E_t=Πe_t` 是非负超鞅；阈值 `1/α` 的任意时刻越界概率不超过α。该结论可用于“合法模型遭到错误拒绝”的控制 [R18](#r18)。多对象、多假设、多次重启要分配α预算或使用合法组合规则，不能每次从头免费使用5%。

适用的首个实现是已知条件测量模型的合成校准实验。学习生成模型、复合干扰参数和真实RAW通常不直接满足条件；必须有针对整个零假设族的合法构造，或明确退回固定窗口、独立校准的经验误报率。温度缩放、BNRE、把残差取指数都不能单独得到此保证。拒绝H0也只说明该模型族不足，不能自动定位哪条语义边错误。

### T5. SMC与变维搜索的概率账目正确

标准重要性权重包含目标增量与提议分布之比，重采样保留祖先和概率记录。RJMCMC结构编辑需要可逆映射、正反向选择概率及Jacobian [R14](#r14)。在目标/支持/可积性等条件成立时，采用相应SMC一致性或MCMC不变分布结论；有限粒子和有限时间仍有偏差、退化和模式遗漏风险。

先在可枚举的实体—关系系统上，对照真实后验、Gen和particles实现，核查边际概率、模式质量和采样误差。部署的近似剪枝/学习搜索若不满足条件，只保留数值与工程保证，不继承“精确Bayes”。

### T6. “发现新解释”的有限支持保证

若每次结构提议在给定历史下，以至少ε>0概率落入目标结构的某个可接受邻域，则m次都未提出它的概率至多为 `(1−ε)^m`。不必假设各次独立，但必须有统一条件概率下界。提议中可混入具有明确支持的基础分布，避免学习提议完全排除某类结构。

这只保证**提出**邻域候选的概率，不保证接受它、识别它为真实或覆盖模型空间之外的解释。连续高维情况下ε可能极小；本项目将通过枚举小系统和受控组合留出测量实际发现率，不把此弱保证包装成开放世界理解定理。

### T7. 局部求解误差的可验证边界

局部更新必须包含跨边界因子。若某个固定、可微、无约束连续子问题在包含当前解z与参考极小点z*的凸区域内m强凸，且该完整子问题满足 `∇E(z*)=0`、`||∇E(z)||≤ε`，则解误差可界为 `||z−z*|| ≤ ε/m`。有约束问题须另用投影梯度或KKT残差推导，不能直接套用此式；只检查选中局部坐标的梯度，也不足以得到相对全局解的界。一般非凸神经能量无此全局保证；在不满足条件时，报告完整目标差、梯度残差与全局求解对照，不报告不存在的误差证书。

研究方向是学习选择修订区域后，用廉价的边界残差检查判断是否需要扩张，直到满足停止标准或回退全局求解。该规则的代价也计入实际时延。若维护边界所需成本抵消局部收益，应接受全局算法更优的结果。

**必须明确不作的承诺：** 无条件发现任意未知解释；仅凭观测辨识真实因果图；非凸网络达到全局最优；无限时域无遗忘；上述数学性质直接推出π0.5任务成功率提高。理论保证须与其适用实验一起交付。

## 6. 创新假设与最接近方法的区分

建议只保留一个主机制主张和两项可拆分支撑，避免用模块数量代替贡献。

| 待验证设计 | 最近已有方法 | 真正需要证明的额外价值 | 决定性对照 |
| --- | --- | --- | --- |
| 主机制：以经干扰解释后的测量不足为触发，在同一概率/能量账本中做结构编辑、撤回和再求解 | Gen结构推断、SCALOR发现、ATMS支持维护、SMC | 同预算下更快找到可解释新证据的结构，同时更少误撤回 | 共用同一编码器、生成模型、提议集合的Gen/标准SMC+来源缓存 |
| 可选支撑A：学习修订区域，并用实际因子边界残差校验、扩张或回退 | iSAM2增量优化、普通缓存 | 未知/变化依赖下，达到相同解误差所需实际计算更低 | 全局求解、iSAM2、精确依赖缓存、去掉边界校验 |
| 支撑B：来源一致的神经状态重建 | 循环状态、计算图重算、真值维护 | 撤回后消除旧假设在循环/策略状态中的残留，保持独立支持 | 只改权重、清空全部历史、来源重放、没有循环状态 |

上述名称描述研究设计，不构成首创声明。阶段P5前必须做一次围绕Gen、神经符号真值维护、结构SMC和对象世界模型的补充检索；若新规则可直接归约为已有算法，仅保留其RAW/控制应用贡献并重新定位论文，不强行宣称新推断范式。

创新检验要比较完整强基线，不能只与旧85k模型或dense更新比较。若完整候选仅靠更大的编码器或更多训练提升，消融后应将收益归于表示学习；若只减少无关状态写入而无真实时延/能耗收益，就不能宣称计算效率提升。

## 7. 分阶段实现与验收

阶段从P0到P7推进。所有门槛是本方案提出的预注册目标，不是现有成绩或论文通用标准。P0可根据独立开发试验确定合理范围，随后冻结，不能看最终测试结果后降低门槛。每阶段至少交付代码、配置、数据/来源清单、模型、曲线、反例和中文结果记录；“完成实现”“通过数值性质”“通过行为”“通过闭环”分别标记。

### P0. 冻结新问题，复现成熟组件与建立数据约定

**实现。** 建立 `n02_full` 独立命名空间、来源锁与GPU运行时；复现ConvNeXt V2、SAVi/dNRI原算子，验证Theseus和Gen数值参考。整理RAW噪声/标定、首帧参考相关性、光照和相机位移处理。审计RawVLA训练数据/相机/动作/语言的实际可用字段及现有基线最新状态，不能把本地历史快照当远端当前状态。

**数据。** 冻结训练、调参、校准和最终测试四个分区，以场景/物体/采集轨迹分组；同一轨迹的不同照明和连续帧不得跨区。构建曝光、噪声、位移、遮挡、实体进入/离开、双实体合并误解和关系变化的受控任务。新数据使用全新种子和生成器版本，旧16场景只保留为回归。

**验收。** 原版与移植模块的FP32前向/梯度在预定容差内相符，固定batch短训练方向一致；真实NPZ输入及动作对齐审计通过；没有未来帧、隐藏标签或重复计数进入推断。交付完整参数量、200步吞吐/峰值显存画像。200步仅用于估算资源和工程验证。

**阶段决策。** 若公开代码依赖不兼容，先保留原环境参考，修复移植；不能用未经核验的小网络代替后直接扩训。

### P1. 建立足够强的RAW观测与绝对拟合模型

**实现。** ConvNeXt V2-Base在RAW域做掩码预训练，再训练相对评分、RAW条件预测和成像干扰推断。比较原始帧、显式条件创新、测量配准；采用多尺度局部预测检查而非全图均值。首版固定实体候选，暂不增加结构搜索。

**关键对照。** 相同Base编码器的NRE/BNRE、条件似然、标准判别评分；已知成像/几何oracle只作上界。所有学习方法使用相同RAW历史和训练监督。

**行为门槛。** 每类至少1000个独立场景，正式3种子：线索互换两侧正确≥90%；无信息条件中至少95%的序列后验漂移≤0.05；95%错先验在预定信息量条件下双方向纠正≥80%，且假设检验/已知模型上界表明确实可纠正；局部结构不足在≤5%正常误报下检出≥90%。每个噪声/位移/曝光组分别报告，不只给总平均。

**提前的系统预检。** P1行为合格后，在真实训练/开发分区上执行一次不超过2k更新的π0.5适配预检，使用同一Base RAW特征、读出和已冻结后端。核查实际动作loss、梯度、输入尺度、输出分布、episode reset和保存恢复；固定少量开发任务用于连通性与明显退化排查，不能查看正式P7测试集。此时对象/结构机制尚未接入，结果属于直接RAW特征基线。2k是排查接口风险的预算上限，不是充分适配或能力门槛；接口正常而短训收益不明显，仍按P6正式预算评估。P2末对对象读出做同协议预检，两次费用单列。

**决策。** 若评分失败，检查信息/表示/标定；若只有绝对检查失败，隔离修复预测和局部统计。完成充分训练判据后仍失败，则停止进入结构搜索，保留失败的能力边界。

### P2. 循环实体状态与候选内约束求解

**实现。** 接入SAVi式对象槽与几何辅助训练，分离成像干扰和实体状态；在固定实体数/固定关系的第一阶段，用Theseus全局求解每个候选内的连续变量，先建立可对照的完整重算结果，不加入学习区域调度。显式区分时间递推与同一时刻的推断迭代。建立T1、T2的证明、回归和拒绝日志。

**对照。** 共用Base编码器的直接测量特征读出、标准循环对象模型、固定迭代次数、纯优化、学习提议加接受/回退。对象状态是否有用与求解是否有用分别消融；完整网格循环仅在对象表示暴露明确瓶颈时作为定点对照，不同时建设第二条正式主线。加入已知输入位移与真正物体移动的成对任务；不能用配准把真实任务变化消除。

**验收。** 受控场景跟踪IDF1≥0.85、遮挡后重识别≥80%；相同观测多次循环不提升证据量；接受步能量上升次数为0；非收敛输出有残差与预算标志。学习循环相较同预算前馈须有可重复行为增益，否则保留求解基线并重新评估循环结构。对象化若持续损失局部测量或动作相关细节，在充分训练后暂停P3，针对表示做一次受控重选；不得仅因模块来自论文就强行保留。

### P3. 从固定标签走向新解释发现

**实现。** 粒子包含完整实体配置与身份关联；接入出生、消失、拆分、合并、关联重置。由学习网络提议，标准SMC/变维接受规则管理。先处理实体数量与身份，再处理复杂关系，避免一次改变全部自由度。

**任务。** 真实结构起初不在候选集合；新物体从遮挡后出现；两物体初始被误并；一个物体初始被误分；相似物体身份交换；噪声亮点不应生成实体；重新出现不应重复出生。训练与测试分开留出组合、数量和遮挡模式。

**验收。** 简单可枚举系统与精确后验一致到Monte Carlo误差；新结构发现率≥80%，虚假出生≤5%，正确拆分/合并≥80%；预算内发现延迟、模式覆盖、有效样本数与粒子灭绝率完整报告。初始候选中暗藏真结构的结果不计为“发现”。有限实体类型之外的输入应能暂缓，而非强行解释。

### P4. 学习变化依赖与可追溯推断链

**实现。** 接入dNRI关系分布；模型推断G，运行时记录实际J。构建至少3跳的推断链、多重独立支持、共享祖先、关系变化、遮挡和身份错配任务。让历史错误进入循环状态，再通过新证据撤回，检验污染是否消失。包括窗口外来源被撤回和边际化摘要失效的案例。先实现全局重放/重建得到可信参考，再实现依赖失效传播；预测消息传播与修订需求传播使用不同接口。此阶段要求正确撤回，不要求已经实现局部提速。

**训练。** 先在有真实结构的仿真中使用关系/身份监督，再降低监督比例并报告；以已执行动作和对照干预检验预测关系。最终RawVLA推断只使用观测、语言、本体和历史已执行动作。使用生成器真值的oracle边不作为学习结果。

**验收。** 在有可识别真实图的受控集合上关系F1≥0.85；多跳错误链撤回正确率≥90%，有独立有效支持的判断误撤回≤5%；确定性trace修订与全重算数值一致；无来源依据的假设不能被当作已测量事实。没有足够干预的数据只报告预测依赖，不报告真实因果恢复。

### P5. 集成机制、理论审计与可选局部执行

**实现。** 将结构提议、连续求解、反证检验与trace修订组成闭环。先冻结全局正确性参考，再对比精确依赖缓存、学习修订区域与边界扩张。证明并验证T3/T5，明确T4/T6/T7适用子集。局部方案要记录真实感受野、全局注意力和边界因子；全局归一化或注意力导致全局依赖时不能只靠掩码声明局部计算。提议失败、局部求解不收敛或支持记录不完整时，输出暂缓/全局重算，不产生伪确定结论。

**强对照。** 使用同一编码器、测量模型、候选提议预算，比较标准SMC+精确缓存、Gen结构搜索、全局能量求解、iSAM2适用子问题、对象循环模型与N02；固定候选诊断仍保留普通事件缓存。Gen/CPU与PyTorch/GPU原生运行时分别披露，算法工作量和同硬件主实现时延分开，不能用语言开销制造性能差距。

**机制准入。** 五个训练种子，至少四个在独立测试上无关键行为退化；相对共用表示与训练预算的成熟强基线，满足以下之一：错误链恢复提升≥5个百分点且未受影响状态漂移不恶化；或恢复性能相差≤1个百分点而全链路p95代价降低≥20%。配对置信区间支持方向，所有候选发现、误撤回与漏检指标一起报告。P0同时冻结可接受的决策延迟与内存上限；质量收益若超出系统预算，不直接进入部署。

**局部执行启用。** 它单独接受验收：相对机制相同的全局/精确缓存参考，恢复不劣于1个百分点、未受影响状态漂移不恶化，且端到端p95代价降低≥20%，至少4/5种子方向一致并有配对区间支持。计算成本包含特征、候选搜索、因子评估、拒绝步、回滚和内存维护。未通过则使用表现最好的全局/精确缓存执行，不宣称局部效率收益，也不为保留propagate继续加模块。

**退出规则。** 数据/预算充分且机制准入增益不成立，归档该机制组合，不通过删除强基线或再加一个模块维持结论。表示学习部分若有效，可以独立继续；总体路线仍需承认机制主张未成立。

### P6. π0.5离线接入与充分适配训练

**实现。** 复用现有[特征桥](../../src/owac/backends/rawvla_features.py)，绕过RGB图像塔，将一个自洽世界解释读成每相机256×2048 tokens。保留原语言/本体输入、归一化、flow-matching动作头、动作维度和时间对齐。训练和`sample_actions`共享同一入口；一个前缀在同一次去噪中只建一次。修订版本变化必须使相关prefix KV失效。

默认读出为整世界MAP，保留分布供诊断；若做多个候选的策略评估，每个候选独立调用策略，明确增加的成本。不同世界的tokens不能无掩码混合后仍声称保持多峰。动作平均也不能保证物理可行。

**两种训练轨道。** A：冻结π0.5语言/动作后端，所有RAW前端与读出获得相同动作监督；用于隔离前端贡献。B：共同适配预算，N02与强RAW视觉基线解冻同样的后端层或相同LoRA配置；用于充分能力比较。若A受特征分布不匹配限制，允许进入已预注册的B，不能为N02单独扩大后端预算。

**离线验收。** 实际NPZ完整训练批次、动作loss在声明可微的观测/实体/连续提议路径上产生有效梯度；离散提议按第8.2节单独核验训练信号；循环跨chunk状态、episode reset、重放和保存恢复通过。分别报告完整预测horizon与实际执行前缀误差、夹爪转换、低光/遮挡组误差、动作分布异常和机制保留。离线误差改善只是P7准入证据，不替代任务成功率。

### P7. RawVLA-Bench全量闭环与机制因果验证

**主评测。** 使用固定作者任务清单与本地协议：LIBERO 40任务×50初态×5照明域=10000条；RoboTwin 13任务×50dataset seeds×5域=3250条。训练集、开发闭环和正式测试完全分开；每个平台至少3个独立训练种子，每个正式方法原则上完成全部13250条，即每方法39750条。基础设施异常保持原身份与分母，未补齐标为incomplete。

**机制验证。** 原基准主要检验成像鲁棒性，不能单独证明未知结构与错误链撤回。另设清楚标注的扩展任务：错误初始身份/关系、遮挡后新实体、动作相关关系变化、独立支持的撤回。修改物理目标或动力学后重新生成专家/成功判据，不能机械沿用原动作标签。扩展分数与官方原协议分数分表。

**目标。** 相对同预算强前端基线，总体成功率提升目标≥3个百分点，配对95%区间下界>0；Normal域下降不超过2个百分点，低光和强光分别报告。无总体提升但机制有收益时，只报告限定任务结果，不能宣布全量优越。最终“完整N02成立”要求P3发现、P4撤回、P5独有增益和P7操作结果共同通过，不能由其中一项替代。

**最终交付。** 三种子模型、完整协议/版本、全部有效任务结果、失败身份、机制事件与动作轨迹、训练曲线、逐环节p50/p95时延/显存/状态字节、消融及论文主张—证据对应表。

## 8. 数据、损失和“充分训练”的判据

### 8.1 数据规模与监督来源

建议P1起建立至少100万张独立条件覆盖的RAW训练帧，P2—P5建立至少10万条16—64帧的受控训练序列。优先在既定LIBERO/RoboTwin环境和专用机制生成器中产生原始测量表示，不恢复已经终止的Arena/PolaRiS路线。生成器要变化对象形状、布局、相机、成像干扰、交互结构和先验错误，避免只对旧圆弧模板扩增噪声。

以上是首版建设目标，不声称当前已有这些资产。序列、独立场景、渲染帧、增广视图和重复训练曝光量分别计数；在线生成器记录种子、版本和资产清单。正式测试建议每机制类型1000个独立场景，校准集与开发集各至少5000条，困难条件分层配额事先固定。

RawVLA现有训练NPZ按实际盘点冻结，历史记录的2403条训练轨迹不是13250条闭环测试样本。P0先核查任务、源轨迹和重复照明版本，以约80/10/10分组划分训练/开发/校准；正式仿真测试初态及新增机制测试单独封存。若某任务数据不足，优先报告数据限制，不跨区借用相邻帧。额外生成的专家、深度或关系监督必须给所有可用该监督的机制对照同等访问。

无隐藏真值的正式推断输入只包括RAW、可用标定、本体状态、任务语言、历史已执行动作和声明先验。仿真器物体ID、深度、接触图可以作为训练标签或评价真值，但不可通过缓存、掩码、候选初始化或测试时solver偷偷进入主方法。无监督分解的可辨识性依赖归纳偏置和监督，不能承诺纯重建自然学出唯一语义 [R29](#r29)。

### 8.2 损失组织与优化

先完成RAW自监督预训练，再加入对象/关系/动态损失，最后接入动作监督。联合目标中的每个损失都记录实际激活样本、共享/专属分支梯度、范数和夹角。旧N02出现过背景拟合压制差异和几何—权重监督冲突，因此每个新增目标必须有单目标与联合目标对照。

- RAW预测：带已知/学习噪声的proper scoring目标，饱和和缺失使用相应观测模型；对共同背景与局部变化分别记录误差。
- 实体学习：来源明确的深度/几何/存在性/时序一致性目标；有标签和无标签结果分报。
- 提议学习：用小系统真实后验或高预算参考产生目标，记录其额外计算；防止只模仿当前单一MAP而丢失替代模式。
- 依赖学习：多步预测损失加稀疏/结构先验，另以干预和边删除检验依赖效用。NRI已指出单步预测可能靠惯性忽略交互边 [R05](#r05)；本项目比较1/5/10步预测与删边后的性能变化，不能只验收较低重建误差。
- 行为学习：保留原π0.5 flow-matching目标，同时维持测量与结构约束；不直接沿用ISP亮度/色度损失到非图像tokens。

离散结构搜索与可微训练分开规定。连续几何、噪声参数和读出使用重参数化或经过数值核验的求解器反传；SMC重采样、出生/拆分和硬接受不假装天然可微。首版离散提议使用可枚举/高预算参考后验的监督目标训练，并记录参考成本；若进一步使用score-function估计、连续松弛或straight-through，须分别报告方差、偏差及消融。训练时松弛梯度的性质不能用于宣称部署时粒子后验正确，也不能用一个非零代理梯度代替实际动作行为收益。

优化器以公开配方为起点，P0在开发集确定学习率/权重衰减。预训练可参考FCMAE调度；后续以AdamW、warmup、cosine、梯度裁剪为起点，具体数值进入冻结配置。若采用CAGrad等冲突处理，仅增加独立对照，不能掩盖错误任务定义。预测方差不能无限增大来回避拟合，噪声校准、方差统计和平均预测误差同时验收。

### 8.3 训练预算起点

下表是新实验的初始预算建议，**不是论文原配置、已经执行的训练或收敛保证**。达到行为门槛且曲线稳定可以停止；未充分覆盖数据不能只因达到步数就宣布失败。

| 阶段 | 优化更新/种子 | 全局有效batch与历史长度起点 | 种子与扩展 |
| --- | --- | --- | --- |
| P0 | 200—1000 | 正式架构的小batch | 工程和吞吐；不计行为结论 |
| P1 | 100k预训练 + 50k测量训练 | 256帧；测量阶段32条×8帧 | 3种子；训练数据≥20次等价曝光或明确记录不足 |
| P2 | 100k | 32条×16帧 | 3种子，循环展开先4再8次 |
| P3 | 100k | 32条×16帧，K=8世界候选 | 3种子；K=4/8/16做模式/成本曲线 |
| P4 | 100k | 16条×32帧，含多跳错误链 | 3种子；长历史64/128帧留出 |
| P5 | 50k联合训练 | 16条×32帧 | 确认阶段扩至5个完整训练种子 |
| P1后/P2末预检 | 各≤2k；不计能力验收 | 有效8个动作锚点，训练/开发分区 | 各1个工程seed；P2与P1使用匹配样本及初始化控制 |
| P6-A | 原预算2k参考 + 20k充分适配起点 | 有效8个动作锚点；因果历史按冻结协议 | 每平台3种子，强基线同样预算 |
| P6-B | 50k适配起点，上限预定100k | 有效64个动作锚点；跨GPU/累积实现 | 每平台3种子，同样后端解冻范围 |

按上述起点，P1—P5累计为每seed 500k次更新；五个完全独立的确认seed合计2.5M次更新，尚未包括强基线、调参和π0.5适配。各阶段每步成本不同，必须用P0实测分别累计资源，不能把这些更新都按图像预训练的吞吐估算。

每个阶段从同seed上一阶段检查点续训，阶段新增步数与累计步数均记录；P5新增两个确认seed须补齐上游训练，不能只把同一预训练模型换两个末端随机种子称五个独立训练。早期可共享预训练做消融节约成本，但主表标注“共享预训练条件下的seed”，另保留完整独立确认。

RawVLA论文的仿真ISP比较是2000步、A100 80GB、microbatch1、累积8，采用冻结策略；这只是参考协议 [R25](#r25)。其历史采样、输入路径和视觉塔保留方式与N02不同。本文20k/50k训练是充分适配轨道，不能与论文2k数字直接宣称公平胜出；同时提供受控更新数、样本曝光量、训练GPU小时和可训练参数的比较。

**充分训练须同时检查五件事：** 训练数据有效覆盖；至少三个种子的完整行为曲线；梯度和优化健康；合理学习率/训练时长敏感性；开发行为与校准是否趋稳。每5000步做固定开发评测，在至少三个检查点窗口观察趋势。如果损失下降而行为无改善，立即开展因果诊断；若行为持续改善且未过拟合，可按预注册上限延长至2倍预算。最终留出不用于决定延长、调阈值或换配置。

达到最大预算但仍在稳定改善时，结论为“尚未收敛、资源受限”，不把它写成机制无效；在合理配方和预算下平台化且强基线更优时，则执行阶段退出条件。足够训练与严格退出并不矛盾。

### 8.4 统计与资源

场景/episode是主要独立单位，帧和同轨迹照明变体按簇处理；训练seed单独报告。对配对场景/初态给bootstrap区间或适当配对检验，多任务与多指标的选型顺序预注册。P5的“四个seed同方向”与总体区间同时检验，不能用海量相关帧制造很窄的置信区间。

资源建议：4—8张80GB级GPU用于Base对象模型和长序列；π0.5阶段依据实际后端显存画像配置。单卡80GB可以通过梯度累积执行部分阶段，但吞吐和完整周期另算；现有服务器GPU型号、空闲量和磁盘本轮没有检查，不能把建议硬件当作可用资产。

每个阶段先在正式架构上测200步：GPU小时 = 更新数 × 实测秒/更新 × GPU数 / 3600。例：100k步、8卡、1秒/步约222 GPU小时/seed；若5秒/步则约1111 GPU小时/seed。这里只是公式示例，不是本模型预测值。基线、5个确认seed、移植复现和39750条/方法的闭环费用要另计。训练和评测GPU分配隔离，保留失败日志和可恢复检查点。

两次早期适配预检的训练与开发闭环单独计费，不复用其开发数据作为P7测试，不将工程seed并入三个正式训练seed。理论、数据、组件复现与训练各阶段需要连续评审。可按P0→P1→P2→P3→P4→P5→P6→P7作为里程碑，不预先承诺几周内完成全部研究；P0画像后给出真实资源与日程估计。

### 9.2 必须保留的系统基线

| 编号 | 方法 | 比较作用 |
| --- | --- | --- |
| B0 | 作者Default输入 + 原π0.5 | 冻结系统参照；继承正确光照和动作协议 |
| B1 | 作者RawVLA ISP + 原视觉塔 + 冻结π0.5 | 最近任务方法；允许其RGB输出，独立基线边界清楚 |
| B2 | 同Base RAW编码器 + 相同读出 + 相同π0.5适配 | 排除编码器/参数量/训练预算带来的收益 |
| B3 | 同循环对象模型 + 标准SMC/全局求解 + 精确来源缓存 | 最近完整机制基线；不把B2当唯一强对照 |
| N02 | 完整测量约束结构修订 | 与B3比较新规则，与B0/B1比较系统价值 |

P5中Gen和iSAM2分别覆盖结构推断与连续增量子问题；进入P7时优先保留其中经开发选择最强的实现作为B3，不用测试结果挑一个较弱对手。B1保留作者2k复现，同时给出与N02动作训练充分预算可比的曲线。B2/B3/N02的数据、深度监督、预训练曝光、后端训练容量与调参次数对齐。

闭环主表给每平台、每光照域、每任务和每训练seed的分数；LIBERO与RoboTwin首先分报。若给合并指标，预先定义任务宏平均与样本微平均并同时披露，不掩盖不同任务数量和控制频率。标准光照稳定性、最差组、机制触发次数、误触发动作后果、完整决策延迟共同报告。

### 9.3 三组必须完成的因果消融

1. **发现是否必要：** 固定初始候选、随机提议、SCALOR/Gen提议、N02提议，候选和计算预算一致。
2. **撤回是否有效：** 仅改权重、全部重置、精确trace重放、N02局部重建；检验实际历史污染和动作恢复。
3. **依赖学习是否有用：** oracle图、学习图、随机图、全连接图；oracle只作上界，全部计成本。对学习图比较有无边界校验。

额外拆分干扰估计、绝对拟合、相对评分、循环深度和粒子数。禁止只报告“去掉模块后变差”却不给参数/训练/信息预算相同的强替代实现。

## 11. 最先执行的开发包与最终研究判断

首个开发包只做P0和P1的准备及正式启动：

1. 冻结全量模型与数据约定，保留旧tiny作为回归，不作为新路线能力代表。
2. 锁定公开网络/求解参考，完成移植一致性和GPU资源画像。
3. 建立独立成像干扰与结构变化数据，修复“局部双亮点漏检”和“两像素位移误判”的评价盲区。
4. 启动Base RAW预训练与观测模型充分训练，交付完整3种子行为曲线；通过后先完成早期π0.5适配预检，再进入P2全局对象推断。

这次完整开发值得推进的依据是：观测学习已显示可修复的瓶颈，学界也提供了对象循环、结构推断、增量求解与真值维护的成熟起点。研究风险集中在三处：学到的结构是否可用于正确撤回；局部机制是否优于强增量基线；机制收益是否能穿过π0.5接口成为操作收益。分阶段方案的作用，是让这三项问题分别得到足够训练和可判定的证据。
