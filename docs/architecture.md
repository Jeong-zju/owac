# OWAC 工程架构边界

本文件将 roadmap v4 的共享外部约定映射到代码目录。它是初始设计草案，尚未冻结 API；目前各子包只有职责说明，没有算法、训练器、驱动或后端实现。

## 数据流和模块职责

```text
原始观测及元数据 → 输入适配 → 候选核心计算 → 明确的后端读出 → VLM/VLA 后端
                            ↕ 可选持续状态
                   计算预算、有效性及成本记录
```

| 目录 | 负责内容 | 边界 |
| --- | --- | --- |
| `src/owac/core/` | 被多个实现实际需要的最小共享类型与契约 | 暂不引入全家族统一网络基类 |
| `src/owac/frameworks/` | 候选的原语、组合、求解与原生表征 | 按实际候选设子目录，不为 F01—F12 预造空模型 |
| `src/owac/raw/` | 采集、元数据、校准、清单、拆分和 RAW 输入适配 | 原始采样可追溯，不隐式成像 |
| `src/owac/backends/` | 读出、语言/动作后端接入与参数边界 | 披露训练/推理预处理及所有学习投影 |
| `src/owac/baselines/` | 最近机制对照及 C0—C4 系统对照 | 图像基线独立于主链路 |
| `src/owac/training/` | 学习、拟合、优化及后端适配的复用逻辑 | 解析求解不必强制经过梯度训练 |
| `src/owac/runtime/` | 状态 reset、缓存、增量/异步执行和预算管理 | 允许候选自定义调度，防跨样本或 episode 泄漏 |
| `src/owac/evaluation/` | 机制、架构、闭环、资源及统计评测 | 区分证据层级，不用代理指标替代闭环 |

## 外部概念契约

```text
observations + metadata + optional_state + compute_budget
    → representation + optional_state + validity + cost_record
```

- `observations`：保留信号的自然采样结构；RAW、一般测量集合和一维时序均可通过各自适配器进入。
- `metadata`：采样坐标/时间、来源身份、噪声与有效性等信息；各任务声明必需字段和缺失处理，对照获得相同可用信息。
- `optional_state`：可为空、图、场、记忆、隐式解等；声明创建、更新、reset、保存与释放的条件。时序推理只消费当时可用观测。
- `compute_budget`：候选适用的迭代、时间、状态或通信等限制；明确停止条件和超预算行为，具体 API 在原型中验证。
- `representation`：特征、集合、图、系数或 token 等；不强制同一形状。后端读出负责适配，单独记录其参数和成本。
- `validity`：说明输出的有效性、缺失、饱和及求解失败；任意学习分数不自动是概率。
- `cost_record`：标注测量方式和范围，记录适用的计算、耗时、内存、状态、通信/访存等；没有测量的量不能填零充数。

API 定型前，至少用两种内部形式不同的最小候选检验契约；这是一项待办，不是当前已经完成的兼容性保证。

## 初始技术选择

共享入口采用 Python `src` 包布局。初始化只锁定开发工具，不绑定 PyTorch、JAX、具体 VLM/VLA、相机 SDK、机器人平台或配置框架。需要这些依赖时，在独立变更中记录用途、版本与环境。

完整系统比较记录读出后的输入预算；机制与架构比较保留原生表示、求解和扩展轴。F06—F08 的时序/持续状态、F06 的执行开销等，可在各自最小实验中直接验证。
