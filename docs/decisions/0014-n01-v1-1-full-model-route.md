# N01 v1.1：完整模型、真实任务与可理解证据

日期：2026-10-15。状态：用户认可讨论方案后正式采用。适用：`lzh/n01-evidence-integration` 的后续研究；本次工作范围为更新方案与入口，未启动实现、训练或评测。

## 背景

v1.0 把支持、特征、状态、迁移、动作训练及全量闭环分为 P3—P8 多个阶段。用户指出局部代理指标不能代表完整编码器效果，要求 P3 直接建立完整 N01，任何局部改进也对接 RawVLA-Bench 并提供直观可视化；网络使用有来源的成熟模块，新机制有明确理论依据和创新差异，训练充分。

P2 独立验收保留了真实实现/训练，但六组仅一组符合原平台条件；大运动与当前异常诊断中对应误差和风险外推失效。三通道正式运动臂仍是程序生成数据，真实策略预检只证明接入。这些证据支持把后续投入转到完整模型与目标任务。

## 决定

正式依据为 [N01 全量开发方案 v1.1](../N01_full_development_plan_2026-10-15_v1.1.md)及[同源 HTML](../N01_full_development_plan_2026-10-15_v1.1.html)。

- v1.1 P3 一次交付完整时空支持、成熟内容融合、来源撤回/重算、32 帧有界回放、期限读出、π0.5 真实训练及开发闭环；局部指标用于诊断，不再串成长期研究关卡。
- 从 P3 起用两平台真实 RawVLA-Bench 承担主体训练和验证。每次研究交付含同步输入、历史权重、支持/对应、来源干预和动作结果；数值夹具不承担任务性能结论。
- 默认复用作者完整 DBSR 和已适配 SEA-RAFT；BSRT-L/Burstormer 等为有依据的强候选，Mamba/长记忆按实测必要性引入。不得缩成自造小网络后充当强基线。
- 理论围绕主链的删除一致性、积累—陈旧偏差取舍、条件内顺序错误控制；证明、假设、经验覆盖与未完成分别报告，不承诺无条件闭环成功保证。
- 核心对照为成熟融合、融合＋标准检测/reset、完整 N01 及关键机制消融。按用户2026-10-15执行补充，当前各核心臂采用1个种子匹配训练（默认101），三种子留作后续可选验证，不作为当前门槛，充分性由优化、数据覆盖、延长训练与开发动作/闭环共同判断。
- v1.1 P4 固定模型和协议后执行原完整 13,250 身份/每 checkpoint；P5 承担原生 RAW、跨域、第二骨干或长记忆扩展。阶段含义不再沿用 v1.0 同号阶段。
