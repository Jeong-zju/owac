# N01 v1.2 RAW 信息利用与 VLA 行动归因

日期：2026-10-15。状态：按用户要求采用。当前仅更新技术路线、文档、控制台和DeepSeek提示词，P3待实施。

## 问题

v1.1的全RAW N/B0/B1对照能检验支持修订，却不能单独解释RAW相对RGB的信息收益。来源撤回、删除一致性和状态重算是可信编码的组成部分，不足以独立定义RAW编码器的核心贡献。

## 决定

正式依据为[N01 v1.2](../N01_full_development_plan_2026-10-15_v1.2.md)与[同源HTML](../N01_full_development_plan_2026-10-15_v1.2.html)，执行入口为[v1.2阶段包](../prompts/n01_v1_2/README.md)。

- 主线改为“同源测量与ISP信息差异→测量支持/内容编码→非图像表征→VLA行动”。噪声降低、细节保留和响应时延共同评价，删源一致性作为正确性保障。
- 核心四臂为`raw_base/raw_n01/rgb_base/rgb_n01`。RGB由同一受损RAW经冻结ISP得到；正常光配对RGB不自动作为暗光RAW对照。RGB臂不偷用RAW计算的flow、可靠性或特征，不套用不成立的RAW物理噪声公式。
- 两平台每臂单种子，默认101，P3主体共8个训练run；P4核心完整评测53,000条。标准检测/reset作为补充，不默认第五训练臂；三种子为后续可选，常规修改不全矩阵重训。
- 按用户最新补充，开发期每轮默认共100次闭环，优先当前模型，不按平台/方法乘开，不要求全任务/全条件/四臂全部覆盖。完成即报成功率，不因低分自动追加；完整正式清单留P4单独安排。
- P3仍一次交付完整编码器、真实训练、四臂开发闭环、理论和同步案例。原生CFA采样规格从模型设计明确，实际未测的能力不默认成立；不能把P3的RAW/RGB归因推到P5。
- RoboTwin HDR派生输入优先研究显示处理前的信息利用；LIBERO逆处理/量化输入不声称恢复已丢失的传感器信息。真实CFA/跨域或第二骨干等由P5按已知限制扩展，非行动数据不承担VLA能力结论。
- 保留成熟作者网络、充分训练、简单实时监控、单种子和减少无意义门槛的要求。更新Markdown、HTML、研究控制台和全部当前执行包，旧v1.1作为历史。

## 证据边界

P0—P2源码与历史结果继承，P2未完全通过的独立复核限制保留。输入信息原则不是N01训练成功保证；信息/机制/预训练/任务能力分开归因。本决定不改冻结基准、其他研究方向或远程服务，不启动训练。
