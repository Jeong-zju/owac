# 0015：正式采用 N04 v1.1 技术路线

- 日期：2026-10-15
- 状态：用户明确认可并要求正式更新；已采用
- 适用范围：N04，分支 `lzh/n04-egomotion-separation`
- 当前方案：[N04 v1.1](../plans/N04_full_development_v1.1.md)

用户要求 S2 直接建立完整 N04，以官方 RawVLA-Bench 数据、整体 VLA 效果和可解释的轨迹可视化推进，保留已有完整 ConvNeXt-B 框架。不能靠同环境补采数据使机制具备可训练性，不能把通用运动分离直接当作 RAW 的增量能力。

正式采用以下决定：

1. 研究主问题改为：机器人运动时，如何利用连续 RAW 中与动作有关的弱测量证据形成可靠表征，并在新证据反驳旧预测时修订状态。物理原因分类只在可辨识时解释，不作为必达主任务。
2. S2 一次建立 ConvNeXt-B、完整 RAFT 与 RAW 自监督、条件 RKN、双模式更新、Perceiver 读出及真实 π0.5 动作学习，并交付固定官方轨迹可视化与开发闭环。S3 按优先级补单种子四臂对照；S4 用选定模型的百次闭环整理阶段结论。不再按旧 S2—S7 长时间逐项添加部件。
3. 新增网络仅在官方训练池学习。S0 扩展、受控渲染及其衍生权重不进入主模型训练、校准、选模或正式比较。保留 S1 ConvNeXt-B 结构和可复用实现；官方数据主实验重新初始化新增网络。
4. 主编码路径为 RAW 到特征，不生成 RGB 中间图像，不用 RGB、外部深度／光流教师或仿真几何标签。保留固定预训练 π0.5 的共同起点；适配容量和可用上下文按方案匹配。
5. 以同一 RAW 经固定 ISP 得到的 RGB 建立 RGB／RAW × 单帧／N04 四臂比较。官方默认光照配对 RGB 不能冒充同源退化输入的匹配对照；两平台实际精度和处理历史分别披露。
6. 用整体动作、闭环表现、机制干预、可视化和完整成本形成结论。局部指标是诊断，理论性质限于明确假设，不承诺全局收敛、物理原因可识别或一定优于 RGB。

本决议取代 v1.0 与旧提示词中和上述安排冲突的后续开发要求，不改写既有实验事实。S0 数据合同通过和 S1 局部效果均为历史证据；S1 几何方差等问题仍未通过，不能升级为 RAW 增量或完整编码器有效的结论。

本轮完成方案与入口更新，未启动 S2 实现、训练或新评测，未自动提交或推送。
