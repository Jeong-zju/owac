# 0014 · 归档当前N02局部修订调度实现

- 日期：2026-10-13
- 状态：执行；2026-10-13 用户授权提交本轮修改并开展下一轮开发
- 范围：当前N02局部反证调度/单跳依赖传播实现，保留独立测量基线和全部历史证据

用户明确授权先建立可靠测量基线，再检验N02独有贡献；如果可靠评分成立但局部修订
在多个种子下无可重复收益，就归档当前机制，不继续追加模块。

重训官方CNN、采用真实RAW首帧差分后，预定开发选择的基线在三个种子的新留出均通过
线索互换、无信息保持和95%错误先验纠正门槛。随后在固定候选、已知依赖和共享精确
重组算子下，比较标准滤波、全局更新、N02原semantic_map/propagate和简单事件缓存。
N02与事件缓存的每帧状态逐位相同，纠错与漂移相同；N02端到端约慢4%，独有收益0/3。

据此归档当前调度实现，停止追加N02模块、扩大模型或延长该路线训练。源码、检查点、
协议和原始结果不删除，成功的独立测量基线保留。原完整学习N02仍未验收，真实RAW／
VLA闭环和未知关系下的机制贡献未验证；归档不被表述为对所有可撤回推断的否定。

这是一项基于当前实现与声明条件的研究投入决定。复活需要针对简单事件缓存提出具体、
可检验的额外规则及新协议，不能只依靠步数、规模或名称变化。
