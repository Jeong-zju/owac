# 0015 正式采用 N02 v1.2 技术路线

- 日期：2026-10-15（Asia/Shanghai）
- 状态：用户明确认可并要求正式更新；已采用
- 范围：N02，分支 `lzh/n02-measurement-completion`
- 正式方案：[N02 v1.2](../plans/N02_full_development_v1.2.md)；[HTML 阅读版](../plans/N02_full_development_v1.2.html)

N02 的目标是充分利用 RAW 相比既定 RGB 处理路径保留的动作相关测量，建立可直接接入 VLA 的完整编码器。采用以下决定：

1. 以 RAW 测量约束的动作表征为研究主线。循环、多假设、对象状态与撤回服务于“测量线索→表征修正→动作”，不以通用信念修订替代 RAW 信息增量问题。
2. P2 一次建立完整模型、真实 RawVLA-Bench→π0.5 链路、训练入口与实际诊断可视化；P3 充分训练和整体比较；P4 独立确认与100次闭环。旧 v1.1 的 E1/E2、P2—P7 逐项扩建路线退出执行入口。
3. 复用经核验的 ConvNeXt V2-Base 等成熟组件，保留直接空间特征与测量反馈两条通路。初始 K=4、内部4轮、8帧历史为配置起点。完整通用关系图、变维搜索和局部提速不作为首版前置。
4. 训练对接官方 RAW 和专家动作，主链不生成 RGB 输入、不用 RGB 教师。LIBERO RGB8-derived pseudo-RAW 与 RoboTwin HDR-derived RAW 分报，当前不主张原生 CFA 优势。
5. 同源 RAW/RGB × 普通编码/N02 四臂区分输入收益与机制收益，加入强学习 ISP、普通循环/多假设及必要消融。相同历史、可比容量、训练和后端预算；正常光配对 RGB 不能冒充同源退化对照。
6. RAW 预训练100k与完整适配50k是资源起点，首轮每平台/方法单种子，默认1103。按计划预算完成并报告实际效果，不要求loss单调/平台期或数学收敛，不将绿测当能力结论。用户最新要求每个实际选中模型共100次闭环；默认RoboTwin100，若预定双平台则50+50分报。三种子、13,250主清单、53,000四臂及632附加不作为本轮任务。
7. P1 先验接线、校准、候选泄漏、数据重叠和伪线索互换并入 P2 修复。旧 P1 独立验收未通过的判定不改；旧调度归档与负结果、检查点保留。

本决议取代旧方案和提示词中与上述决定冲突的后续开发要求，不修改历史验收、冻结基线或正在运行的任务。
