# 0004 仿真 benchmark 先于 RAW 适配

日期：2026-10-08。状态：按用户要求采用建设顺序；具体 benchmark 为调研首选建议，尚待兼容性与闭环验收。本决议调整 [0003](0003-pi05-backend-first.md) 的后续阶段，保留已完成的 π0.5 PyTorch 部署。

## 用户要求

用户认为下一步应根据其 Isaac Sim / RAW 调研报告寻找合适的仿真 benchmark，随后再做 RAW 适配。机器人实物、相机和正式数据仍未选定，配置继续留空。PDF 的实施步骤是调研材料，不自动作为安装或改造指令。

## 当前首选与范围

详细比较、固定源码和问题证据见 [benchmark 选型](../simulation-benchmark-selection.md)。

- 主 benchmark 首选：Lightwheel-LIBERO 的少量桌面任务，验证通过后逐步扩大。
- 首个工程闭环：Arena 自带 DROID / π0.5 RGB 抓放示例，用于验证版本、权重及协议。
- RoboCasa 风格厨房任务用于后续场景扩展；原版 MuJoCo LIBERO 用于独立 RGB 参考；BEHAVIOR-1K 留给后期长程研究。
- RawVLA-Bench 作为直接竞争对照协议登记；其三通道 pseudo-RAW 不视为本项目原始 CFA 输入，公开训练数据与闭环测试 manifest 分开审计。
- Isaac Sim 是底座，Isaac Lab Arena 是环境组织和评测框架，Lightwheel-LIBERO 是任务套件，三者不能互相替代称谓或结果。

首选不代表可直接运行：LW-BenchHub 安装脚本固定 Sim 5.0；报告中的相机阶段针对 6.x。Arena 官方示例还使用不同的 jointpos π0.5 配置/权重。版本兼容、资产、任务判据、演示重放和 PyTorch 策略接入必须通过实际检查。

## 共同基线

在后端、选定仿真任务/数据协议及必要首版接入接口验收后，合入本地 `main`，创建不可移动的注释标签 `owac-dev-v0.1.0`。F01—F12 首批分支从同一标签创建，后续子任务保留家族历史。当前没有创建正式标签。

本次交付是选型与顺序修订，没有把未运行的仿真标为通过；Lightwheel/OWAC 变体不冒充原版 LIBERO 或 RoboCasa 官方评测结果。
