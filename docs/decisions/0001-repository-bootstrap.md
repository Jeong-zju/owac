# 0001 仓库初始化边界

日期：2026-10-08。状态：采用。依据：用户要求后续开发基于本地仓库，以及 research roadmap v4 的共享基础设施要求。

## 决定

- `/home/jeong/zeno/owac/` 作为工作空间容器，`repo/` 作为本地 Git 根目录，`worktrees/<task>/` 统一容纳后续并行 checkout，避免散落到 `zeno/`。初始分支为 `main`，保留原路线图和历史版本。
- 采用轻量 Python `src/owac` 包布局和 uv 依赖锁；当前只安装开发工具。
- 按候选核心、RAW、后端、基线、训练、运行时和评测划分职责，先文档化外部接口。
- 全部 12 个家族以种子卡登记，没有默认主线；不预造统一网络基类或虚假的算法实现。
- 版本管理覆盖代码、配置、协议、卡片和小型实验记录；原始数据、权重及大运行产物在 Git 外管理。

## 后果与复核

本决议只完成工程起点，不代表相机、后端、训练方案或算法设计已经选定。
