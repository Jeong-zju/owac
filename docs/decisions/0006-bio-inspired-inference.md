## 决策

将首个实例的核心问题表述为“弱证据下，形成、维持和修正服务于物理行动的表征”。允许结构先验和记忆参与推断，以测量和交互检验推断；输出特征、状态、关系或假设，不生成供下游使用的 RGB/sRGB/XYZ。

原 PI1—PI5 改为具身评价维度。新增 N01 自适应时空积分、N02 测量约束循环补全、N03 情景记忆补全、N04 自运动预测、N05 跨感官约束、N06 行动验证六类机制问题，与 F01—F12 交叉。它们不是六个必选串联模块，不统一内部表示，也不要求全部框架具有记忆、多假设或神经网络。

生物证据、工程抽象及 OWAC 假设分列。补全必须可被反证修订；区分测量支持与先验/记忆支持，检查重复证据和错误先验。先验带来的收益允许作为贡献，但要匹配来源、训练数据、记忆和观测预算。无信息时的猜测不能当作恢复了真实观测。

## 与既有规则的关系

- 保留从设计起追求 ResNet／Transformer 级影响力潜力的完整框架目标和所有家族。
- 0005 的物理决策增量要求继续有效；其五类选题现在用作评价维度，不再作为主要机制划分。
- RawVLA 等 neural ISP 继续是独立系统基线。机制近邻扩展到递归估计、预测编码、联想记忆、真值维护及主动感知，不能只比较 ISP。
- 0004 及其后续单任务仿真部署记录继续约束工程成熟度；RAW API 与候选实现尚待设计和验证。
- N05 的触觉/力传感与 N06 的额外探测不是全体候选的前置条件；硬件和真实数据仍待选定。
