# 收敛到 RAW stem 与 SigLIP 蒸馏路线

日期：2026-10-20。状态：用户认可方案，当前主线；工程实施中，训练与闭环能力尚待验证。

## 决定

OWAC 当前研发投入收敛到 **RAW stem＋继承现有 π0.5 策略的 SigLIP 权重＋教师蒸馏**。先恢复正常光单任务控制，再检验弱光、曝光和噪声变化下的收益。完整[方案](../plans/RAW_STEM_SIGLIP_DISTILLATION_2026-10-20.md)与[GPT-6.1 Sol 执行 prompt](../prompts/GPT61_SOL_RAW_STEM_SIGLIP_DISTILLATION.md)是当前入口。

OWAC-D1.1 的主教师必须接收 RAW，内部允许 Neural ISP→RGB→VLA；教师与学生不限定单帧，以效果选择因果 burst／递归／状态并披露信息与成本。既有视觉权重和内部成像依赖须披露；学生部署直接从 RAW 生成非图像 tokens，不生成 RGB/sRGB/XYZ 中间图像，不调用教师。首轮继承与后端匹配的视觉语义，冻结语言／动作后端，先训练 stem，必要时有限适配视觉层并加入原生动作监督。

这取代 2026-10-19 ConvNeXt 视觉替换方案作为当前实施路线，也变更历史“不使用 RGB 教师”的训练约束。旧代码、协议、实验、负结果和冻结基准保持可追溯。F01—F12 保留为候选池；N01／N02／N04 暂停，不作为三个并行执行入口。

## 为什么收敛

N01 的同场景正常光诊断中，原策略 4/4，而替换 RAW/RGB 两臂各 0/4；N02 的局部动作读出收益尚未变成学习策略的闭环收益；N04 的工程修复也未建立任务收益。因此先解决视觉表征与既有动作后端的兼容性，复杂推断机制的效果才有可解释的参照。

这些证据支持改变下一步投入顺序，不证明旧机制原理不可能，也不保证蒸馏成功。继承权重和教师对齐是当前最小可检验选择，不能单凭结构称为新架构贡献。

## 历史与权限

统筹台中的连线表示研究选择的演进、暂停和收敛，不表示算法通过验收，也不表示三条旧机制已融合成一个模型。2026-10-19 的本地代码合并与 2026-10-20 的研究路线采纳分别记录。

本次更新方案、规则和统筹台，不启动模型派工、训练、仿真闭环或实机动作。后续 GPT-6.1 Sol 通过本机 DeepSeek Harness V41-Flash Max 执行主要编码，并独立验收；正式实验须有新的具体授权。旧远端运行状态只作历史记录。

## 2026-10-20 执行中用户澄清

教师要求为作者 **RAW 输入的已训练 RawVLA 神经 ISP＋冻结 VLA**；历史 Default ISP＋π0.5 的成功率是诊断参照，不能替代该教师。当前官方模型代码和训练配方已公开，但尚未找到作者训练后的 RawVLA 前端 checkpoint；骨干 π0.5 权重不等于完整教师。

用户撤销“策略固定单帧”的硬约束。教师与学生均可使用多帧／递归状态，以控制效果、稳定性及实测成本选型。必须声明实际因果历史、采样步长、相机／时间对齐及 reset；信息范围不同须披露和诊断。此前单帧设计保留为可选基线与每帧编码组件，不限定最终策略。正式训练和闭环仍需具体新授权。
