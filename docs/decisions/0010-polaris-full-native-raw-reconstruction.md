下文为历史授权与实施要求。当前不继续 Arena/PolaRiS 重建或公开上传，旧数据和结果保留。

用户要求重建能用于微调 π0.5 的完整 Isaac Sim / Arena DROID 仿真训练数据，每条轨迹加入与 RGB 并列的仿真器原生 RAW，并以 public 权限上传至 Hugging Face `Jeong-zju`。随后明确接受逐任务重建，要求尽量接近原场景及 RGB 对应关系。此授权包括最终公开上传，无需重复请求常规运行或发布许可。

范围固定为作者公开 `owhan/PolaRiS-datasets` 的仿真共同训练部分，提交 `dca86b8e186df63323eb375344a1977d92f508f7`：32 分片、316 条独立轨迹、52,914 个控制帧、14 个源场景目录、17 条不同任务指令。这不包括 π0.5 的全部预训练数据或共同训练配方中的真实 DROID 数据。

每条保留源身份、原动作、机器人参考状态与全部原 JPEG。逐任务重建物体/布局，并在物理回放时新采配对 RGB 和 CameraCore ISP 前原生 CFA。原 JPEG 是对应参考，新 RAW 对应同帧新 RGB；原场景、相机标定和原 JPEG 的逐像素 RAW 无法从公开包恢复，不能声称精确恢复。必须记录逐条对应审查、任务完成情况、状态跟踪偏差与缺失项。

完整源数据审计发现全部 52,914 帧的两个 exterior JPEG 字段字节完全相同。因此保持三字段结构，明确 exterior 2 是 exterior 1 的别名，实际采集外部和腕部两个独立相机；不虚构第三个独立机位。

发布名为 `Jeong-zju/isaac-arena-droid-rgb-raw-reconstructed`，属于作者仿真训练数据的重建衍生集，不冒充官方原场景数据。完整公开版本须核验所有 316 条身份和原控制帧、三路字段、原动作不变、原生 RAW 整数无损、逐条物理任务和 RGB 对应审查，以及真实 LeRobot / π0.5 数据加载。失败、重试和未完成场景均留档，不能用少量成功样例代替全集。

完整 RGB 基准冻结运行不受源码改动影响。GPU 试验只暂停外层调度、让当前 episode 自然结束，串行运行，随后恢复同一调度器。版本和原因独立留档，不覆盖历史。持续云端任务使用 supervisor。定时任务保持关闭；云端权重、图像和数组不下载本地，只归档小型数字并更新离线进度页。
