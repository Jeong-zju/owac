# 验证目录

当前只有包和文档骨架，没有业务测试用例。`make check` 验证静态格式和源码语法，包导入单独检查；这些不是算法验证。

- `unit/`：后续 RAW 数值/精度、有效性、候选算子、状态 reset、因果性和预算等行为测试。
- `integration/`：后续采集/数据到候选/读出/评测的端到端小样例。

实现后通过 `uv run --locked pytest` 运行适用用例。GPU 和实机测试使用项目已注册的 `gpu`、`hardware` marker，并显式检查资源与执行前提；普通检查不连接真实机器人。

优先使用可控合成信号或有来源说明的小夹具。不要下载大数据集作为基础测试前提，不用只检查常量或空类存在的测试充数。
