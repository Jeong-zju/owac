## 当前研究定义

机器人运动时，利用连续 RAW 中质量不均但仍与动作有关的测量证据，形成可靠的视觉表征，并在新测量反驳旧预测时及时更新。运动预测和空间对应是利用弱测量的手段；不把通用的“自己动／物体动”分类本身称为 RAW 贡献。

完整模型由 ConvNeXt-B 当前测量、完整 RAFT 自监督对应、RKN／Ac-RKN 条件预测、延续／修订双模式更新、Perceiver 读出和 π0.5 动作学习组成。新增网络只用官方训练池，不补采；S1 扩展数据权重仅作历史对照。S2 建立全部路径，S3 按优先级补 RGB／RAW × 单帧／N04 四臂单种子对照，S4 整理每个待评模型100次闭环结果。当前每平台／方法seed101，两平台默认各50次，不强制所有方法和消融齐备；实时监控网页任务已写入阶段提示词。以同源 RGB、机制干预、固定真实数据轨迹可视化和整体行为判断贡献；具体理论条件、配置、训练及结论边界以 v1.1 方案为准。

- 基础计算问题与已有方法的具体失效：观测变化同时来自自运动、外部物体运动与成像不可靠
  （饱和、遮挡、曝光）。普通递归编码器把三者混在一个 residual 里：或者把运动物体抹平
  （稳定分支把外因当噪声），或者把自运动当成场景变化（ego residual 被读成物体运动）。
- 预期优势、适用范围与可能反例：把传播误差、外部变化、成像不可靠性**分别**参与状态更新，
  应当同时得到“自运动被解释掉”和“外部变化被保留”两个性质。反例：降低 ego residual 的
  同时降低对外部运动的敏感性；或学习版把 action 当任务 ID 捷径而不跟踪实际运动。
- 启发来源：[Keller 等感觉运动失配](https://pubmed.ncbi.nlm.nih.gov/22681686/) 提供
  “预测与实际反馈之差”的问题形式；这是**问题启发**，不构成“机器人的分解可识别”的证据。

## 生物启发与弱证据机制

- 关联 N01—N06：N04（自运动预测与变化分离）；F 是架构家族，PI 是评价维度，不互相替代。
- 生物原始实验、任务/物种及支持观察：仅引用感觉运动失配作为问题形式，见
  [机制综述](../reviews/2026-10-09_bio_lowlight_inference.md)；本轮**没有**新增生物证据。
- 工程抽象与生物事实的距离：抽象只保留“预测—反馈之差可影响状态更新”，不声称大脑分区或
  概率编码；候选的新增计算规则是三分支门控 + 独立变化 cell + 传播可靠性。
- 神经/非神经实现：本轮是神经实现（MLP 运动编码 + Conv 分解器 + 解析几何可选）；
  最近机制基线是同上下文 ConvGRU、运动补偿 + EMA、predict–update filter。
- 测量、先验、记忆的作用：测量=当前帧；记忆=持续特征状态；先验=传播预测。三者来源在
  `EncoderOutput.diagnostics` 与 `N04State.decomposition` 中分别记录。
- 不使用补全，因此“先验正确/无信息/误导”的补全检验不适用；对应的替代检验是
  “无历史区域用有效当前测量初始化，而不是把 pred=0 当历史证据”。
- 积分：本候选不做空间积分；多尺度场是分辨率组合，不是时间常数。

## Physical intelligence 增量

- 物理决策问题：相机自身运动造成的观测变化不应改变“目标在哪里、有没有动”的判断；反之
  外部物体运动必须及时进入表示。首项闭环场景：LIBERO/RoboTwin 上的操作策略在相机运动时
  仍要正确选择目标。
- 最近具身方法及已覆盖能力：RawVLA 的动作监督 ISP、任务条件化与外观增强已覆盖 RAW 接入、
  动作损失与时序状态；见 [Cui 专题综述](../reviews/2026-10-08_ziteng_cui_raw_physical_intelligence.md)。
- 拟新增的计算规则：分解后的三分支门控改变**状态更新权重**，进而改变视觉前缀里保留的信息；
  与“普通 RAW 网络 + 更强时序”的区别在于传播可靠性显式参与更新，而不是隐含在深度里。
- 新规则应改变的动作/恢复能力：目标移动后的恢复帧数、遮挡后恢复、照明突变不误报。能否由
  更强控制器或更多信息解释：目前**不能排除**——这正是下方反证实验要回答的。
- 成像干预：合成中固定几何、改变照明/曝光/饱和；物理干预：独立控制目标速度与相机速度。
- 信息条件：候选与所有对照共享历史长度、元数据（本体/动作可用性）、训练划分与读出预算；
  不输入未来专家动作或隐藏真值。oracle 几何（`calibrated_geometry`）单独报告，不与无深度模型混报。
- 主动观测：本轮不涉及；不新增采集动作。
- 当前具身证据：未建立。真实闭环必须在 RawVLA-Bench 上另做。

## 完整框架设计契约

| 层面 | 实际实现与证据边界 |
| --- | --- |
| 状态 | 每相机多尺度 stable、独立 change、支持 mask、可用性、age；照明统计另存线性测量/支持，计入状态成本；部分 reset、缓存去重、TBPTT 有回归 |
| 传播/更新 | 纯 predict 不读取当前图像；learned-proprio、proprio-only、identity、解析几何分开；三支加 unknown；低尺度进入损失和读出 |
| 输入 | 作者三通道 RawVLA 测量；合成 CFA 各平面分别采样，保留四相位；无 RGB 教师或重建中间输入 |
| 组合 | tiny 32/2 blocks/2 scales；small/medium 配置仅构造，未验证 scaling；二维规则在薄一维信号上复用 |
| 学习 | 运动/分解层在 optimizer 前 materialize，实际参数更新可检验；合成掩码定位与测量预测；readout 实际动作梯度通过，尚未动作适配训练 |
| 后端 | 固定 StarVLA 真实语言/动作权重，显式释放被替换视觉塔；保留语言缩放、mask/position、adaRMS 和 flow target；每相机 256×2048 |
| 执行 | 离线序列、真实 batch 前反向、独立 HTTP infer/reset 均运行；逐相机状态，未做跨相机状态融合 |

规则：`pred=Propagate(state, past/current executed context)`；`innovation=f_t-observation_reference`（新配置在RAW域传播历史、匹配当前支持并解释增益，旧配置保留task-state参考）；分别处理传播误差、外部变化、成像不可靠及 unknown；`stable=(1-g)*pred+g*f_t`；变化 cell 独立衰减/写入；有界 block correction；多尺度读出。四种支持分数独立，允许共存；外部事件门只有“运动存在”的标签，不再同时学互斥原因占比。归一化 `mix` 只用于诊断，不进 loss/更新/检测；旧 checkpoint 需旧源码运行。门控与 unknown 未校准为概率，不冒称物理空间地图或可识别分解。
