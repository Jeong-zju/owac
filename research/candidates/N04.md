## 问题、假设与文献定位

- 基础计算问题与已有方法的具体失效：观测变化同时来自自运动、外部物体运动与成像不可靠
  （饱和、遮挡、曝光）。普通递归编码器把三者混在一个 residual 里：或者把运动物体抹平
  （稳定分支把外因当噪声），或者把自运动当成场景变化（ego residual 被读成物体运动）。
- 预期优势、适用范围与可能反例：把传播误差、外部变化、成像不可靠性**分别**参与状态更新，
  应当同时得到“自运动被解释掉”和“外部变化被保留”两个性质。反例：降低 ego residual 的
  同时降低对外部运动的敏感性；或学习版把 action 当任务 ID 捷径而不跟踪实际运动。
- 启发来源：[Keller 等感觉运动失配](https://pubmed.ncbi.nlm.nih.gov/22681686/) 提供
  “预测与实际反馈之差”的问题形式；这是**问题启发**，不构成“机器人的分解可识别”的证据。

| 最近工作的规则与框架（原始来源） | 本候选拟新增的设计 | 可检验差异与反证 |
| --- | --- | --- |
| predict–update filter（[filterpy Kalman innovation](https://github.com/rlabbe/filterpy/blob/3b51149ebcff0401ff1e10bf08ffca7b6bbc4a33/filterpy/kalman/kalman_filter.py)、[DPF](https://github.com/tu-rbo/differentiable-particle-filters/blob/488f233a07f275d7321562899cec7e63ec389069/methods/dpf.py)） | 创新残差被分解为 ego_error / external_change / imaging_unreliability 三支 + unknown 残留通道，各自进入更新门控 | 同测量模型的标准 filter 只有单一创新；若候选的分解门控与“全部 residual 当噪声”消融在机制矩阵上无法区分，则新增规则不成立 |
| 运动补偿 + EMA、ConvGRU、action-conditioned recurrent（[RAFT update](https://github.com/princeton-vl/RAFT/blob/2888e15a51fa41140771d3f498ed8023cff098d1/core/update.py)） | 传播算子只吃**已发生**的运动上下文与低分辨率上一特征，当前测量进入独立 correction 分支 | 当前图像不得影响纯预测输出（已有测试）；消融 `n04_time_shifted_context` 检验“上下文是否真的对应本帧” |
| 显式几何 warp（[Kornia depth](https://github.com/kornia/kornia/blob/4fcfcf863e0a9e2b3e93179c3fa96bcf278ce3c6/kornia/geometry/depth.py)） | forward projection 与 `grid_sample` backward 采样严格分离，越界/遮挡产生 validity 而非 border padding | 解析几何测试（整数平移/identity/组合与逆/越界不伪造历史证据） |

局部公式等价检查：`stable=(1-g)*pred+g*f_t` 与一阶滤波同形，差异只在 `g` 由三分支联合给出；
这一点已在候选卡内明确写成“首版更新”，不作为贡献。与 N01（时空证据积分）、N02（测量约束补全）
的重叠是“弱证据下维持/修正表征”的公共问题，但本候选不引入补全或长时积分，保持独立。

## 生物启发与弱证据机制

- 关联 N01—N06：N04（自运动预测与变化分离）；F 是架构家族，PI 是评价维度，不互相替代。
- 生物原始实验、任务/物种及支持观察：仅引用感觉运动失配作为问题形式，见
  [机制综述](../reviews/2026-10-09_bio_lowlight_inference.md)；本轮**没有**新增生物证据。
- 工程抽象与生物事实的距离：抽象只保留“预测—反馈之差可影响状态更新”，不声称大脑分区或
  概率编码；候选的新增计算规则是三分支门控 + 独立变化 cell + 传播可靠性。
- 神经/非神经实现：本轮是神经实现（MLP 运动编码 + Conv 分解器 + 解析几何可选）；
  最近机制基线是同上下文 ConvGRU、运动补偿 + EMA、predict–update filter。
- 测量、先验、记忆的作用：测量=当前帧；记忆=持续特征状态；先验=传播预测。三者来源在
  `EncoderOutput.diagnostics` 与 `N04State.decomposition` 中分别记录。
- 不使用补全，因此“先验正确/无信息/误导”的补全检验不适用；对应的替代检验是
  “无历史区域用有效当前测量初始化，而不是把 pred=0 当历史证据”。
- 积分：本候选不做空间积分；多尺度场是分辨率组合，不是时间常数。

## Physical intelligence 增量

- 物理决策问题：相机自身运动造成的观测变化不应改变“目标在哪里、有没有动”的判断；反之
  外部物体运动必须及时进入表示。首项闭环场景：LIBERO/RoboTwin 上的操作策略在相机运动时
  仍要正确选择目标。
- 最近具身方法及已覆盖能力：RawVLA 的动作监督 ISP、任务条件化与外观增强已覆盖 RAW 接入、
  动作损失与时序状态；见 [Cui 专题综述](../reviews/2026-10-08_ziteng_cui_raw_physical_intelligence.md)。
- 拟新增的计算规则：分解后的三分支门控改变**状态更新权重**，进而改变视觉前缀里保留的信息；
  与“普通 RAW 网络 + 更强时序”的区别在于传播可靠性显式参与更新，而不是隐含在深度里。
- 新规则应改变的动作/恢复能力：目标移动后的恢复帧数、遮挡后恢复、照明突变不误报。能否由
  更强控制器或更多信息解释：目前**不能排除**——这正是下方反证实验要回答的。
- 成像干预：合成中固定几何、改变照明/曝光/饱和；物理干预：独立控制目标速度与相机速度。
- 信息条件：候选与所有对照共享历史长度、元数据（本体/动作可用性）、训练划分与读出预算；
  不输入未来专家动作或隐藏真值。oracle 几何（`calibrated_geometry`）单独报告，不与无深度模型混报。
- 主动观测：本轮不涉及；不新增采集动作。
- 当前具身证据：未建立。真实闭环必须在 RawVLA-Bench 上另做。

## 完整框架设计契约

| 层面 | 当前设计及未解决问题 |
| --- | --- |
| 状态与表示 | `N04State`：多尺度 stable 场、独立 change cell、传播可靠性、validity/available、时间与相机身份。不声称是物理空间完整地图 |
| 交互与拓扑 | 逐相机独立状态；block 组合同一套 predict/correct 规则；跨相机融合未实现，若引入需单列信息与成本 |
| 组合与扩展 | 宽度 32/64/128、层数 2/3/4、多尺度 2/3/4（tiny/small/medium 三档配置）；核心规则可组合，未验证 scaling |
| 学习与推理 | 全部学习（运动编码器、分解器、block、读出）；几何分支为解析；状态初始化/部分 reset/TBPTT detach 已实现 |
| 数值与硬件实现 | FP32、CPU 参考实现；状态 7.90 MB（tiny，含优化器之外的状态张量统计见实验记录）；p50/p95 见记录 |
| 通用输入与读出 | `rawvla_rgb3`（3 通道）与 `bayer_cfa`（单测量面 + 采样相位）共用核心规则；读出为每相机固定 token 数，本轮受控配置 256×2048，小尺寸单独命名 |
| 复用与工程接口 | `core/encoder_contract.py` 的 `init_state/step/reset/detach_state/readout`；`backends/rawvla_features.py` 提供 π0.5 特征前缀入口 |

- 最小状态与算法：`f_t = Stem(raw_t)`；`pred_t, valid, unc = Propagate(state_{t-1}, context_t)`；
  `innovation = f_t - pred_t`；三分支分解；`stable/g_update` 与 change cell 各自更新；
  表示 `[stable, change, measured, validity]`。首版 `g_update` 是解析先验（可靠性越高越接受测量、
  残差越大越及时更新、饱和显著降权），**未校准为概率**。
- 完整端到端草图：测量 → stem → 传播 → 分解 → 更新 → 多尺度 block → 读出 → π0.5 视觉前缀。
- 最小机制原型：合成二维可控测量场（相机平移/旋转、目标运动、照明、噪声、遮挡、标定误差）+ CFA 采样。
  可能隐藏的瓶颈：合成场过于简单，传播误差与真实光流误差分布不同。
- 外部接口：见 `core/encoder_contract.py`（MeasurementFrame / EmbodimentContext / ComputeBudget /
  EncoderOutput / VisualTokens）。
- RAW 接口：主链不经 RGB/sRGB/XYZ 中间图像；CFA 按四个子平面分别采样再混合，保留每平面相位。
- VLM/VLA 后端：π0.5（StarVLA 固定 commit）特征入口已实现为可执行 bridge；**未做真实权重验收**。
