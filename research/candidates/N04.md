## 问题、假设与文献定位

2026-10-13 补充[已有方法与源码复用评审](../reviews/2026-10-13_n04_existing_methods/README.md)：优先用现成 FilterPy 和作者 PyTorch RKN 检验动态状态；RAW 噪声与融合参考 EMVD 后续工作，几何分解参考 Dynamo-Depth。已核查接入边界，尚未集成或产生性能结果；候选维持 prototype，不将标准滤波/动力学及 RAW 接入本身计作新增机制。

- 基础计算问题与已有方法的具体失效：观测变化同时来自自运动、外部物体运动与成像不可靠
  （饱和、遮挡、曝光）。普通递归编码器把三者混在一个 residual 里：或者把运动物体抹平
  （稳定分支把外因当噪声），或者把自运动当成场景变化（ego residual 被读成物体运动）。
- 预期优势、适用范围与可能反例：把传播误差、外部变化、成像不可靠性**分别**参与状态更新，
  应当同时得到“自运动被解释掉”和“外部变化被保留”两个性质。反例：降低 ego residual 的
  同时降低对外部运动的敏感性；或学习版把 action 当任务 ID 捷径而不跟踪实际运动。
- 启发来源：[Keller 等感觉运动失配](https://pubmed.ncbi.nlm.nih.gov/22681686/) 提供
  “预测与实际反馈之差”的问题形式；这是**问题启发**，不构成“机器人的分解可识别”的证据。

| 最近工作的规则与框架（原始来源） | 本候选拟新增的设计 | 可检验差异与反证 |
| --- | --- | --- |
| predict–update filter（[filterpy Kalman innovation](https://github.com/rlabbe/filterpy/blob/3b51149ebcff0401ff1e10bf08ffca7b6bbc4a33/filterpy/kalman/kalman_filter.py)、[DPF](https://github.com/tu-rbo/differentiable-particle-filters/blob/488f233a07f275d7321562899cec7e63ec389069/methods/dpf.py)） | 创新残差被分解为 ego_error / external_change / imaging_unreliability 三支 + unknown 残留通道，各自进入更新门控 | 同测量模型的标准 filter 只有单一创新；若候选的分解门控与“全部 residual 当噪声”消融在机制矩阵上无法区分，则新增规则不成立 |
| 运动补偿 + EMA、ConvGRU、action-conditioned recurrent（[RAFT update](https://github.com/princeton-vl/RAFT/blob/2888e15a51fa41140771d3f498ed8023cff098d1/core/update.py)） | 传播算子只吃**已发生**的运动上下文与低分辨率上一特征，当前测量进入独立 correction 分支 | 当前图像不得影响纯预测输出（已有测试）；消融 `n04_time_shifted_context` 检验“上下文是否真的对应本帧” |
| 显式几何 warp（[Kornia depth](https://github.com/kornia/kornia/blob/4fcfcf863e0a9e2b3e93179c3fa96bcf278ce3c6/kornia/geometry/depth.py)） | forward projection 与 `grid_sample` backward 采样严格分离，越界/遮挡产生 validity 而非 border padding | 解析几何测试（整数平移/identity/组合与逆/越界不伪造历史证据） |

局部公式等价检查：`stable=(1-g)*pred+g*f_t` 与一阶滤波同形，差异只在 `g` 由三分支联合给出；
这一点已在候选卡内明确写成“首版更新”，不作为贡献。与 N01（时空证据积分）、N02（测量约束补全）
的重叠是“弱证据下维持/修正表征”的公共问题，但本候选不引入补全或长时积分，保持独立。

## 生物启发与弱证据机制

- 关联 N01—N06：N04（自运动预测与变化分离）；F 是架构家族，PI 是评价维度，不互相替代。
- 生物原始实验、任务/物种及支持观察：仅引用感觉运动失配作为问题形式，见
  [机制综述](../reviews/2026-10-09_bio_lowlight_inference.md)；本轮**没有**新增生物证据。
- 工程抽象与生物事实的距离：抽象只保留“预测—反馈之差可影响状态更新”，不声称大脑分区或
  概率编码；候选的新增计算规则是三分支门控 + 独立变化 cell + 传播可靠性。
- 神经/非神经实现：本轮是神经实现（MLP 运动编码 + Conv 分解器 + 解析几何可选）；
  最近机制基线是同上下文 ConvGRU、运动补偿 + EMA、predict–update filter。
- 测量、先验、记忆的作用：测量=当前帧；记忆=持续特征状态；先验=传播预测。三者来源在
  `EncoderOutput.diagnostics` 与 `N04State.decomposition` 中分别记录。
- 不使用补全，因此“先验正确/无信息/误导”的补全检验不适用；对应的替代检验是
  “无历史区域用有效当前测量初始化，而不是把 pred=0 当历史证据”。
- 积分：本候选不做空间积分；多尺度场是分辨率组合，不是时间常数。

## Physical intelligence 增量

- 物理决策问题：相机自身运动造成的观测变化不应改变“目标在哪里、有没有动”的判断；反之
  外部物体运动必须及时进入表示。首项闭环场景：LIBERO/RoboTwin 上的操作策略在相机运动时
  仍要正确选择目标。
- 最近具身方法及已覆盖能力：RawVLA 的动作监督 ISP、任务条件化与外观增强已覆盖 RAW 接入、
  动作损失与时序状态；见 [Cui 专题综述](../reviews/2026-10-08_ziteng_cui_raw_physical_intelligence.md)。
- 拟新增的计算规则：分解后的三分支门控改变**状态更新权重**，进而改变视觉前缀里保留的信息；
  与“普通 RAW 网络 + 更强时序”的区别在于传播可靠性显式参与更新，而不是隐含在深度里。
- 新规则应改变的动作/恢复能力：目标移动后的恢复帧数、遮挡后恢复、照明突变不误报。能否由
  更强控制器或更多信息解释：目前**不能排除**——这正是下方反证实验要回答的。
- 成像干预：合成中固定几何、改变照明/曝光/饱和；物理干预：独立控制目标速度与相机速度。
- 信息条件：候选与所有对照共享历史长度、元数据（本体/动作可用性）、训练划分与读出预算；
  不输入未来专家动作或隐藏真值。oracle 几何（`calibrated_geometry`）单独报告，不与无深度模型混报。
- 主动观测：本轮不涉及；不新增采集动作。
- 当前具身证据：未建立。真实闭环必须在 RawVLA-Bench 上另做。

## 完整框架设计契约

| 层面 | 实际实现与证据边界 |
| --- | --- |
| 状态 | 每相机多尺度 stable、独立 change、支持 mask、可用性、age；照明统计另存线性测量/支持，计入状态成本；部分 reset、缓存去重、TBPTT 有回归 |
| 传播/更新 | 纯 predict 不读取当前图像；learned-proprio、proprio-only、identity、解析几何分开；三支加 unknown；低尺度进入损失和读出 |
| 输入 | 作者三通道 RawVLA 测量；合成 CFA 各平面分别采样，保留四相位；无 RGB 教师或重建中间输入 |
| 组合 | tiny 32/2 blocks/2 scales；small/medium 配置仅构造，未验证 scaling；二维规则在薄一维信号上复用 |
| 学习 | 运动/分解层在 optimizer 前 materialize，实际参数更新可检验；合成掩码定位与测量预测；readout 实际动作梯度通过，尚未动作适配训练 |
| 后端 | 固定 StarVLA 真实语言/动作权重，显式释放被替换视觉塔；保留语言缩放、mask/position、adaRMS 和 flow target；每相机 256×2048 |
| 执行 | 离线序列、真实 batch 前反向、独立 HTTP infer/reset 均运行；逐相机状态，未做跨相机状态融合 |

规则：`pred=Propagate(state, past/current executed context)`；`innovation=f_t-observation_reference`（新配置在RAW域传播历史、匹配当前支持并解释增益，旧配置保留task-state参考）；分别处理传播误差、外部变化、成像不可靠及 unknown；`stable=(1-g)*pred+g*f_t`；变化 cell 独立衰减/写入；有界 block correction；多尺度读出。四种支持分数独立，允许共存；外部事件门只有“运动存在”的标签，不再同时学互斥原因占比。归一化 `mix` 只用于诊断，不进 loss/更新/检测；旧 checkpoint 需旧源码运行。门控与 unknown 未校准为概率，不冒称物理空间地图或可识别分解。

## 可证伪实验与验收

当前 v0.5 按单因素顺序完成数据修复、传感器观测参考、支持掩码、实际增益解释、组合训练以及动态记忆干预。三份独立训练数据/初始化，共36份权重；最终留出原9条件定位0.332→0.310 px、三因素共存漏报20.6%→6.6%，同时纯相机/照明误报上升。同分布无变化分支0.303 px、仅增益提示0.302 px，均优于完整候选；独立定位收益尚未归因于新增机制。删除历史change只影响约0.001—0.002 px；缺失观测时固定stable只改变change，下一帧stable差异严格为0。当前保持prototype，H1/H2/动态记忆尚未获得稳定支持。全仓248 tests和make check通过；旧错误数据结论继续保留为失效历史，不混入新基准。完整协议、方差、成本和限制见最新记录。

以下为 v0.4 及更早历史：

历史 v0.4 数值来自[事件分数复验](../experiments/2026-10-13_n04_event_semantics.md)；历史 v0.2 来自[独立验收记录](../experiments/2026-10-12_n04_acceptance.md)，v0.3 来自[六项修复及对比](../experiments/2026-10-13_n04_six_fixes.md)。旧 0.0232/0.0352 等“定位误差”是特征对齐，已失去目标定位的解释。原 176,808 参数数目也漏计懒建模块。

- v0.4 候选、五个最近基线、C4、五个消融（含单独关闭 illumination）、初始化冻结传播各做三个初始化；上一版候选也做三个初始化。同一 seed-0 数据与 200 updates，共 42 checkpoint、252 次 suite。容量/读出差异分别披露；最近基线是受控简化实现，没有声称完整论文复现。
- continuity 10000/10001/10002 与运行前预定的 fresh 20000/20001/20002 分开报告；扩大相机/目标速度范围；两种精确配对反事实，9 条件、逐帧轨迹、恢复/censored 留档。三初始化共用同一训练数据，并非三个独立训练数据集；fresh 仍来自同一合成生成过程。
- 定位是有标签训练探针的逐样本质心误差/IoU；变化响应比不能称为误报率。空 change 分支指标为空，不把零输出当良好分解。
- 原生 CFA 四相位有前向/梯度回归与 v0.2 各 20 步合成训练，来源是生成器，不是实采 RAW；v0.3 新增 CFA 线性统计/坐标回归。
- v0.2 的 LIBERO/RoboTwin 各一源轨迹 20 步 NPZ 训练；统计/source identity/监督动作时序核对；无 executed control 标签，不读未来动作。无目标标签，真实 location loss 是 feature consistency proxy。本轮没有重做真实数据动作训练。
- v0.2 的两套真实预训练 π0.5 动作梯度到达传播、更新、readout，后端被冻结；10 次去噪复用视觉 prefix。独立服务两次真实请求与 reset 通过。证明历史实现/接口，不证明任务成功或新版本收益。

H1 的预设支持条件仍是自运动变化响应比 <1 且低于无 ego/错位消融；H2 要求照明响应低于物体运动且有匹配的分支对照。v0.4 留档漏报 66.221%→53.448%、定位 2.010→2.019px，以及 no-change/运动补偿/filter 排序均来自受批次标签缺陷影响的合成数据；不能据此确认改善、分配失败原因或判断架构优劣。旧指标完整保留，H1/H2/H3 待正确数据与新冻结协议复验。

v0.4 只读最小复现：batch=2 请求目标在 (44,32)/(20,32)，实际两张图均在 (44,32)，标签却均含两个目标、质心为 (32,32)。训练 batch=4、评测 batch=2 均受影响。另在 batch=1 的无噪声静态场景中，真值零运动下 feature residual 三初始化均值仍为 0.24795；同一传播仅旁路 block 修正后降至 1.33e-8，确认当前权重存在内部表征改写混入创新的问题。照明增益仅作门控线索，外部写入仍乘完整混合残差；组合照明/物体运动在训练规则中缺席。详情与方案见最新诊断。

历史六项缺陷通过 19 项新增行为回归、全仓 206 项测试；v0.4 新增 8 项事件语义回归，全仓 215 passed、make check 通过。源码/42 份权重 hash、完整评测身份与反事实不变量核验通过；训练后外部 logit 的直接辅助梯度均为零，事件正样本梯度推动分数升高。核心 predict/correct、三原因加 unknown、有符号 change cell、原测量读出保持；当前与 v0.3 候选参数（含训练探针）均 294,990，batch=2 状态均 7,241,744 bytes。fresh 条件 p50/p95 平均时延 7.764/11.202ms，旧候选 2.662/4.551ms，未建立效率收益，具体速度差未做隔离剖析。上述审计证明分数语义冲突移除与产物身份一致，但遗漏了渲染/标签逐样本一致性；不能据此确认数据或全部实现正确。
