## 问题、假设与文献定位

- 基础计算问题与已有方法的具体失效：弱光下单次测量不足以支持精细判断；扩大空间范围或累积更多
  时刻能增加可用信号，但会混合不同物体、模糊细边缘或引入控制滞后。普通 EMA、Kalman、ConvGRU
  和 motion-compensated averaging 各自固定了「支持哪些采样」这一决定，不能按测量可靠性、运动与
  动作精度重新组织。
- 预期优势、适用范围与可能反例：在相同因果观测、曝光与后端下，按测量可靠性/运动/动作精度**重新
  组织支持域**，改善弱信号利用、定位与反应速度之间的取舍。可能反例：只提高静态平均信噪比却在快速
  细边缘上拖尾；或完全退化为最大窗口平均。
- 启发来源：天蛾弱光时空求和（Stöckl 等 2016）与低光运动跟踪（Sponberg 等 2015）提供「积分时长与
  运动速度存在交叉取舍」这一**生物观察**；RAFT 的局部相关/recurrent update 提供工程组织；
  unfold/grid_sample 提供向量化。工程抽象与生物事实分开记录：本候选不声称复现任何生物算法。

| 最近工作的规则与框架（原始来源） | 本候选拟新增的设计 | 可检验差异与反证 |
| --- | --- | --- |
| 固定窗口平均、EMA、Kalman 递归估计（FilterPy 参考） | 支持域 = 空间半径 × 时间长度的笛卡尔积；窗口偏移是域内采样；每个原始采样在域内只有一个最终系数 | 同历史/曝光下，精度或时延损失是否抵消弱信号收益 |
| ConvGRU 时序编码（RAFT `core/update.py`） | 支持图的一跳局部合并/分裂 + 迟滞；分裂后**从唯一观测缓冲重算**子域统计 | 候选去掉 merge/split 后是否等价于固定平均 |
| motion-compensated averaging | 因果对应只服务积分（`CausalCorrespondence`），不做自运动/外部变化分解（N04） | 相同 correspondence 下，重组是否优于固定对齐 |
| softmax 注意力/门控 | `SupportSelector` 以可解释代价选择或输出**混合权重**，并报告有效域数 | 学习版是否优于解析版；选择开销是否被计入实测成本 |

局部公式等价性检查：本候选的逐源加权 `w_i = m_i c_i /(v_i + eps)` 在 `c_i ≡ 1` 时退化为已知的
逆方差加权平均；`V_diag` 在独立噪声假设下退化为标准加权方差。整体组织差异在「支持域何时合并/分裂」
与「何时缩短历史」，不在单个算子。与同家族 F06（增量执行）的重叠：本候选的预算条件化只减少候选
半径/时间档/更新块数，不实现异步增量执行，保留 F06 的独立性。

## 生物启发与弱证据机制（适用时）

- 关联机制问题：N01 自适应时空证据积分。F 是架构家族，PI 是评价维度，此处不互相替代。
- 生物原始实验与支持的观察：天蛾在极弱光下以时空求和换取可靠性，且该收益伴随分辨率/响应代价；
  低光运动跟踪显示速度与积分时长存在交叉影响。这些只支持「取舍存在」，不支持本候选的具体规则。
- 工程抽象与拟新增计算规则：`support_edges`/`support_age`/`last_seen`/`history_ids` 显式状态，
  一跳局部支持图 + 迟滞合并/分裂 + 分裂后重算 + 预算条件化读出。
- 神经/非神经实现选择：`matrix`（解析 gate + 可学习残差）与纯解析路径都在；`learnable_gate=False`
  给出严格解析对照。最近机制基线 6 个 + 2 个消融（见 `src/owac/baselines/n01.py`）。
- 测量/先验/记忆作用与支持来源：全部统计只来自真实测量缓冲；feature 更新不回写缓冲；重复帧
  （`new_measurement=False`）不产生新的独立证据，测试逐项覆盖。
- 积分方向的空间细节/时间常数/运动与控制期限如何共同验证：见实验记录「机制矩阵」与三条轨迹。

## Physical intelligence 增量

- 对应物理决策问题与首项闭环场景：弱边缘下的精确放置；目标快速移动时的持续定位与反应速度取舍。
  具体失败模式：固定长积分让快速细边缘拖尾，固定短积分在弱光下无法定位。
- 最近具身方法及已覆盖能力：RawVLA 的动作监督流式 ISP 已覆盖「RAW 直接进 VLA 并闭环」，其输出
  仍是图像；本候选不把「RAW 接入」「时序状态」当首创。
- 本候选拟新增的计算规则与可复用性：支持域合并/分裂规则 + 迟滞 + 分裂后重算 + 代价化读数；
  可复用于一维异方差序列（`input_mode="sequence1d"` 的 adapter 复用同一积分/分裂规则）。
- 新规则应改变的动作/观测/恢复能力：定位精度与恢复帧数（转向后、遮挡解除后），以及何时缩短历史。
- 成像干预中固定/改变的因素：固定物理状态与目标，改变曝光/噪声；弱信号收益不得以放宽任务精度换取。
- 物理或目标干预：改变目标运动速度与相邻目标分离距离；正确动作随几何改变。
- 目标/已执行动作/本体/历史与可观测性：任务精度与反应期限只在确实作为公开任务要求提供时进入代价；
  不输入目标真值位置（`SupportSelector.cost` 只读候选统计与预算）。
- 固定采集还是主动观测：固定采集；额外曝光/探测动作不在本轮范围。
- 当前具身证据与边界：**未建立**。本轮有合成机制、真实 NPZ 动作梯度与独立服务证据；无真实闭环。

## 完整框架设计契约

| 层面 | 当前设计及未解决问题 |
| --- | --- |
| 状态与表示 | 每相机 `N01State`：≤8 个唯一帧的因果环形缓冲（测量/方差/有效位/帧号/时间戳/年龄）+ 每平面一跳支持图 `edges`、`support_age`、`last_seen`、`history_ids`；显式 open_edges 保存迟滞开闭；长期状态是支持关系与其年龄。统计量以 `[C,B,P,H,W]` 候选张量表示 |
| 交互与拓扑 | 同 CFA 平面内 (左, 上) 一跳邻接；支持域是半径窗口内沿边路径连通的采样集合；分裂后从唯一缓冲重算。平面间语义混合只在 feature stem |
| 组合与扩展 | 宽度 32/64/128、block 数 2/3/4、历史 8、空间半径与时间档独立可调；tiny 完整跑通，small/medium 可实例化 |
| 学习与推理 | 解析 gate（`data_gate × edge_gate × distance × motion`）零初始化学习残差；选择器解析代价 + 可选学习 logits；推理与训练共用同一 `step`，TBPTT 边界 detach |
| 数值与硬件实现 | FP32 累计；`unfold` + 有界逐源系数向量化，另有逐源 Python 参考解；实测 CPU 单步时延与状态字节数见实验记录 |
| 通用输入与读出 | `rawvla_rgb3`（三通道 pseudo-RAW/HDR-derived）、`bayer_cfa`（2×2 重排为四平面，记录相位与 RGGB/BGGR/GRBG/GBRG 语义）与 `sequence1d`（一维异方差序列 adapter，复用同一积分/分裂规则且全程无 Conv2d）；读出 256×2048 受控配置与实名 CPU 测试配置分开 |
| 复用与工程接口 | `SupportDomainIntegrator`（含 `edge_field`/`update_edges`/`domain_statistics`/`reference_domains`/`edge_field_reference`）、`CausalCorrespondence`、`N01Encoder.step/readout`、`MechanismProbe` 统一 probe 接口 |

- 最小状态与方程/算法：`w_i = m_i c_i /(v_i+eps)`，`mu = S/(W+eps)`，`V = Σ w_i² v_i /(W²+eps)`，
  `age = Σ w_i (t-t_i)/(W+eps)`；`c` 为支持路径权重（边权乘积，带下限），连通性是边的开/关判定。
- 完整端到端草图：`MeasurementStem → SupportDomainIntegrator → EvidenceBlock×N → SpatialReadout`，
  再经 `VisualTokenPostprocessor` 进入 π0.5 语言宽度前缀。
- 最小机制原型与差距：合成弱边缘/窄缝定位 + 机制矩阵；与完整结构的差距是充分调优真实适配与闭环。
- 外部接口：`MeasurementFrame/EmbodimentContext/ComputeBudget/EncoderOutput/VisualTokens`
  见 `src/owac/core/encoder_contract.py`。
- RAW 接口：`x=(raw-black)/(white-black)`，保留缺失/坏点/饱和三 mask，四平面记录相位。
- 后端/预训练/适配容量/读出成本：π0.5 冻结语言+动作，新增读出参数 4,763,651（256×2048，3 相机）；
  真实权重已在固定服务器通过离线前向/反向。
