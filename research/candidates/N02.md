## 问题、假设与文献定位

- 基础计算问题与已有方法的具体失效：局部测量不足时，先验/历史可以帮助提出结构解释，但普通
  递归编码与预测编码会把“当前最好的猜测”不断固化；当新测量否定该解释时，普通循环需要把整个
  状态重新推一遍，且容易把同一 likelihood 在多轮迭代里重复累加。已有方法（贝叶斯滤波、DPF、
  预测编码、现代 Hopfield）分别覆盖了候选加权、运动模型与联想读取，但**反证到达后“哪些关联
  状态必须更新、哪些仍可保留、有限计算优先用在哪里”**这一局部修订调度没有直接对照。
- 预期优势、适用范围与可能反例：优势应体现在反证后的纠错帧数/内部迭代数、错误解释的持续
  面积以及未被反驳区域的漂移；可能反例是“只在先验正确时有收益”“把 prior 置零才纠错”“循环
  增加即置信度上升”。真实场景中若反证本身不可辨识（例如遮挡后无任何区分性线索），正确行为
  是保持歧义而不是给出更自信的答案。
- 启发来源：视觉补全与预测编码的生物/计算动机（Tang 等；Rao & Ballard）是**启发**，不是本
  候选新规则的证据；“多假设”“循环”本身不构成新颖性。

| 最近工作的规则与框架（原始来源） | 本候选拟新增的设计 | 可检验差异与反证 |
| --- | --- | --- |
| 可微粒子滤波（Karkus 等，`tu-rbo/differentiable-particle-filters` 固定提交）：proposal → 权重 → 重采样 | 候选不重采样，而是保留 K 个显式解释并做**局部**重组；权重来自冻结测量集上的完整能量 | 同 K、同测量函数、同历史下比较纠错速度与错误解释持续面积；若只有重采样/加权形式不同而无行为差异，则不构成机制差异 |
| 预测编码 / PredNet（Rao & Ballard；coxlab/prednet）：预测、残差与循环状态 | 残差不再只驱动状态更新，而是先转成**矛盾图**，再沿**有记录的依赖边**传播一跳，决定本轮允许更新的区域 | 关掉依赖传播/反证重置后行为应退化（已有消融开关）；若关闭后无差别，则修订调度无贡献 |
| Belief Propagation NN（Yoon 等）：可学习消息传递、避免重复计算证据 | 依赖边是“u 的解释依赖 v”的记录，**不当作物理因果**；同一测量集合在一次 step 的循环内冻结，完整分数重算而非累加 | 重复提交同一观测必须使 unique evidence 不变、posterior 不变；静态精确例必须与闭式 Bayes 一致 |
| 现代 Hopfield / 联想记忆：关联读取 | 作为可选读出基线；关联检索不能代替测量支持与反证撤回 | 未实现（本轮范围外），不得以“Hopfield 检索”声称 N02 已成立 |

局部公式等价性检查：单假设、单次迭代、无矛盾时，本候选退化为“用测量能量加权一个循环 cell”，
与预测编码的差别只剩残差进入方式与调度；因此机制主张必须落在**多假设 + 反证调度**上，而不能
落在 cell 本身。与 N01（支持域积分）相比，N02 不改变测量支持域的合并/分裂，只维护解释集合；
与 N04 相比，N02 不建模自运动传播，历史只经一次状态转移进入 prior。

## 生物启发与弱证据机制

- 关联机制问题：N02（测量约束的循环补全）；架构家族 F02/F05/F10；PI 维度中对应“动作相关信息”
  与“可靠性与恢复”。
- 生物原始实验、任务及支持的观察：遮挡补全（Tang 等 PNAS 2018）、预测编码（Rao & Ballard 1999）
  支持“高层预测 + 低层残差 + 反复求解”的组织方式；这些实验不证明本候选的修订调度有效。
- 工程抽象、拟新增计算规则：把“反证”实现为**相对最好解释的归一化残差阈值**，把“依赖”实现为
  4 邻域可学习兼容性表，把“局部重组”实现为 gate 选择 + 共享 ConvGRU cell + proposal 重建。
- 神经/非神经实现选择：本实现是神经核心 + 显式调度（阈值、衰减、重置比例、停止容差均为配置）。
  最近机制基线：K=1 单假设、普通 ConvGRU、DPF 风格粒子/多假设滤波、dense 全局循环。
- 测量、先验、记忆各自作用与支持来源：测量只经 stem 与能量项进入；先验来自上一步的总能量
  （时间更新，不是同一观测的第二次 likelihood），其权重 `beta_prior` 有显式上下界并在本轮
  按配置固定；记忆（N03）不参与。歧义读出：`map_hypothesis` 与 `hypothesis_tokens` 两种，
  后者给每个候选独立 token 组并附权重与支持。
- 若使用补全（是）：先验正确/无信息/误导/缺失/陈旧五条件在生成器与解析例中显式建模；反证
  修订用 `RevisionController` 的 contradiction → 依赖传播 → 局部重置验证；不可辨识条件用
  “cue 落在两假设重合点”的序列验证 posterior 保持 0.5/0.5。
- 额外历史、模态、观测或计算的预算与对照：历史长度 4（tiny）与基线共享；无额外模态、无主动
  探测；不把重复测量或模型自身预测当作新观测。

## Physical intelligence 增量

- 对应的物理决策问题与首项闭环场景：**错误先验下的补全与纠正**——局部外观相似但开口/把手
  方位不同的物体，先给歧义线索，再给支持或反驳的新证据；失败的决策是“坚持不存在的结构并据此
  抓取/插入”。首个闭环场景仍是冻结的 RawVLA-Bench（LIBERO/RoboTwin），本轮未运行。
- 最近具身方法及其已覆盖能力：RawVLA 的动作监督流式神经 ISP 已覆盖“RAW 域处理接 VLA”；
  Dr. RAW 覆盖任务条件化；M³A 覆盖材质外观增强。这些都不做“反证驱动的局部撤回”。
- 本候选拟新增的计算规则与可复用性：可切换的反证调度（定位 → 依赖传播 → 局部重组）与
  “同一测量集合循环重算但不重复计数”的能量契约；两者都与具体 cell 解耦，可迁移到其它潜结构
  解释（槽口位置、连通性、把手方位）。
- 新规则应改变的动作能力：反证到达后应更快撤回错误解释并改变抓取方位/插入位置；反证不可
  辨识时不应武断收敛。能否由更强控制器解释：普通 ConvGRU 基线获得相同历史与循环预算，
  若它同样快，则机制主张不成立。
- 成像干预：固定物理状态与目标、改变噪声/遮挡；合理行为是信息足够时保持正确决策、信息不足时
  保持歧义或降低置信。
- 物理或目标干预：改变关键几何（开口朝向/把手方位）与指令；正确动作应随之改变。本轮只做
  测量域机制验证，动作标签来源在真实阶段必须由示范提供，不能由机制实验伪造。
- 目标、已执行动作、本体信息、历史与可观测性：本轮编码器不使用本体与已执行动作（它们在本
  方向的假设中不是必需）；真实接入时它们经 `EmbodimentContext` 声明为可用/不可用，未来专家
  动作与仿真隐藏真值禁止进入编码器输入。
- 固定采集还是主动观测：固定采集；主动验证属 N06，另计成本。
- 当前具身证据与边界：**未建立**。仅有测量域机制证据与解析参照。

## 完整框架设计契约

| 层面 | 待回答内容 | 当前设计及未解决问题 |
| --- | --- | --- |
| 状态与表示 | 对象类型、位置/时间/有效性、长期状态 | `h[B,V,K,D,h,w]` 假设场 + 每个 batch 元素一份有界 `MeasurementBuffer`（唯一 ID、mask、采样条件、方差）。K 是解释数，不是额外观测数。位置由固定坐标编码承载；有效性由 mask 与 `Validity` 承载。待解决：跨相机 V>1 的残差证据目前只在单视图定义（多视图需显式扩展而不是广播） |
| 交互与拓扑 | 组合/竞争/绑定/传播 | 竞争来自冻结测量集上的 softmax 能量；绑定是“同一潜结构”的候选组；传播沿 4 邻域 `dependency_edge[B,V,h,w,4,K,K]`，一跳，可关。主要计算在局部 cell + gate 选择的区域。待解决：稀疏/长程关系 |
| 组合与扩展 | 组合单元与扩展轴 | 单元 = stem + 测量头 + initializer + cell + proposal + 读出。扩展轴：K（候选数）、D（宽度）、cycles（循环）、history（历史）、分辨率/网格、token 预算。tiny/small/medium 为三档；K/宽度/循环需分别消融，不能一起增长后归因单项 |
| 学习与推理 | 学习量与解析量 | 学习：stem、测量头（含 variance）、initializer、cell、proposal、位置 gate、兼容性表、读出投影。解析/配置：阈值、衰减、重置比例、停止容差、beta_prior 上下界。状态初始化在 `init_state`，维护在 `step`，清空在 `reset`，训练在 TBPTT 边界 `detach_state` |
| 数值与硬件实现 | 复杂度、精度、内存、时延 | 实测 tiny CPU：encoder step p50/p95 28.6/39.6 ms（64×64 bayer 输入、4 次循环、未预热）、状态 214 272 B。实际实现是 Python 级研究原型，未做算子融合/稀疏化；峰值显存未测量（无 GPU） |
| 通用输入与读出 | RAW 适配与核心边界 | 输入适配：`bayer_cfa`（单通道、真实采样坐标、四平面分离）与 `rawvla_rgb3`（三通道 pseudo-RAW）使用**不同**测量头，核心规则共用。读出：每相机 256 token × 2048 维，K=4 时每组 64；地图读出与分组读出并列。核心必须保留的规则：预测不写回测量、同一集合循环重算不加倍、反证可局部撤回 |
| 复用与工程接口 | 最小 API、参考实现、配方、评测 | `owac.core.encoder_contract`（共同 v0 契约）、`owac.frameworks.n02.*`（核心）、`owac.baselines.n02`（最近基线与消融）、`owac.training.n02` / `owac.evaluation.n02`（配方与评测）、`owac.backends.rawvla_features`（π0.5 特征桥）。命令见实验记录 |

- 最小状态与算法：见 `model.py` 的循环与 `measurement.py` 的能量定义。**不声称**收敛保证、
  精确去重或线性复杂度：本轮只证明“同一集合上重算不加倍”与解析例一致。
- 完整端到端草图与执行顺序：观测适配 → 缓冲（唯一证据）→ stem/测量头 → 候选初始化 →
  （能量 → 矛盾图 → 依赖传播 → 局部更新/提议）× cycles → 读出 → π0.5 前缀。
- 相互作用与组合：N02 与 N01 正交（不改支持域）、与 N03 可组合（记忆作为 prior 来源之一）、
  与 N04 可组合（历史经运动传播进入 prior）、与 N06 可组合（歧义触发探测）；本轮不串联。
- 学习规则与训练目标：`L = L_measurement + L_geometry_set + 0.1*L_revision + 0.01*L_diversity`
  （权重在配置内，各项归一化与有效样本数分别报告）；真实 NPZ 阶段以 π0.5 原动作损失为主。
- 量化/数值/硬件假设：解析例与早期方差计算用 FP64/FP32；未做 BF16 验证。
- 可证伪预测与最大风险：最大风险是“局部修订调度在学到的 latent hypothesis 上不产生可测差异”，
  此时应保留为诊断工具而不是机制贡献。
- 接口与复用规则：核心不与读出耦合；读出参数计入编码器；不生成中间 RGB。
- 当前证据与未解决项：见文末。

## 当前证据与未解决项

- 已有证据：解析两假设例与闭式 Bayes 一致（最大偏差 2.5e-8，受 float32 测量缓冲限制）；重复
  观测不增加 unique evidence 且 posterior 不变；强错误先验可被 2σ 有效反证改写（0.9972），
  且该纠错不是靠 `beta_prior=0`；不可辨识序列保持 0.5/0.5；真实 `RevisionController` 在
  residual `[5.0, 3.0]` 上只反驳被证伪的候选并局部重建；tiny CPU 时延与状态成本已实测。
- 未解决 / 下一步问题：
  1. 学到的 latent hypothesis 上，反证调度相对普通 ConvGRU/DPF 是否有可测的纠错优势（同 K、
     同历史、同循环预算）？这是机制主张的核心，尚未完成。
  2. 候选多样性是否来自物理解释而不是 latent 距离？需要合成多解任务上的覆盖指标与动作/定位
     探针，而不是欧氏距离。
  3. 真实 NPZ（三通道 pseudo-RAW）与 π0.5 动作损失下的行为，以及测量预测辅助损失的取舍。
  4. 多视图残差证据、稀疏/长程依赖边、BF16 与 GPU 时延。
  5. 概率语义：当 `beta_prior` 与温度未标定时，weights 只能称相对解释权重，不能称真实概率。
- 交叉评审记录：待定。
