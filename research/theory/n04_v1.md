# N04 v1.0 理论：坐标、单位、生成模型与性质的适用边界

状态：S0 合同文档（工作流 A2）。本文把 `docs/plans/N04_full_development_v1.0.md` §6–§7
已有的坐标约定、误差模型和四条性质写成可检查的表述，并交出像素↔米的换算依据。

本文**不主张**新的数学性质或首创性：协方差半正定、Joseph 更新、nuisance 消元、
Lipschitz 误差界和 Poisson–Gaussian 噪声都是既有估计/成像结论，来源见方案 §7 与 §15
的 [R12]/[R15]/[R17] 等条目。本文新增的是 OWAC 的**坐标与单位合同**及其可执行检查
（`src/owac/frameworks/n04/measurement_geometry.py`、`proprio.py`、对应测试）。
本文仍属 S0：没有真实标定、没有 S4 的数值对照与覆盖率实验，也没有验证任何模型效果。

## 1. 单位表

所有跨模块传递的量必须能落到下表之一；单位不一致时显式报错，不做隐式换算。

| 量 | 字段 / 参数名 | 单位 | 定义与落点 | 禁止 |
| --- | --- | --- | --- | --- |
| 三维位置、深度 | `p_W` / `p_C` / `depth_m` | **米 (m)** | `project` / `unproject` / `T_A_from_B` | 用像素或 DN 冒充深度 |
| 时间间隔 | `dt`（`time_unit="frame"` 仅当无秒） | **秒 (s)** | 只在有真实时间戳时填；帧号不是秒（`proprio_delta` 的 `dt=None` 分支） | 把帧差写成秒 |
| 旋转量 | 轴角、相对旋转向量 | **弧度 (rad)** | `rotvec_to_quaternion` 等，wxyz 边界保留 | 度/弧度混用（除非显式换算） |
| 原图像素 | `original_px` | **测量像素 (px)** | `CameraIntrinsics.unit` 默认；§11.2 的 0.05 px 绝对门槛在此单位 | 当作特征像素 |
| 特征像素 | `feature_px` | **特征像素 (feature px)** | stride 缩减网格；K 经 `on_feature_grid` | 当作原图像素 |
| 归一化采样坐标 | `grid` | 无量纲 `[-1, 1]` | `grid_sample`（`align_corners=False`） | 与像素坐标直接相加/比较 |
| RAW 数字数 | DN | **DN**（12 bit，黑 64 / 白 4095） | `configs/n04/full/s0_data.json` 的 `mechanism_data.d0.cfa` | 标定/线性化前当作物理量 |
| 协方差 | `P`、`R`、`Σ_η` | **对应量单位的平方** | §4 的误差模型 | 不同单位的协方差相加或互相替代 |

强制手段（代码层）：

* 像素坐标用 `PixelPoints(xy, unit)`，内参用 `CameraIntrinsics(K, unit)`；把
  `feature_px` 的点交给 `original_px` 的内参（或反向）抛 `PixelUnitError`。
* 所有仿射换算走 `PixelAffine`，其 `apply` 检查源单位、`compose` 检查中间单位。
* 坐标系用 `T_A_from_B` 标签；复合/作用时 frame 不一致抛 `FrameMismatchError`。
* 深度参数名固定为 `depth_m`；秒/弧度不做隐式假设。

## 2. 坐标约定

### 2.1 变换命名与刚体代数

`T_A_from_B`（A←B）把 B 系坐标变到 A 系：`p_A = T_A_from_B @ p_B`。复合
`T_A_from_C = T_A_from_B ∘ T_B_from_C`，逆为 `T_B_from_A = (T_A_from_B)^{-1}`；逆用
`R^T` / `-R^T t` 闭式解。方案 §6.1 的传播链因此写作

```text
p_C(t-1) = depth(t-1) * K(t-1)^{-1} * homogeneous(pixel(t-1))
p_C(t)   = T_C(t)_from_W ∘ T_W_from_C(t-1) @ p_C(t-1)
pixel(t) = project(K(t), p_C(t))
```

独立物体运动在世界系或明确的物体局部系中传播，再变到当前相机系；不允许把两个
不同参考系的增量拼在同一个变量里。

### 2.2 相机系与像素中心

仓库沿用标准针孔约定：相机系 C 为 **x 向右（列）、y 向下（行）、z 向前（深度）**，
`u = fx X/Z + cx`、`v = fy Y/Z + cy`（见 `geometry.project_points` /
`unproject_pixels`）。像素坐标是**连续量**，整数落在像素中心。

统一 `align_corners=False`：`n = 2 (x + 0.5) / W - 1`；有效采样域
`x ∈ [-0.5, W-0.5]`（首末像素中心向外半个像素的边缘）。统一
`padding_mode="zeros"`：越界位置取值 0 **并且**支持掩码置 0，禁止用
border/reflection 把从未观测到的像素搬成历史证据（`geometry.GridSpec` 直接拒绝
`align_corners=True` 与非 zeros padding）。

### 2.3 与外部 `align_corners=True` / border 约定的换算

同一个物理采样点在两种约定下的坐标满足 `2 x_true/(W-1) = 2 (x_false+0.5)/W`，因此

```text
x_false = x_true * W / (W - 1) - 0.5
x_true  = (x_false + 0.5) * (W - 1) / W
```

Y 方向同理（W 换成 H，要求边长 ≥ 2）。`align_corners_false_from_true_xy` /
`align_corners_true_from_false_xy` 实现这一对换算且保留像素单位。

缩放的差别同样必须换算：仓库 `align_corners=False` 的中心映射是
`x_dst = s x_src + (s-1)/2`（`s = dst/src`），而外部 `align_corners=True` 的缩放是
`x_dst = x_src (N_dst - 1)/(N_src - 1)`（无半像素项）。两者不是同一个数，不能只换
`padding_mode` 或只换 `align_corners` 标志就拼接；要么在坐标层先换算，要么按仓库约定
重新缩放。border padding 是另一套取值模型：即使坐标换算正确，它的边界取值也不是本
仓库的 0/无支持语义，外部结果必须显式重算有效性掩码后才能进入本管线。

### 2.4 裁剪、缩放、stride 与特征网格

* 裁剪：新原点在源坐标 `offset`，`p_new = p_src - offset`（像素中心不变）。
* 缩放（`align_corners=False`）：`x_dst = s x_src + (s-1)/2`，`s = dst/src` 逐轴计算。
* stride（原图 → 特征）：中心对齐 `f = (u + 0.5)/s - 0.5`；旧 `GridSpec.pixel_stride`
  的角点约定是 `f = u/s`。两者在 `u` 处相差 `(s-1)/(2s)` 特征像素
  （`s=32` 时为 `31/64 = 0.484375`）。**中心对齐才是与 `align_corners=False` 自洽的
  默认值**；角点约定只作为旧接口对照显式给出。真实骨干（ConvNeXt-B 的下采样、padding
  与 kernel 组合）的实际对齐必须在 S1 用逐层数值探针测量，不能靠 stride 数字推断。
* 内参同步更新：`fx' = s fx`，`cx' = s (cx + 0.5) - 0.5`（逐轴）。只乘焦距而不平移
  主点会引入 `(s-1)/2` 像素的中心误差。stride 时 `fx' = fx/s`、
  `cx' = (cx + 0.5)/s - 0.5`。

### 2.5 CFA 四相位

2×2 排列下平面像素 `(i, j)` 对应原图格点 `(2i + δy, 2j + δx)`，`(δy, δx)` 取自
`(0,0)/(0,1)/(1,0)/(1,1)` 的四个相位。四相位（R/G1/G2/B）各自持有自己的原点，不允许
共享一个忽略相位的坐标；平面名 `"G"` 不唯一，必须写 `G1`/`G2` 或 `Gr`/`Gb`
（本模块定义 `G1` = 表中光栅序在前的绿色相位，是显式约定而非通用记号）。
例如 GRBG：`Gr(0,0)`、`R(0,1)`、`B(1,0)`、`Gb(1,1)`，平面 `(i,j)=(2,3)` 分别落在
`(4,6)/(4,7)/(5,6)/(5,7)`。该表与 `synthetic.CFA_PLANE_OFFSETS` 有交叉一致性测试。

## 3. 生成模型

S0 固定结构，不声称任何参数已被标定。测量由以下链条生成（§6.1、§6.3）：

```text
世界状态 x（相机位姿、物体运动、三维结构/深度、场景辐射）
  --标定/干扰 η（K、T、畸变、时间偏移、曝光/增益）-->
投影 + 可见性（z-buffer、遮挡、出生/出界、支持掩码）
  --采样/量化（原始像素或 CFA 相位；三通道 pseudo-RAW / 原生 Bayer 分列）-->
测量 y
```

几何分支的观测方程写作 `y = h(x, η) + ε`，其中 `h` 是带掩码的投影
`π(K, T_C_from_W, p_W)`：负深度、越界和多对一遮挡不产生“猜测像素”，只产生掩码
（`project_with_support` / `z_buffer_visibility`）。RAW 分支的完整噪声与增益模型属于
S4 交付；S0 只固定其**单位与相位坐标**（DN、黑电平 64、白电平 4095、CFA 相位原点），
以及“三通道 pseudo-RAW ≠ 原生 Bayer”的边界。

## 4. 误差模型（方案 §7.1）

在线性化点 `(μ⁻, η̂)` 附近，残差与状态/干扰误差满足

```text
r = y - h(μ⁻, η̂) ≈ H e + J_η δη + ε
e = x - μ⁻,   Cov(e) = P⁻,   Cov(δη) = Σ_η,   Cov(ε) = R,   C = Cov(e, δη)
S = H P⁻ Hᵀ + J_η Σ_η J_ηᵀ + H C J_ηᵀ + J_η Cᵀ Hᵀ + R
K = (P⁻ Hᵀ + C J_ηᵀ) S⁻¹
```

假设与成立条件：

* `h` 在该点可微，一阶展开的高阶项可忽略（强非线性、大时间偏差、滚动快门不在此列）；
* `e`、`δη`、`ε` 的**二阶矩**存在且如上式（协方差代数只需要二阶矩，不需要高斯性）；
* `S` 可逆（异常/秩亏情形单独处理为不可辨识，见 §6）。

`C = 0` 是**需要论证的假设**，不是默认值：状态与标定若来自同一段历史估计，必须用联合
状态/交叉协方差，或明确验证保守近似；不能默默假设独立。

### 4.1 一个误差源只能进入一处

规则：**同一次误差（或同一段历史）不能既表示在 `P⁻`/`C` 里，又重复计入 `R`。**

| 误差源 | 允许进入 | 不允许进入 | 检查点 |
| --- | --- | --- | --- |
| 状态估计误差 `e`（来自历史测量） | `P⁻`、与干扰的交叉项 `C` | `R` | `R` 只放**当前**测量的噪声/模型误差 |
| 当前测量噪声 `ε`（读出、量化） | `R` | `P⁻` | 与历史无关 |
| 相机位姿 / 外参 / 内参误差 `δη_cal` | `Σ_η`、`C`（若与状态共同估计） | `R`（若已进 `P⁻`/`Σ_η`） | 同一标定误差只能选一处 |
| 时间戳 / 曝光时刻误差 `δη_t` | `Σ_η` | `R` | 需要时间误差模型（[R14] 类参照） |
| 曝光 / 增益残差 | 显式建模进 `Σ_η`，或作为当前测量的 `R` 项 | 两边同时 | 建模位置写进配置 |
| 重复使用同一历史测量 | `C`（相关性） | “`R` 独立”的隐含假设 | 每个 measurement ID 只融合一次 |

补充边界（§7.1）：神经潜在特征的 `R` 必须在**自身单位**下学习和校准；RAW 像素方差
不能直接塞进任意非线性特征的协方差。几何、噪声与协方差保持 FP32，数值参照与有限差分
用 FP64（方案 §7.2、实现合同）。

## 5. 性质 A–D：假设与适用边界

### 5.1 性质 A：协方差的半正定性（§7.2）

陈述：`P⁻ = A P Aᵀ + Q` 在 `P, Q ⪰ 0` 时半正定；Joseph 形式
`P⁺ = (I - K H) P⁻ (I - K H)ᵀ + K R Kᵀ` 在维度正确、`R ⪰ 0` 时对**任意** `K` 保持
代数半正定。

假设：`P, Q, R` 对称半正定，维度一致，精确算术。实现要求：Cholesky / 正值参数化、
方差下界、FP32 更新，另加小维度 dense 参照；RKN 结构化协方差必须满足每 2×2 块的
`P_u ≥ 0`、`P_l ≥ 0`、`P_u P_l - P_s² ≥ 0`，不能只对对角线做 softplus。

边界（不可保证）：这只保证**数值结构**，不保证估计方差等于真实误差；当增益依赖当前
残差、使用关联筛选或非高斯门控时，Joseph 输出不是精确的 Bayesian 后验协方差。S4 必须
另做经验覆盖率检查；S0 尚未实现该检查。

### 5.2 性质 B：对局部干扰的一阶不敏感性（§7.3）

陈述：对严格正定的 `R = L Lᵀ` 令 `Jw = L⁻¹ J_η`，取 `U` 为 `Jw` 列空间的正交补基
（`Uᵀ Jw = 0`），则 `e_perp = Uᵀ L⁻¹ r` 满足在当前线性化点
`∂e_perp / ∂δη = 0`（一阶项）。

假设：`R ≻ 0`、Jacobian 在该点精确、`U` 正确张成正交补。代价与边界：真实物体运动
的方向若落在 `Jw` 的列空间内也会被一并消去；外部运动的测量 Jacobian 为 `Jd` 时，
只有 `rank(Uᵀ L⁻¹ Jd)` 个方向保留。大时间偏差、强旋转与滚动快门的高阶项不在保证内。
这是估计中的 nuisance 消元原理（方案 [R15]），不是新发明。

实现边界：主路线用带先验不确定性的**边缘化更新**，硬投影只作独立对照；两者不能无审计
叠加，也不能先把同一残差拟合标定、再按未拟合自由度计算显著性。

### 5.3 性质 C：缺失阶段的有限时域误差界（§7.4）

陈述：若传播 `f` 在考察区域有 Lipschitz 常数 `L`，每步模型与扰动误差上界为 `b`，
缺失 `k` 步后

```text
||e_k|| ≤ L^k ||e_0|| + b * Σ_{i=0}^{k-1} L^i
```

假设：`f` 在该区域内 Lipschitz、每步误差确有上界 `b`、考察区域不跨越动力学切换。
边界：**不能假定所有物理系统 `L < 1`**——匀速位置积分本身就会累积速度误差，强制收缩
会破坏正确动力学；线性状态还需报告 `A` 的 `k` 次乘积与过程噪声累积。RKN 只在局部近似
条件下使用这些诊断，不继承 IEKF 的稳定性定理（[R12] 的条件是系统结构 + 可观测性 +
局部性）。看不见期间、没有任何额外线索的停止/反向**不可被保证提前预测**；目标是扩大
不确定性、保留多种可能，并在恢复测量后迅速修订。

### 5.4 性质 D：成像尺度与统计阈值一致性（§7.5）

陈述：独立 Poisson–Gaussian 近似下，黑电平校正后的 RAW 方差可写为
`Var = α * signal + β`（[R17]）；乘性增益 `g` 使方差乘 `g²`；线性重采样 `W` 的完整
协方差是 `W Σ Wᵀ`。

假设与边界：

* 只有**独立输入的单点方差**才能写成权重平方求和；插值后的相邻像素一般相关。
* 参考帧也有噪声时，差分残差要同时计入当前与参考的不确定性，以及重复使用历史带来的
  相关性。
* 饱和与裁剪破坏零均值 Gaussian 假设：应屏蔽或用截断似然，不能把饱和像素的低残差当
  高置信。
* 标准化创新平方只有在模型正确、线性 Gaussian、自由度与选择过程明确时才能按 χ²
  解释；实际特征在独立开发集上校准，并在轨迹层报告覆盖率、分组误报和可靠性。
  默认不承诺任意分布漂移下的统计覆盖。

## 6. 可辨识反例（§7.3、§9.1）

以下都是**在 §3/§4 的模型下**的不可辨识/退化情形；它们不构成对任意估计器的一般定理，
但要求系统输出“解释不唯一”而不是高置信原因：

1. **单移动平面占满视野**（D0 factor `unidentifiable_full_view_plane`）：平面诱导的
   观测是单应，相机运动与平面参数只能在尺度意义下联合确定；整幅画面都是移动平面时没有
   静态参照给自运动/标定定锚，`H` 与 `J_η` 的主要方向重合，分解不唯一。
2. **相机与物体以相同刚体运动运动**：测量只能约束相对运动；把同一残差分配给 `e`（状态）
   还是 `δη`（相机位姿）没有额外依据，`Jd` 落入 `Jw` 列空间，性质 B 的秩条件退化。
3. **深度不可确定**：单目单帧有尺度模糊——`p_C = depth * K⁻¹ [u,v,1]` 中深度与相机
   平移尺度可交换；光轴方向（视差为零）的运动在像素上一阶不可见。
4. **遮挡期停止/反向**：性质 C 明确不保证；正确行为是增大不确定性并保留多种假设。
5. **关联错误**：错误对应把残差配给错误的 `H`，超出局部线性化假设，需由门控/鲁棒似然
   处理并作为独立失败组报告（S0 只在接口层保留 unmatched 语义）。

对应的数据覆盖已列在 `configs/n04/full/s0_data.json` 的 D0 factors
（`static`、`camera_only`、`object_only`、`both`、`stop_reverse`、`occlusion_recovery`、
`unidentifiable_full_view_plane` 等）。

## 7. 像素 ↔ 米换算（`protocol.nominal_camera`，诊断参照）

来源：`configs/n04/full/s0_data.json` 的 `protocol.nominal_camera`
（`focal_px=320.0`、`depth_m=0.6`、`image_size=[256,256]`、`feature_stride=32`），配置
自带说明：“用于把像素门槛换算为米制门槛的诊断参照，不是真实标定；真实标定缺失时明确
标注。”仓库当前没有真实相机标定（`docs/status.md`：机器人本体、相机和数据留空），因此
以下全部数字**只作诊断参照**，不得当验收门槛或真实传感器标定。

公式（针孔、无畸变、无 skew；`cx, cy` 取图像中心 128）：

```text
u - cx = fx * X / Z        X = (u - cx) * Z / fx
=> 原图像素横向尺度 s_px(Z) = Z / fx        [m / original px]
   特征像素尺度   s_feat(Z) = stride * Z / fx   [m / feature px]（中心间距）
```

在 `fx = 320 px`、`Z = 0.6 m` 下：

| 量 | 数值 | 依据 |
| --- | --- | --- |
| 1 原图像素 | `0.6 / 320 = 1.875e-3 m = 1.875 mm` | 上式 |
| 0.05 原图像素（§11.2 绝对门槛） | `9.375e-5 m = 0.09375 mm` | `0.05 * 1.875 mm` |
| 0.05 原图像素折算到特征像素 | `0.05 / 32 = 1.5625e-3 feature px` | stride 32 |
| 图像半宽 128 px | `0.24 m` | `128 * 1.875 mm` |
| 图像全宽 256 px | `0.48 m` | `256 * 1.875 mm` |
| 1 特征像素（中心间距） | `32 * 1.875 mm = 60 mm` | `stride * s_px` |
| stride 中心偏移 `(s-1)/2` | `15.5 original px = 29.0625 mm`；或 `31/64 = 0.484375 feature px` | §2.4 |
| 水平视场（精确） | `2 atan(128/320) = 43.6028°` | 小孔几何 |
| 水平视场（近轴 / 切线近似 `W/f`） | `0.8 rad = 45.8366°` | 仅在近轴下成立 |
| 特征网格尺寸 | `256/32 = 8 × 8` | stride 32 |

`protocol.reference_2d.relative_improvement_min = 0.10` 是**无量纲**相对门槛，不需要
米制换算；只有 `absolute_improvement_px_min = 0.05`（原图像素）需要上面这一列参照。
