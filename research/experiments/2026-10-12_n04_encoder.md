## 运行前设计

- 可证伪假设与判据：
  - **H1**：相机自运动不应产生 external_change。判据 `camera_vs_object_change < 1`（越低越好）且优于同预算消融。
  - **H2**：照明变化不应被误判为物体运动。判据 `illumination_false_alarm` 明显 <1。
  - **H3**：错误的传播（标定误差/动作延迟）应能被测量纠正而不退化定位。
- 方法与对照：候选 `N04Encoder`（`learned_proprio`）；机制消融 `n04_no_ego`（传播退化为 identity）、
  `n04_no_change_branch`、`n04_all_residual_noise`、`n04_time_shifted_context`——**四者与候选同配置、
  同种子、同 200 步预算训练**。最近系统基线 `single_frame` / `convgru` / `motion_compensation` /
  `predict_update_filter` / `action_conditioned_recurrent` 目前**没有训练入口**，只在评测中作为
  随机初始化对照（单独列出，不与候选并列）。
- 信息条件：候选与全部对照共享 64×64 测量、12 帧窗口 / TBPTT 8、同元数据、同读出预算；
  `predict_before_observe()` 签名中没有测量参数。真实 NPZ 路径中缓存无可靠的已执行动作记录时
  `executed_action_available=False`。oracle 几何只在解析测试中使用，不进入本轮主结果。
- 机制矩阵条件：camera_only、object_only、both、illumination、same_direction、occlusion、
  calibration_error、action_delay、exposure_step。

## 本轮由实际运行暴露并修复的缺陷

| 缺陷 | 影响 | 修复 |
| --- | --- | --- |
| 评测场景未注入 `calibration_scale` / `action_delay` | `calibration_error`、`action_delay` 退化为 camera_only，机制矩阵出现整行逐位相同的数字 | `evaluation/n04.py` 显式传入；加回归测试 |
| `occlusion` 只写 `valid_mask`，而 `step()` 没有测量有效性入口 | 遮挡条件对编码器完全不可见 | `step`/`correct_after_observe` 新增 `measurement_valid`，断开更新门、change 写入、block 输入三条通路；训练与评测都传入 `valid_mask`/`saturated_mask` |
| 合成 `proprio` 含物体位移 | 外部运动泄漏进 ego 预测输入（捷径） | proprio/action 只保留自身运动（平移+旋转），加测试固定 |
| 变化幅值先压成标量再做掩码加权 | “目标处/目标外”恒等（change_contrast 曾为 4e-12） | 改为逐像素幅值图 + 归一化对比；无变化分支记 NaN |
| `change_branch=False` 时 `old_change` 未绑定 | 两个消融直接崩溃 | 无条件取出上一状态变化 cell |
| 逐样本平移传进只收标量的几何函数 | `motion_compensation` / `predict_update_filter` 崩溃 | 几何层支持 `[B]` 位移并校验 batch 一致性 |
| checkpoint 前缀与懒建层不匹配 | 消融 checkpoint 无法加载，“同预算对照”跑不出来 | key 前缀按重合度对齐 + 预建懒层；加载到 wrapper 与内层均可 |

## 解释与下一步

- 观察事实：传播与更新链路可训练、可复现、梯度贯通（冻结后端时动作损失仍回传到新编码器），
  解析几何/因果性/测量有效性都有测试；ego warp 误差相对 identity 传播减半。
- **H1、H2 未被支持**：同预算对照下相机自运动的变化响应高于物体运动（1.391），
  照明误报 0.959；去掉变化分支与照明分支后指标几乎不变。
- 区分原因（当前证据不足以判定“机制失败”）：
  1. **变化分支幅度极小**（~1e-3 vs stable O(1)），指标可能测不到差异；需要先把变化 cell 的量级与
     监督做起来（`L_change` 只在可识别标签上，200 步可能远不够）。
  2. 评测条件仍需加强：`same_direction` 只有 0.95 倍速、`occlusion` 只改有效性不改像素，
     最强反例（同向近同速、遮挡后新暴露）还没有真正的可识别性压力。
  3. 最近基线未训练，无法回答“候选是否只是更好的对应估计”。
- 与原计划的偏离：整数平移 → learned_proprio → 四类基本变化矩阵 → 模型误差/不可识别 已覆盖；
  CFA 相位/多视角有单元测试但无训练；真实 NPZ 与 π0.5 真实权重受资产限制未执行；
  small/medium 配置可构造（962 K / 4.90 M 参数，读出 128×256 / 256×512）但未训练。
- 下一项诊断（按优先级）：
  1. 让变化分支的量级可测（更长训练或显式幅值监督），再重跑同一矩阵；
  2. 加强可识别性压力：同向近同速、遮挡后新暴露、颜色决定目标选择的反例；
  3. 给 5 个最近基线实现同预算训练入口；
  4. 真实 NPZ 试运行（需要数据侧挂载或服务器运行时）。
