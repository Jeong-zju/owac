# N02 下一轮：绝对拟合与语义反证的边界诊断

2026-10-13 用户授权提交上一轮修改并开展下一轮开发。上一轮代码及证据已分成
`8c60a78`（NRE/BNRE）与 `843be67`（重训测量与调度归档），未推送。
本实验不复活当前归档调度器，不增加模型、训练、候选或依赖模块。

## 问题与冻结条件

先区分测量异常、候选模型不足和语义反证。沿用三个冻结 innovation 评分器、2.5
绝对残差阈值、相同首帧测量，使用新场景种子 28000–28015。每个场景八帧，末帧加入
固定扰动；标签仅用于评价，不进入评分或残差计算。三通道合成伪 RAW，不是真实 CFA。
所有条件和门槛在运行前写入 protocol.json，无训练、无按结果调整阈值。

正常条件保持原帧；增益条件乘1.25；位移条件循环平移(2,2)像素；噪声条件添加独立
高斯噪声sigma=.03。后三项不改变生成场景的方向标签，但超出原训练的部分条件。
结构不足条件为首帧加两个远离的正PSF亮点，或首帧加均匀亮场.15。
它们超出检查器的单个正PSF假设，不能把它们写成已证明的现实物理矛盾。

预定门槛：每种正常/干扰条件拒绝率≤10%；每种结构不足条件双候选拒绝率≥90%。
评分选定候选的拒绝与两候选同时残差过高分别统计，避免混淆。

## 实测

| 条件 | 三个种子的方向正确数（各16） | 双候选拒绝数（各16） |
| --- | --- | --- |
| 正常 | 16 / 16 / 16 | 0 / 0 / 0 |
| 增益 | 16 / 16 / 16 | 0 / 0 / 0 |
| 增加噪声 | 16 / 16 / 16 | 0 / 0 / 0 |
| 平移两像素 | 8 / 11 / 8 | 0 / 0 / 0 |
| 两个分离亮点 | 不定义方向真值 | 0 / 0 / 0 |
| 均匀亮场 | 不定义方向真值 | 16 / 16 / 16 |

两个分离亮点在三个种子中都使相对概率≥.95（每种子16/16），但绝对拟合仍接受。
位移条件中，高确信结果为14/14/15（各16），方向正确仅8/11/8。
正常16/16只是这组新诊断条件的结果，不替代上一轮冻结留出的13/16。

干扰误拒门槛通过，结构不足检出门槛失败。零拒绝也不能解释为干扰鲁棒：位移已经
破坏方向判断。当前平均残差检查对局部双亮点不够敏感；这里定位的是检查器的
边界，没有证明具体语义被反驳，也没有证明误差只能由该检查器导致。

## 下一步与边界

当前局部调度保持归档。下一项开发应先建立校准、配准和局部残差诊断对照，分别
检验“干扰能否解释残差”和“候选不足是否仍有局部证据”，与成熟标准方法公平比较。
在模型不足定位及无信息行为可靠以前，不启动候选生成或未知依赖学习，不延长训练。
最终即使检出模型不足，也还需要独立证明该证据应撤回哪条语义判断。
