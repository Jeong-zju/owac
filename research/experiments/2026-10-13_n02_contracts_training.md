# 2026-10-13 · N02 三契约修订与 tiny 训练阶梯

## 运行前协议

用户授权：先验证评分尺度、几何解释与测量预测的一致性，以及残差何时构成语义反证；
随后 3 个种子各 200 步，行为证据支持时才延长到 800 步。
基础提交 `21f99c3`。本轮新配置 `configs/encoders/n02/tiny_contracts.json` 为可关闭研究变体；
旧配置/旧检查点的默认计算保留。多假设、因果先验、真实测量去重、局部依赖传播与重置继续使用。
实现交付提交为 `b800636`；实验运行时尚未提交，精确源码由 manifest 中逐文件哈希固定。

三个修订：

1. 评分用逐独立测量 Gaussian NLL 求和；总方差明确为传感器方差 + 共享的模型误差方差。
   模型方差通过含 log variance 的预测损失学习；不允许单个候选靠独立放大方差赢得竞争。
   训练测量损失仍按实际标量测量数归一化，posterior 保留求和单位。
2. RAW 均值由共享背景预测与几何调制的共享对比项生成：`mean_k = common + g_k * contrast`。
   `g_k` 是实际返回的第一维几何代理，范围 [-1,1]。对比项初始化为 0，初始等价候选不产生
   人为证据。合成训练额外监督两个反事实测量模板；它们只进入 loss。这是新增监督信息，
   不能将结果与上一轮旧配方称为同信息方法优劣对比，也不等于实现完整物理几何。
3. 语义反证要求：有测量支持、几何代理有差异、局部对数似然优势 ≥log(19)，且竞争解释在
   总误差尺度内拟合良好。普通拟合残差可触发状态修正，但只有语义反证进入传播、重置与撤回。
   保留一次新观测一次撤回；内部循环和重复 ID 不增加证据。

定点检查包括闭式赔率/无关像素、传感器与模型方差、几何干预改变预测、等价候选、同语义
预测差异、全候选拟合差、缺失测量、局部反证与拟合修正分离、监督无输入泄漏、旧检查点兼容。
这些通过后才开始正式训练。

训练固定 tiny：K=4、D=32、cycles=4、history=4；batch=2、sequence=8、64×64 合成三通道
测量，opening_direction，AdamW lr=3e-4、grad clip=1、CPU FP32、1 thread。
初始化/数据种子 0/1/2，分别训练至 100 和 200 步并保存检查点；恢复包含优化器与 RNG。
新头增加少量参数，实际数量记录。训练和模板监督来自原 train 几何/位置/遮挡拆分。

开发集为 validation seeds 400–415，沿用原五条件门槛；另加 16 组相同噪声、仅切换线索的
无先验配对。开发结果用于唯一一次是否延长的决策，不调参、不修改门槛。
延长至 800 步必须同时满足：

- 至少 2/3 个种子在 200 步各达到：正确先验 ≥12/16、错误先验全程纠正 ≥4/16、
  无信息保歧义 ≥12/16、场景变化恢复 ≥4/16、配对两边均正确 ≥8/16。
- 三种子平均的纠错/保歧义/变化恢复通过数之和，从 100 到 200 步不下降。
- 所有定点检查通过，三个训练运行均无非有限损失/梯度/权重。

满足则三个种子均恢复至 800，总正式训练最多 2400 步；否则均停在 200，共 600 步。
这些是计算预算分配门槛，原行为验收阈值不变。
最终一次留出评测使用 seeds 600–631；开发决策前不查看。源码核查确认 generator 只有 train /
validation，故留出仍使用 validation 几何集合，属于独立种子留出，并非第三套全新几何拆分。
此更正在正式训练开始前完成。
任何训练分支只报告实际结果；loss 降低、测试通过、模板参考通过不等于机制成立。

原始 checkpoint/log/逐帧记录保存在 ignored `outputs/n02-contracts-20261013/`；Git 保存
配置、源码/输入/检查点哈希、检查结果、小型数字与结论。本轮不运行真实 NPZ、π0.5 或闭环。

## 实际结果

完成三个种子各 200 步，共 600 次正式优化；**不延长至 800 步，N02 机制仍未通过验收**。
开发集决定在留出数据被读取之前已写入 [decision.json](results/2026-10-13_n02_contracts/decision.json)。
三个种子合格数为 0/3；纠错、保歧义、变化恢复三项通过数合计由 100 步的 20 降至 200 步的 7。
没有因为损失下降而放宽行为门槛，也没有在运行中修改配置。

### 学习模型卡在哪里

训练结束后在开发集上做只读诊断：三个检查点 ×16 种子×三条件（误导、无信息、缺失先验）
×8 帧，共 1152 帧、4113 次实际内部循环。诊断前后参数哈希一致；不额外训练、不参与延长决定。

| 观测（有线索帧的均值） | 种子 0 | 种子 1 | 种子 2 |
| --- | ---: | ---: | ---: |
| 几何代理候选最大间距（触发要求 ≥1） | 0.576 | 0.288 | 0.451 |
| 物理两模板差异 RMS | 0.00603 | 0.00603 | 0.00603 |
| 学习预测两类差异 RMS | 0.000578 | 0.000270 | 0.000395 |
| 学习差异沿真实模板差异的投影增益（理想为 1） | 0.00261 | 0.000815 | 0.000466 |
| 单帧测量分数偏向正确解释的比例 | 38.5% | 59.2% | 50.8% |
| 模型误差标准差 | 0.04681 | 0.04519 | 0.04692 |

1. **评分单位修正没有自动得到可靠证据。** 无线索物理模板严格相同，但学习预测仍有
   0.000283–0.000597 的类间 RMS 差异，单帧测量 log BF 的绝对值均值分别为
   0.359 / 0.097 / 2.980。求和会累积这些微小预测偏差；这些数不能解释成真实语义证据。
   学习的模型标准差也远大于池化后传感器标准差 0.0025；模型误差校准仍需检验。
2. **几何参与预测已经是计算事实，但预测没有学对。** 上表的投影增益说明学出的预测差异
   与真实线索差异对应极弱，不能用几何符号正确率代替物理解释学习成功。模板监督虽然可反传，
   仍未使两类预测沿正确物理方向充分分开。
3. **反证规则不再把普通残差直接当成语义反证，但学习模型没有提供合格反证。** 4113 次循环
   中，满足几何间距或局部 log BF 条件的受支持位置均为 0；最终语义反证也为 0。
   约 99.5% 的位置已经满足“竞争预测在误差尺度内拟合良好”，阻塞在几何分离和局部判别优势。
   本轮不能声称反证传播的学习收益，也不能把不触发规则算成机制成功。

所有 600 步均触发梯度裁剪；三种子前/末 5 步平均总损失分别为
2.956→−4.283、1.685→−4.788、10.970→−1.328。这些是优化诊断，不构成增长训练预算的依据，
也不足以单独认定梯度裁剪就是主因。下一步应先隔离“正确几何已知时能否学出真实测量差异”与
“联合损失是否给几何/线索足够有效梯度”，而不是继续堆步数或降低反证门槛。
逐项数字见 [learned_diagnostics.json](results/2026-10-13_n02_contracts/learned_diagnostics.json)。

## 实现与定点验收

`tiny_contracts.json` 显式启用新变体。旧配置仍为 mean / legacy / independent，
`counterfactual` 权重默认 0；旧检查点无需迁移。编码器参数由 159636 增至 159687，仅新增
51 个共享对比预测参数；K、D、循环和历史预算不变。此数不含单独创建的后端读出投影。

- 评分：总方差为 0.25、两个预测为 0 与 1、观测为 0 时，实际代码产生的 log BF 恰为 2；
  增加三个两候选完全相同的位置不稀释该证据。带 95% 错误先验的后验与闭式式子一致。
- 几何：只干预第一维几何代理的符号，预测均值按 `2*g*contrast` 改变；初始化对比为 0 时，
  四候选预测逐位相同。反事实模板损失有真实梯度，但修改模板目标不会改变编码器输入或前向结果。
- 反证：预测相同、同一几何、全候选拟合差、没有测量支持、模型不确定性较大这五类情况均不
  撤回语义；可靠竞争解释只反驳对应候选的局部格点。大残差仍能触发拟合更新而不触发重置。
- 证据去重：固定场下 1/4 次内部循环的分数逐位一致，重复 ID 不改变分数；暖状态有效新帧
  可以产生非零撤回。原有有向依赖传播、局部更新边界和批隔离测试继续通过。
  实际学习场在重复 ID 上允许继续优化同一个 likelihood；本轮最大权重变化为 0.0459，
  不能把固定场的精确不变性推广为学习求解器所有状态都不变。
- 兼容/恢复：旧 200 步检查点在 seed 200 的五条件逐帧数值与既有记录逐位一致；新变体 seed 99
  的连续 3 步与 2+1 步恢复训练，54 个参数张量逐位一致，评测也能完整运行。
- 正式训练前完整测试为 340 passed / 4 skipped / 1 warning；`make check` 通过。跳过项确切
  对应本机缺失的真实 NPZ 与 π0.5 资产，warning 来自既有测试中带梯度张量转标量。
  seed 99 两条集成试跑合计额外 6 次优化，未计入正式三种子结果。

以上只验证公式、计算依赖和规则边界。求和评分假设各测量项条件独立；学习模型的预测误差
相关性、方差校准和真实概率语义没有因此成立。第一维二元代理参与预测，也不代表网络已经
学会正确物理模板；语义反证判据有效仍依赖候选预测的正确性。这三项须继续看实际行为和预测。
当前判据是局部充分条件；跨帧、分散的弱证据如何形成可传播的语义反证，仍未建立完整规则。

## 复现与证据索引

正式训练前固定的原始协议见 [protocol_before_run.md](results/2026-10-13_n02_contracts/protocol_before_run.md)。
完成测试、旧检查点复核与恢复一致性核查后，正式命令为：

```bash
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONUNBUFFERED=1 uv run --locked python \
  -m owac.evaluation.n02_contracts \
  --output outputs/n02-contracts-20261013 \
  --checks outputs/n02-contracts-preflight-20261013/checks.json
```

输出目录必须尚不存在。脚本每个种子先训练到 100，再恢复至 200；写出开发集决定后才打开
留出种子，满足冻结门槛才训练到 800。它对非有限 loss/gradient 直接失败，并核对运行前后
全部 `src/owac` Python 文件及 N02 配置的哈希。`checkpoint100.pt` 和 `checkpoint200.pt`
分别保留；所有记录位于 ignored 输出目录，Git 仅保留摘要、审计脚本和哈希。

复核入口：

```bash
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 uv run --locked python \
  research/experiments/results/2026-10-13_n02_contracts/inspect_learned.py
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 uv run --locked python \
  research/experiments/results/2026-10-13_n02_contracts/audit_artifacts.py
```

三次留出评测的阶梯主运行墙时 697.52 秒。进程峰值 RSS 708 MiB（累计高水位），CPU FP32、
单线程；期间另有诊断活动，不作为隔离性能基准。无 GPU/真实 NPZ/π0.5/机器人运行。
