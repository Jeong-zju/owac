## 目标与内存语义

新损失定义是 `v1_1_s2_live_forecast_observation_vicreg_v3`。同一窗口中，各项使用实际有效项均值，外层 action / correspondence / forecast / representation 权重仍为 1 / 0.1 / 0.1 / 0.01，窗口之间等权。分段模式先累计各项梯度和，得到有效计数后归约；它与同一 TBPTT 切口下的一次总反传对照。跨段只持有源段图，未来目标不反传。

保留 ConvNeXt-B、完整 RAFT／12 次迭代、6 层读出、每相机 128 支持／256 queries、16 burn-in＋32 梯度帧、4 动作点及 horizons 1/2/4。纯 RKN cell 重算用于临时稠密转移矩阵，不改作者公式或更新次数。

历史 checkpoint 的参数形状虽然相同，读出和目标定义已不同。旧模型继续使用旧冻结源码核查；修补版拒绝把旧权重当无缝 resume 或直接生成新的“同模型”叠图。需要将旧权重作初始化时应另建明确迁移实验，当前未授权、未执行。

## 来源与剩余边界

- Gaussian 裁剪自监督依据 [SMURF 固定源码 smurf_utils.py](https://github.com/google-research/google-research/blob/3ef52111c1fabc301880818f5a547570e926a76b/smurf/smurf_utils.py)。移植该项的掩码、目标停梯度与像素均值，使用同网原图／中心裁剪。**没有声称完整复现 SMURF 的随机光度增强、EMA 和整套训练配方**。
- K/V 结构核对 [OpenFlamingo 固定源码 helpers.py](https://github.com/mlfoundations/open_flamingo/blob/655f693fbfa04cd6e9a987d960654624d48917cf/open_flamingo/src/helpers.py)。项目增加媒体组装、mask、SDPA 和前缀投影。
- 方差／协方差轴依据 [VICReg 官方实现](https://github.com/facebookresearch/vicreg/blob/main/main_vicreg.py)中的跨观测统计；按固定 query 分开计算是本项目防止 query 多样性绕过约束的适配。

**这是代码与梯度语义修复，不是研究能力验收。** 修补版未训练、未产生新 checkpoint、未闭环。RAW 连续证据是否改善动作、质量方差是否校准、修订模式是否具备任务意义、四臂匹配比较及修补版闭环效果仍待后续授权实验。本轮停止点是可审查的代码与验证回执；训练保持停止。
