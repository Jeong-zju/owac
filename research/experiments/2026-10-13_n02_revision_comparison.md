# N02 · 可靠测量下的局部修订调度比较

## 运行前协议与证据范围

可靠测量前置条件已通过：按预定开发选择顺序选出的`innovation`重训官方CNN基线，
新留出25000–25015的三个种子都满足三项行为门槛。配对均13/16，无cue均16/16；
两个方向纠错分别为10/5、5/5、11/8。该选择在留出生成前保存，没有根据留出换到
开发更强的`center_innovation`。所有适配均停在200步，没有续训到800。

本轮将N02**原源码的semantic_map和单跳依赖传播规则**放在独立、精确的状态重组
算子上，与标准有限假设滤波、全局更新和简单事件触发缓存比较。这样不给局部调度混入
旧预测头/随机cell的误差，直接检验它应当贡献的调度收益。它是组件条件实验，**不代表
原完整N02 latent encoder已通过验收**，也不代表机器人闭环。原生产代码和检查点保留。

### 信息、状态与对照

- 新场景seeds27000–27015，各包含4×4个**非重叠**64×64测量支持域，每域独立合成
  物体、噪声和二元世界，八帧。每域的完整前缀由同一冻结CNN评分，不将全局分数复制
  成像素反证图。每域维护首帧参考和GRU32状态；重复观测ID不再运行GRU，乱序拒绝。
- 四个域0/5/10/15有晚到线索和95%错误声明先验，其余十二域不含线索、声明先验0.5。
  这些生成/评估事实不输入调度器；调度器只看实际测量、声明先验和共享依赖记录。
- 任务关系为已知随机单跳邻接图：`q_i = p_i * ∏邻居p_j`，代表联合条件的读出概率。
  每个可能邻边保留概率0.3；图在运行前固定并供全部方法使用，边不携带真实标签。
  全部方法维护相同因子概率p、派生读出q，不用不同状态定义制造漂移差异。
- 标准滤波更新所有支持的因子后重算全部q；全局更新使用相同因子更新与向量化全场重组；
  N02局部方法用原semantic_map检测支持的反证、原propagate沿已记录边传播一次，再
  更新直接被反驳域的因子并重组选择域的q；事件缓存使用直接反证及同一邻接关系完成
  普通缓存失效/重算。最后一个对照用于判断增量计算是否已经解释N02的收益。
- 固定物理候选为±1的两种开口解释，几何间隔为2。使用原log(19)、几何间隔1和
  best_normalized_residual≤2.5的语义判据；不输入测量质量标签或隐藏场景几何。

### 绝对拟合仍是独立检查

分类比不能判断“两候选都错”。这里用实际首帧作为背景参考，在RAW域池化到16×16，
以非正差分拟合衰减干扰、以一个非负Gaussian PSF拟合候选侧的正变化，分别检查两候选
的归一化残差。候选侧由实际首帧的亮度质量中心划分，不读取渲染几何。差分噪声尺度
为`sqrt(2×.01²/16)`；过高拟合误差禁止语义撤回和各方法的因子更新。

这个拟合模型对负干扰很灵活，是声明的结构检查，**不能称已校准的完整RAW密度**。
它与旧生产预测头分开，不将分类置信度当残差。每四个试验中的一个，在末帧域15加入
大范围非结构化亮变化，检查两候选都错时确实被拒绝；正常观测的拟合通过率也必须报告。
本轮不扩展到任意成像变化或隐藏物理变化的可靠检测。

### 指标、成本与退出

- 每种子16场景×4个被误导域，分母64；报告末尾真类质量≥0.7的纠错数及逐帧轨迹。
- 未受影响区域是无cue且不依赖有cue域的节点，**仅供评估**。记录q相对初值的绝对漂移。
  它是明确的概率状态漂移，不用任意latent欧氏距离代替物理状态。
- 每次真实调用都包含CNN/GRU、绝对拟合、语义判断、传播和重组；四方法每帧交错顺序。
  报告p50/p95、实际重组节点数、测量状态字节。按独立场景聚类bootstrap，不能将八帧
  当独立试验。低更新比例不能自动视为低计算；旧生产cell仍在全场计算后才应用mask。
- 预定独有增益：至少2/3种子相对简单事件缓存不降低纠错，且未受影响q漂移降低≥0.01，
  或端到端时延比的bootstrap95%上限<0.9。仅相对全局更新减少工作不视为独有贡献。
- 可靠评分成立而上述独有增益不成立时，按用户要求归档**当前局部修订调度实现**。
  该结论范围为已声明的固定候选/已知单跳依赖条件；不声称否定所有未来的可撤回推断。

## 实际结果与退出决定

完成三个冻结评分器种子×16个独立场景×8帧×四方法的真实比较，共1536次端到端调用。
流式/前缀等价、重复观测、单跳依赖方向与“两候选都错”的针对性检查通过。以下各列
按种子0/1/2列示；每种子的纠错分母64，未满足0.7的节点保留为失败：

| 方法 | 末帧纠错数（/64） | 未受影响q平均漂移 | 实际重组q次数 | 端到端p50（ms） |
| --- | --- | --- | --- | --- |
| 标准有限假设滤波 | 24 / 20 / 35 | 0.00626 / 0.00978 / 0.00601 | 2048 / 2048 / 2048 | 2.472 / 2.467 / 2.462 |
| 全局更新 | 24 / 20 / 35 | 0.00626 / 0.00978 / 0.00601 | 2048 / 2048 / 2048 | 2.472 / 2.462 / 2.457 |
| N02局部调度 | 24 / 20 / 35 | 0 / 0 / 0 | 143 / 118 / 223 | 2.580 / 2.582 / 2.575 |
| 简单事件缓存 | 24 / 20 / 35 | 0 / 0 / 0 | 143 / 118 / 223 | 2.485 / 2.485 / 2.481 |

三种子中，N02与事件缓存的因子p和派生q在**每帧逐位相同**，因此纠错及状态漂移
没有独有增益。普通增量计算已经解释了相对全局重组的收益。N02/缓存的端到端平均时延
比，按独立场景聚类bootstrap的95%区间分别为1.0394–1.0481、1.0335–1.0419、
1.0379–1.0429；三个种子都约慢4%，没有达到上限<0.9的预定时延收益门槛。
N02的p95分别为2.697/2.706/2.658ms，事件缓存为2.562/2.584/2.541ms。

按轨迹独立复算的首次真类质量≥0.7帧号，四方法逐节点一致。曾达到该质量的节点平均
帧号为6.042/6.300/6.389，失败截断数为40/44/28；种子2有一个曾达到门槛的节点末帧
回落，所以其末帧纠错35与曾纠正36分报。该速度是从序列开始计数，不称反证到达后的
反应时。评分前置在原门槛上成立，但这些新组合场景仍有很多未纠正节点；不称完整行为成功。

### 绝对拟合与审计

四个注入的末帧坏支持域在每种子、每方法下都被绝对拟合拒绝（4/4），正常2044个
支持域观测未被该阈值拒绝。它验证声明的非结构化亮变化控制，不能代表任意成像干扰。
没有把ratio置信度代替绝对拟合，原semantic_map/propagate源码与历史检查点未修改。

独立审计重建全部组合场景RAW、图与先验，对1536条调用对应的状态轨迹逐项复算；
又实际重跑每个评分器的一条完整场景，共3×8×4条状态转换，与保存状态一致。正式运行
3.98s、峰值RSS350.23MiB；共享测量张量状态1,575,168字节（≈1.50MiB），每方法另有
p/q各16个浮点值及共享图。该张量计数不含Python对象和参数内存，不称完整模型峰值。

源码进一步说明了成本边界：[旧生产RevisionController.step](../../src/owac/frameworks/n02/revision.py)
先对全场调用cell计算candidate，之后才用mask限制写回，reset时proposal也仍在全场
计算。较小的“updated_fraction”因此不能自动表示卷积计算减少。本实验使用精确重组
算子隔离调度，**没有将该组件时延记为原完整N02 encoder的时延**。

`make check`通过；全库376 passed / 4 skipped，四项skip仍是本机缺少真实NPZ／π0.5
资产。全部源码、协议、观测和权重哈希检查通过，审计脚本见共同回执。

### 归档范围

预定独有收益为**0/3种子成立**。按用户明确的退出条件，归档当前N02局部修订调度实现，
停止沿该实现追加模块或扩训。独立测量基线保留；全部源码、检查点、失败和成功记录保留，
本轮修改未提交。该决定不声称否定所有可撤回推断，也没有把已知固定依赖条件的组件
实验扩张为原全模型、未知关系或机器人闭环的最终定理。

重新开启需要提出相对简单事件缓存有明确新作用的规则和新的冻结验证协议；单纯增加
训练步数、模型规模或重命名消息传递不构成复活理由。见[0014归档决定](../../docs/decisions/0014-n02-scheduler-archive.md)。
