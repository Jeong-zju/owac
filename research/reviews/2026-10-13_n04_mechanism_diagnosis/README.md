# N04：机制收益不明确的原因与解决顺序

## 当前判断需要修正

**首先存在数据与标签错误，导致现有物体定位、运动检测与消融排序不足以判断架构优劣；其次，单样本静态控制确认了创新残差的表征语义问题。** 原“语义修复通过”仍有对应测试和梯度证据；“整体机制收益未建立”仍成立，但不能再把旧指标的高漏报或基线排序直接归因为 N04 的固有机制失败。

此前审计核验了代码/权重身份、训练次数和反事实输入不变量，漏掉了“每个样本中画出来的物体必须与标签一致”。215 项工程测试不能覆盖这个遗漏。所有历史数字保留，标签相关的机制结论转为待修正数据后复验。真实 NPZ/π0.5 的历史接口 smoke 不直接经过该生成器，不能与这次合成标签问题混为一谈。

## 1. P0：批次维被广播成物体维，训练目标含有不存在的物体

[`synthetic.py:254`](../../../src/owac/frameworks/n04/synthetic.py#L254) 执行：

```python
centers = base_object_centers + object_translation
# 实际形状：[B, 1, 2] + [B, 2] -> [B, B, 2]
# 预期单物体/每样本位移：base_object_centers + object_translation[:, None, :]
```

`_paint_objects()` 按 `object_colors` 数目绘制，默认仅画第一个；`_object_mask()` 却遍历广播后的全部 centers。结果是每张图只画一个物体，标签却合并了其他样本的假物体；各样本物体移动还都跟随第一个样本。不同样本的目标位移相同时缺陷不显现，因此很多静态、camera-only 和 batch=1 测试漏过它。该行自 `bdbaa053` 已存在，并非本轮分数统一引入。

无噪声、无饱和、已知颜色的最小复现：

| batch | 请求目标中心 | 实际图像目标中心 | 标签中心 | 每张图真实/标签物体像素 |
| --- | --- | --- | --- | --- |
| 1 | (44,32) | (44,32) | (44,32) | 113 / 113 |
| 2 | (44,32)、(20,32) | 两张均 (44,32) | 两张均 (32,32) | 113 / 226 |
| 4 | 右、左、下、上四个位置 | 四张均在右侧 | 四张均在中心 | 113 / 452 |

batch=2 时每个标签含 113 个没有画出的目标像素；batch=4 时为 339。即使检测器精确分割真正画出的圆盘，在这个特定复现上仍会被算为 50%/75% 漏报。**这不是说历史实验恰好有这么多误差来自此缺陷**，但足以证明评分目标错误。

当前训练 batch=4、评测 batch=2，移动样本确实受影响。所有方法共享错误标签不构成公平物理任务：有的方法可能更善于拟合标签偏差。不能凭 2.019 vs 1.948px 决定架构存废，也不能把 66.22%→53.45%当可靠的真实运动检测改善。源码语义修复可保留；权重需重训。

**解决方法：** 显式规范 `[B, objects, xy]`，位移扩展物体轴；统一渲染对象集合与标签对象集合。除 shape 断言外，加入 batch=1/2/4 的“渲染支持=目标标签”、已知中心、批次置换等变性，以及“仅修改样本 j，其他样本图像/标签不变”的行为检查。生成新数据版本并冻结哈希，重新训练候选与直接基线，旧数据和数字保留。

## 2. 已有受控证据：当前 residual 混入了模型自己的表征改写

[`model.py:237`](../../../src/owac/frameworks/n04/model.py#L237) 的 block 对 stable 加可学习修正；[`model.py:439`](../../../src/owac/frameworks/n04/model.py#L439) 下一步传播这个任务状态；[`innovation.py:194`](../../../src/owac/frameworks/n04/innovation.py#L194) 又直接计算 `stem(current) - propagated(stable)`。没有观测投影确保这两者处在同一语义坐标。未来 RAW 预测头可学习解码 stable，也不自动保证 stable 与 stem 特征可以直接相减。

本轮用 batch=1 避开上述数据错误，固定三份已训练权重，输入 32 帧完全相同、无噪声、未饱和画面，统计第 8—31 帧：

| 固定权重控制 | 三初始化平均 feature residual L1 | 持续 change L1 |
| --- | ---: | ---: |
| 原传播与原 block | 0.32664 | 0.003893 |
| 真值零运动 identity 传播，原 block | 0.24795 | 0.000312 |
| 同一 identity 传播，仅旁路 block 修正 | 1.33e-8 | 7.82e-11 |

单初始化 identity 残差为 0.28465/0.27308/0.18610；旁路 block 后都到约 1e-8。这证明当前权重下，即便几何运动完全正确，内部表征修正本身也会制造 innovation。identity 同时改变传播 uncertainty，所以第一行到第二行不能全部归因于 flow；第二、三行保持同一个 identity/uncertainty，能隔离 block 对本诊断残差的作用。

边界：这些权重来自错误训练标签；控制仅诊断静态残差来源，不能宣称删除 block 能提高任务成绩或某比例的旧误报由 block 导致。零残差下事件门仍有约 0.68% 像素越过 0.5，也说明当前判别可以脱离变化证据；具体外观捷径仍需额外干预验证。

**解决方法：** 让任务记忆与观测预测具有清楚接口。先比较最小改动：任务 stable 照常更新，但创新从传播后的上一有效测量特征形成，配合特征 warp 一致性检查；再比较显式观测投影 `O(predicted_state)` 与当前测量编码 `M(raw)` 的残差。允许 stable 进行任务抽象，要求用于相减的预测与测量对齐。静态、纯相机运动和曝光变化的残差必须分别有可检验的解释，不能只靠分类头忽略内部偏差。

## 3. 源码事实：原因门存在，原因的测量贡献尚未真正分离

[`innovation.py:210`](../../../src/owac/frameworks/n04/innovation.py#L210) 估计线性增益，但增益仅作为 trunk 输入；[`model.py:527`](../../../src/owac/frameworks/n04/model.py#L527) 写入 change 的仍是：

```text
e_t = external_event_score × (measured_feature - predicted_stable) × valid
change_t = decay × ego_warp(change_prev) + write_scale × e_t
```

[`training/n04.py:801`](../../../src/owac/training/n04.py#L801) 用同一个混合 residual 的幅度构造外部分支目标。有效测量处忽略数值 epsilon 时，这项损失近似 `|gate - motion_mask| × ||mixed_residual||`：它主要再次训练门的强弱，没有独立的“外部变化贡献”真值。当物体运动与曝光/传播误差共存，event=1 并不意味着整段 residual 都属于物体运动。

同样，`imaging` 标签把曝光增益变化与饱和归到一支，而其门会降低测量更新。未饱和且可解释的增益变化不一定意味着当前观测更不可靠；这个设计可能导致不必要的滞后。该解释有源码路径支持，尚未通过独立重训分配其对性能的贡献。

**解决方法：** 保留“运动存在”的事件分数，另让外部创新来自具有物理解释的预测差。概念上：

```text
已发生的自身运动 -> 无外部运动时的测量预测
曝光/响应参数 -> 在相同传感器、相同曝光条件下的预测
当前 RAW 与该预测的差 -> 待解释的外部创新及不确定性
```

曝光变化应改变观测模型，饱和/噪声/遮挡决定可靠性；二者分别处理。对 CFA 保留采样相位，用原始测量单位和噪声尺度约束残差。原测量特征继续供任务读出，避免把任务相关颜色/亮度一并抹去。估计增益时使用稳健背景支持，避免外部物体变化被低频增益吸收。当前图像可用于 correction 阶段的成像参数估计，纯运动 prediction 仍只用历史与实际上下文。

这条技术方向有已有工作边界：[DSO](https://arxiv.org/abs/1607.02565) 已联合几何、相机运动及光度标定；[MaskFlownet](https://arxiv.org/abs/2003.10955) 已研究 warp 后的遮挡歧义和可靠特征匹配。引用只支持问题与设计依据，不证明本候选收益，也不将这些规则当作 OWAC 首创。

## 4. 训练分布与任务没有充分要求所宣称的分离能力

[`synthetic.py:404`](../../../src/owac/frameworks/n04/synthetic.py#L404) 中，物体只在 object-only/both/same-direction 移动，照明只在 illumination/exposure-step 变化；后两类物体均静止。因此**运动物体与变化照明在当前序列生成规则中不共存**。首个九条件训练循环的逐帧检查也为零。改为独立 sigmoid 只是允许共存，并没有教会模型在共存时分离。

事件监督是整个移动物体掩码，而可观测的短时像素变化主要发生在边缘、遮挡和反遮挡位置；均匀物体内部、过小位移和采样量化可能不可判别。原 same-direction 单类跳过不能覆盖所有歧义。当前 unknown 主要监督 `1-history_valid`，只表示没有历史支持，不能证明它学会了“多个物理原因无法区分”。这些问题须在 P0 标签修复后重新量化，不能引用受污染的掩码统计来给它们分配误差比例。

位置探针主要要求识别当前圆盘位置，可以由普通当前观测更新完成；未来测量头主要读 stable，缺少明确的外部速度/运动状态训练要求。将梯度接通、产生非零 change、调大某个 loss，都不足以保证额外状态有任务价值。

**解决方法：** 在正确生成器上使用相机运动×物体运动×曝光变化的因子组合；加入运动停止、反向、遮挡重现、变化不可观测、颜色决定目标等配对例子。配对时几何、相机、成像和噪声随机数严格控制。合成训练可用同一时刻“冻结物体在上一物理位置”的反事实渲染差监督外部测量贡献，包含物体离开后的背景暴露；它与物体级运动事件是不同、明确的输出目标。反事实真值仅作离线标签，不进入在线 encoder。

增加必须区分自运动与外部运动的任务读出，例如世界相对目标速度、短时未来位置、停止后的修正；同样给基线上下文。只有这些信息确实改善决策，才能将分解称为机制收益。先在合成任务测可观测上限，再做真实 RAW 动作适配和闭环。

## 5. change 记忆的内容、运输和监督不一致

当前写入的是带符号外观残差，历史 change 只按相机运动运输，没有显式外部目标运动运输；标量衰减约 0.736—0.738，每次写入系数约 0.127—0.134，约 2.3 帧半衰期。它可以形成短时修正缓存，但不能据此宣称跟踪了持续物体变化。原始 `_change_loss` 已改为监督瞬时写入，避免了单帧标签惩罚历史记忆；相应地，持续记忆自身主要通过任务间接学习，缺少明确动态语义。

**解决方法：** 先明确 change 要表示“瞬时证据”还是“动态状态”。若保留短时证据缓存，定义支持、年龄、证据撤销和丢失测量规则，并只提出对应能力主张；若要承担持续跟踪，就需要外部位移/速度或等价动态转换来运输历史，以及停止/反向/遮挡重现的时间监督。不能把 signed residual 的累加幅值直接当作物体运动强度。分别做只去掉记忆、只去掉事件门、只去掉 readout 使用的干预，避免整个分支消融混合多个作用。

## 下一轮建议的执行顺序

| 优先级 | 具体工作 | 进入下一步的证据 |
| --- | --- | --- |
| P0 | 修正批次/物体轴；验收渲染、标签、运动与样本独立性；生成新版数据 | batch=1/2/4 已知几何逐样本一致，批次置换与隔离通过；旧错误样本保留为回归 |
| P1 | 在正确数据上重训当前候选、motion-compensation、filter、no-change、no-illumination | 新初始化与场景/数据划分；同数据同更新、实际容量/成本分报；恢复可信基准 |
| P2 | 单独修正观测残差接口，先做静态与 oracle ego/gain/event 上限诊断 | 固定状态/观测时内部表征修正不再制造观测创新；oracle 改善哪一段有可定位证据 |
| P3 | 将增益纳入观测预测，增加组合干预与可观测标签，再逐项加入动态记忆规则 | 同一物体运动在不同光照/相机条件下保留；无物体运动时不制造外部创新；仍保留任务相关外观 |
| P4 | 冻结新验证协议，比较下游任务、检测/恢复与成本 | 在强基线与匹配消融上有一致收益，报告初始化/数据变化、最差条件及代价 |

当前 frozen 组冻结的是初始化传播器（`train()` 新建 encoder 后立即 freeze，运行脚本没有加载预训练传播器），不能回答“训练好的传播固定住之后，分解是否还有价值”。下一轮应先独立训练传播，再把同一份权重用于冻结/联合训练两组；oracle geometry 只作诊断上限。

当前 200 updates 和同一训练数据的三个初始化也不足以排除优化未收敛或数据依赖。正确数据基准建立后，预定少量训练预算点，给候选与基线同等开发调参机会；用验证集看学习曲线与各目标梯度关系，最终测试集一次冻结。不能以无依据的“再加训练步数/调大 change 权重”替代前面的结构诊断。

两个全图 change 幅值比继续保留为历史诊断，不能作为唯一分离判据：它们受变化面积、可学习尺度及记忆衰减影响。旧 object-only 第 8 帧停止运动，还需分报运动窗口和停止恢复窗口。本轮事后截取相同第 2—7 帧，旧权重比值也未变好（均值 1.267/2.379）；由于数据缺陷，这些只是协议问题检查，不能作为新机制成绩。新的主指标应包含有效区域上的事件 PR/固定误报率召回、配对局部外部贡献保留、分条件定位/未来位置误差、完整恢复/censored 与成本。

如果正确标签下，真值 ego、成像参数和事件门仍不能让新增状态改善需要动态信息的任务，应重新设计记忆/读出，必要时保留简单运动补偿作为主基线；如果 oracle 有收益而学习版没有，才集中处理估计和优化。当前最合理的投入顺序是数据真实性、观测残差语义、实际原因解释与组合训练，最后检验完整机制收益。
