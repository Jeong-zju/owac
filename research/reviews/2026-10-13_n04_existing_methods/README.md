# N04：已有方法与代码复用评审

核查日期：2026-10-13。N04 对照源码：`885d6f2e987ba54f75a7b811b7799253f2265c99`。

本轮是文献检索与源码适配评审，没有修改编码器、安装外部训练环境或产生新的性能结果。论文结果属于作者的数据和协议；下文对 N04 的效果判断均是待验证假设。固定版本、源码入口和核查范围见 [sources.json](sources.json)。

## 判断与优先级

**已有研究足以替代 N04 的若干自制基础模块。优先引入可预测的运动状态和带噪声尺度的观测更新；暂不把更大的光流网络当作首要修复。**

当前证据来自[分阶段重建与留出验收](../../experiments/2026-10-13_n04_staged_rebuild.md)：完整候选定位 0.310 px，同分布无 change 分支 0.303 px，仅照明提示 0.302 px；删除历史 change 对动态序列影响很小；完全缺失观测时，仅扰动 change 不改变下一步 stable。这里的不足是已验证的状态依赖路径与任务增量不足，不能直接归结为“训练太短”。

| 优先级 | 现有方法 / 代码 | 可解决的问题 | 本轮建议 |
| --- | --- | --- | --- |
| P0 | FilterPy；后续可比较 OC-SORT | 是否有必要记住位置、速度和不确定性；重现后的轨迹修正 | 先用现成数值滤波器建立更强的动态定位基线 |
| P0 | RKN，ICML 2019，作者 PyTorch 实现 | 在特征空间中预测和校正；缺失观测时继续传播状态 | 第一项值得接入的可学习动态模块 |
| P1 | EMVD，CVPR 2021；Zheng 等的改进与 IPOL 代码 | RAW 噪声随信号变化；对齐误差、遮挡与融合权重混杂 | 借鉴其 RAW 方差与融合规则；代码需要适配与授权范围核实 |
| P1 | Dynamo-Depth，NeurIPS 2023 | 自运动与独立物体运动存在多种解释 | 复用几何分解和分阶段训练，先做真值运动诊断 |
| P1 辅助 | DSO，TPAMI 2018 | 曝光、响应和光度残差的物理解释 | 参考校准及受约束的亮度模型，无需引入整套 SLAM |
| P2 | DreamerV3 的 RSSM | 动作条件化的潜在动力学与多步预测 | RKN 不够时的架构参照；迁移与训练代价较高 |

这不是整套模块串联方案。每项先作为独立对照；只有收益通过后，才讨论组合。

## 1. 动态状态：先用 FilterPy，再评估 RKN

### FilterPy / OC-SORT：成本最低的反证

[FilterPy](https://github.com/rlabbe/filterpy) 的 `KalmanFilter.predict()` / `update()` 已提供位置—速度状态、协方差传播及创新计算，`update(None)` 保留预测状态。可以直接使用该库，不必重新写滤波数值内核。它是数值库，并非现成的 RAW 视觉模型。

建议在同一个**当前帧测量头**后连接 `[x,y,vx,vy]` 滤波器，并用同一个已估计 ego 变换转换坐标；缺失时不调用观测更新。不要把已经融合历史的 N04 stable 位置再当作独立测量反复融合，也不要用真值目标中心替代预测中心。真值中心和真值 ego 只进入单独标注的诊断。

[OC-SORT 论文](https://arxiv.org/abs/2203.14360)与[作者代码](https://github.com/noahcao/OC_SORT)进一步利用真实检测轨迹修正遮挡期间积累的误差。核对 `trackers/ocsort_tracker/kalmanfilter.py` 的 `freeze()` / `unfreeze()` 后，需要区分：它在目标**重新被观测到以后**，用遮挡前后观测生成虚拟轨迹并更新当前滤波状态。不能把事后修订的历史轨迹当成当时已经做出的预测。

N04 当前是单目标定位，先用 FilterPy 比搬入检测器、匹配器和整套多目标跟踪更直接。两仓库顶层许可证均为 MIT；额外检测器/权重另核查。FilterPy 的 IMM 可作为停止/匀速模式的后续对照，本轮不把多模式切换与基础 KF 同时加入。

### RKN：最值得先试的可学习模块

[Recurrent Kalman Networks](https://proceedings.mlr.press/v97/becker19a.html)把观测编码为潜在均值和方差，学习状态转移，用显式不确定性控制更新。[论文代码入口](https://github.com/LCAS/RKN)明确链接到作者的[独立 PyTorch 实现](https://github.com/ALRhub/rkn_share)，不必移植旧 TensorFlow 工程。

直接复用入口是 `rkn_cell/RKNCell.py`：`_predict()` 传播潜在状态和协方差，`_masked_update()` 在无观测时保留 prior。源码中后半部分潜在状态通过转移矩阵影响前半部分，因此具备 N04 当前 change 缓存缺少的预测依赖路径；这不意味着潜在维度天然等于物理速度。

接入时有四点必须明确：

1. 默认 `never_invalid=True`，要显式设为 `False` 并传入观测有效性；该实现的 mask 是每个样本的标志，不直接支持 N04 的逐像素局部缺失。
2. `forward()` 的顺序是“校正当前 prior，再预测下一步”，返回当前 posterior 和下一步 prior。应包一层时间语义接口，不能把下一步 prior 当作当前定位结果。
3. 原单元没有动作参数。第一轮在相机运动补偿后的共同坐标中评估无动作 RKN；若加入动作转移，属于额外改造和单独因素，不能称原版 RKN 的现成功能。
4. 输入应由 RAW stem 生成，输出接同预算的定位/任务读出。需要训练观测均值、方差及转移；低维输入实验还要按潜在维度调整带状矩阵的 bandwidth。作者的摆杆实验不提供可直接用于 RawVLA 的权重。

该 PyTorch 仓库顶层是 MIT，原始 TensorFlow 仓库是 GPL-3.0，不能混淆。PyTorch 项目的旧依赖环境尚未在当前 OWAC 环境运行验证。本轮推荐的是可复用的研究实现，不宣称即装即用。

**验证意义：**若现成 KF/RKN 在相同测量下明显改善缺失帧定位，说明瓶颈主要在状态及转移；若仍无改善，应先查测量质量、坐标补偿和任务可预测性，而非继续堆 change 门。

## 2. RAW 观测：EMVD 后续工作比泛化的“照明分支”更具体

[EMVD 原论文](https://openaccess.thecvf.com/content/CVPR2021/html/Maggioni_Efficient_Multi-Stage_Video_Denoising_With_Recurrent_Spatio-Temporal_Fusion_CVPR_2021_paper.html)研究低成本的 RAW 视频递归融合、去噪和细节恢复。更贴近 N04 的是 Zheng、Facciolo、Arias 的[改进论文](https://www.gretsi.fr/data/colloque/pdf/2022_zheng966.pdf)及[IPOL 项目与源码](https://www.ipol.im/pub/pre/464/)：加入运动补偿、方差稳定化，并分开处理遮挡和融合权重。IPOL 页面当前标注为 preprint；这是后续作者的实现，不是原 EMVD 作者发布的代码。

已下载源码 ZIP 并检查：

- `networks/emvd.py`：`EMVDfeatbasic`、`variance_stablize()`、`noise_map_fused()`、`fusion_weight()`。`ratioVariance=True` 时，学习权重乘上由当前/历史方差计算的比例，区分匹配可靠性与降噪融合需求。
- `models/recurrentFeat_model.py`：历史特征对齐、状态回传和序列展开；光流使用当前与前一帧，所以应属于 correction 阶段。
- `util/addNoise.py`：噪声参数随 ISO 指定，采用信号相关方差；源码硬编码了特定数据的 ISO 3200/12800 参数，不能沿用到 RawVLA 的三通道 pseudo-RAW 或另一 Bayer 传感器。

对 N04 最值得借鉴的是：**同样大小的观测残差，在噪声很大的像素和干净像素上，应该有不同的证据强度。** 当前降低条件残差幅度，并不自动等于更准确地辨认外部运动。

建议先只加入一个按传感器噪声尺度归一化的残差对照；曝光/增益、运动及训练数据保持不变。使用真值噪声参数检查诊断上限，再判断是否需要学习噪声参数。计算历史方差时应考虑增益平方与插值权重平方；把方差图像像亮度一样直接插值，并不等同于传播独立噪声的方差。对相关的递归误差还应明确近似假设。

该源码包在检查的顶层目录及核心 Python 文件中未发现统一许可证声明，第三方 C 组件有各自许可证；本轮不将其标成可直接复制进 OWAC 的授权实现。包中还包含去马赛克/可视化流程，不能整套接到主 RAW 编码链。先把论文规则和下载源码用于核查；具体 vendor 范围与授权仍需确认。无论授权如何，RAW 去噪的 PSNR 收益都需要另外验证是否转化为 N04 定位或动作收益。

## 3. 运动分解：Dynamo-Depth 比残差分类更接近物理解释

[Dynamo-Depth 项目](https://dynamo-depth.github.io/)联合估计深度、相机运动、独立 3D 运动与运动区域。其核心问题是：同一种图像运动可能由错误深度或真实物体运动解释；增加分支名称本身不能解决这种歧义。

[官方 PyTorch 源码](https://github.com/YihongSun/Dynamo-Depth)中值得复用的入口：

- `Trainer.py::generate_images_pred()`：计算 rigid ego flow，用 complete flow 与其差异得到 residual flow，结合运动 mask 后重新投影。
- `Trainer.py::setup_phase()`：依次初始化深度/位姿、运动、mask，再联合微调。借鉴的是分阶段约束竞争解释的训练方法；不照搬车载数据的全部先验。
- `tools.py`：深度反投影、3D 投影等几何算子。几何内核可与 N04 现有实现交叉核对，没必要重复造轮子。

接入限制：源码图像采样用 `align_corners=True` / `border`，N04 已固定 `False` / `zeros` 与显式 validity，不能直接拼接网格；深度与平移必须共用尺度；相机姿态、forward/backward 方向、CFA 相位坐标都要在边界上转换。RGB 预训练权重和光度损失也不能无改动宣称为 RAW 模型。当前帧参与的运动估计只能进入 correction，不能进入 `predict_before_observe()`。

建议先在 N04 已有真值运动上构造“只有 ego”与“ego + 物体运动”的测量解释对照，冻结其他因素，检查外部事件定位是否改善。此前真值 change 运输几乎无收益，测试的是**缓存怎么搬运**，不等于上述**观测如何解释**已经失败。只有观测解释确有增量，才训练对应运动模块。

顶层许可证 MIT；源码包含继承组件，实际复制时保留文件级声明。作者项目也明确展示移动阴影会被解释为独立运动的失败案例，不能把几何流差当作物体运动的完美标签。

## 4. 成像解释：借 DSO 的约束，不引入整套 SLAM

[DSO 论文](https://arxiv.org/abs/1607.02565)将曝光、相机响应和暗角校准纳入光度模型。[源码](https://github.com/JakobEngel/dso) `src/util/NumType.h::AffLight::fromToVecExposure()` 明确计算曝光比与仿射亮度变换，`src/FullSystem/Residuals.cpp` 使用相应光度残差。

N04 已有 RAW 域乘性增益解释，因此“再加一个 gain”不是新方案。可借鉴的是：有可靠曝光/增益元数据时先按其约束；残余未知变化才拟合低自由度模型，并用可靠历史支持区域求解。黑电平已校准时不无条件加入自由 offset。让任意局部亮度场解释残差，可能顺带消除真实物体变化。

DSO 是 C++、稀疏、静态场景假设下的里程计，顶层 GPL-3.0。当前工作只需参考其观测建模和诊断思路；把全套 SLAM 搬进 N04 不会直接解决动态记忆。

## 5. 较重的替代与容易误用的现成模型

| 方法 | 已核查的能力或代码事实 | 对 N04 的定位 |
| --- | --- | --- |
| [DreamerV3](https://github.com/danijar/dreamerv3) / [论文](https://arxiv.org/abs/2301.04104) | `dreamerv3/rssm.py` 分开 `observe()` 和 `imagine()`；后者由状态与动作推进；官方当前实现为 JAX，顶层 MIT | 更完整的动作条件动力学参照；迁移和训练成本高。只借 RSSM 也需要 RAW 观测接口及合适损失，不能照搬 RGB 重建目标 |
| [OC-SORT](https://github.com/noahcao/OC_SORT) | 在重新获得观测后进行轨迹重更新，顶层 MIT | 多目标/重识别问题出现后再加；不要用事后历史修订抬高缺失期间的在线指标 |
| [FloRNN](https://github.com/nagejacob/FloRNN) | `models/flornn_raw.py` 默认 `forward_count=2`，输出第 t 帧时已处理 t+2；先 `demosaic()` 再用 PWC 估计流；顶层 GPL-3.0 | 可作单列延迟与输入条件的复原对照，不能直接成为 N04 的零等待 RAW 主链 |
| [CoTracker3](https://github.com/facebookresearch/co-tracker) | 官方 `CoTrackerOnlinePredictor` 默认窗口 16、step 8，读取图像块；README 说明主体 CC-BY-NC | 有现成权重的 RGB 点跟踪基线；在线滑窗不等于逐帧零等待，须记录每个输出实际用了哪些帧 |
| [CUT3R](https://github.com/CUT3R/CUT3R)、[STream3R](https://github.com/NIRVANALAN/STream3R) | 官方页面提供持续状态/因果流式 3D 模型及权重；本轮仅核查项目入口，未做文件级审计 | 值得作为更强视觉观测的后续参照；处理动态画面的几何不自动等于缺失期间预测物体运动 |
| [MonST3R](https://github.com/Junyi42/monst3r)、[MegaSaM](https://github.com/mega-sam/mega-sam) | 提供动态视频的几何/相机估计流程；本轮为项目级核查 | 可用于独立 RGB 几何诊断，整段/窗口优化不能按无未来帧的 N04 在线预测计分 |

RawVLA 已是项目的直接系统基线。本轮不把换一个 RGB 几何塔或加入 RAW-to-RGB ISP 作为保留 N04 输入边界的模块复用。更大预训练模型若赢得性能，也需单列外部训练数据、输入和延迟，不能归因为 N04 新机制。

## 6. 建议执行的最小验证序列

第一轮保持编码器和数据不动，先验证动态状态；第二轮独立验证 RAW 噪声尺度；运动解释最后按诊断结果决定是否训练。

| 顺序 | 只变化的因素 | 固定项与对照 | 能回答的问题 |
| --- | --- | --- | --- |
| A0 | 当前测量位置 → FilterPy 位置/速度滤波 | 同一冻结单帧测量头、相机上下文与数据；同头无滤波 | 显式运动状态本身是否值得做 |
| A1 | KF 转移/更新 → 作者 RKN 单元 | 先用相同冻结测量；需要新增投影时，两组共享投影及训练预算 | 学习动态与不确定性是否比简单动力学更好 |
| A2 | RKN 的观测接口 | A1 成立后才换成 RAW latent 均值/方差；同时训练匹配 GRU 对照 | 图像特征中的动态信息是否优于低维测量 |
| B0 | 残差按已知噪声尺度标准化 | 单独从冻结 N04 起跑；相同 gain、ego、数据与门结构 | 误报是否源于残差没有噪声单位 |
| B1 | 已知噪声参数 → 估计参数 | B0 有空间再做；不能同时升级曝光模型 | 实际可估计性是否是瓶颈 |
| C0 | ego-only → ego + 真值独立运动的观测解释 | 同一权重、有效支持、增益、不确定性；只作诊断 | 几何解释能否改善事件识别，而非仅降低残差 |
| C1 | 真值外部运动 → 学习模块 | C0 成立后复用 Dynamo-Depth 分解规则与阶段训练 | 对应运动模块是否值得训练 |

诊断真值不是可部署输入，也不一定是与现有权重兼容的数学上限；硬替换后无收益需同时检查接口分布变化。

评测要求：

- 已看过的 45000—45002 是历史测试结果，不能重新称作未见留出。新选择只用开发集；实现和预算冻结后启用新的场景/轨迹留出，并锁定清单。
- 缺失期逐帧输出当时立即保存。主指标为缺失帧位置误差、停止/反向后的误差和恢复后误差；不让重新出现后的平滑改写历史分数。
- 将纯相机运动、纯物体运动、成像变化以及组合条件分开报告；不以 change 幅值比代替事件误报/漏报。
- 同训练步数之外，记录参数、可用历史、额外监督/预训练数据、完整 encoder 与 readout 时延和状态内存。200 步仅作为快速诊断预算，不能据其失败宣判文献方法无效。
- 对完全不可见期间无外部线索的随机停止/反向，不要求任何方法准确预知；比较合理预测和不确定性，以及重获观测后的修订。先用可预测的持续运动证明动态记忆确实被使用。
- 继续区分作者三通道 HDR-derived / pseudo-RAW 与原生 Bayer CFA；传感器参数不跨域硬套。

## 本轮交付范围

完成原始论文/作者项目检索，8 个 GitHub 仓库提交身份固定，关键源码接口审查，以及 IPOL 源码包下载、哈希与核心文件核查。没有复制外部算法进 `src/owac`，没有运行这些方法的训练或比较，也没有外部方法提高 N04 性能的新证据。选择建议基于当前瓶颈与代码适配性。

本轮最值得投入的第一项是 **同测量的 FilterPy → RKN 对照**；RAW 方向最贴近的参考是 **EMVD 后续工作的噪声方差与遮挡/融合分离**。N04 的候选贡献应在这些现成对照之上重新检验。
